# 🔍 Поиск товаров — Архитектура и возможности

## Обзор

Поиск товаров построен на связке **Laravel Scout** + **Meilisearch v1.5**. Это обеспечивает мгновенный полнотекстовый поиск с типизированной релевантностью, а также продвинутые возможности, которые делают поиск по-настоящему удобным для русскоязычных пользователей.

## Стек технологий

| Компонент | Технология | Назначение |
|-----------|-----------|------------|
| Поисковый движок | **Meilisearch v1.5** | Полнотекстовый поиск с ранжированием |
| Интеграция | **Laravel Scout** | ORM-мост между Eloquent и Meilisearch |
| Обработка запросов | `SearchHelper` | Транслитерация, конвертация раскладки |
| Индексируемые модели | `Product`, `Category`, `Brand`, `Article`, `News` | Основные сущности каталога и контента |

## Ключевые возможности поиска

### 1. 🔤 Поддержка транслита (RU → EN)

Пользователь вводит транслитом — находит товар с кириллическим названием.

| Пользователь ввёл | Найдёт товар |
|---|---|
| `vibrator` | «Вибратор ...» |
| `smazka` | «Смазка ...» |
| `prezervativ` | «Презерватив ...» |

**Как это работает:**

При индексации каждого товара генерируется поле `name_translit` — автоматическая транслитерация кириллического названия в латиницу:

```
"Вибратор Lola" → "Vibrator Lola"
```

Класс `App\Helpers\SearchHelper::transliterate()` выполняет посимвольную замену по таблице:

```
а→a, б→b, в→v, г→g, ж→zh, ч→ch, ш→sh, щ→shch ...
```

---

### 2. 🔤 Обратная транслитерация (EN → RU)

Латинские символы в названии товара также конвертируются в кириллицу для поиска.

| Пользователь ввёл | Найдёт товар |
|---|---|
| `вибратор лола` | «Vibrator Lola» |

Поле `name_cyrillic` — обратное преобразование латиницы в кириллицу:

```
"Vibrator Lola" → "вибратор лола"
```

Метод `SearchHelper::transliterateToCyrillic()` сначала обрабатывает многосимвольные сочетания (`shch→щ`, `sh→ш`, `ch→ч`, `zh→ж`), затем односимвольные.

---

### 3. ⌨️ Непереключённая раскладка клавиатуры (EN ↔ RU)

Забыли переключить раскладку — поиск всё равно работает!

| Пользователь ввёл | Что он хотел набрать | Найдёт |
|---|---|---|
| `db,hfnjh` | «вибратор» | ✅ Вибратор ... |
| `смазла` | (набирал на RU) | ✅ Смазка ... |
| `ghtp` | «през[ерватив]» | ✅ Презерватив ... |

Поле `name_layout` — конвертация названия товара в альтернативную раскладку клавиатуры:

```
"Вибратор" → "db,hfnjh"   (RU→EN)
"Lola"     → "дщдф"        (EN→RU)
```

Метод `SearchHelper::convertLayout()` определяет наличие кириллических символов и заменяет каждый символ на его пару по физическому расположению клавиши:

```
й↔q, ц↔w, у↔e, к↔r, е↔t, н↔y ...
```

---

### 4. ✏️ Толерантность к опечаткам (Typo Tolerance)

Meilisearch **из коробки** поддерживает typo-tolerance — поиск с опечатками.

| Пользователь ввёл | Найдёт |
|---|---|
| `вибраьор` | ✅ Вибратор |
| `презирватив` | ✅ Презерватив |
| `смаска` | ✅ Смазка |

Meilisearch использует расстояние Дамерау–Левенштейна:
- **1 опечатка** допускается в словах от 5 символов
- **2 опечатки** допускаются в словах от 9 символов

Это встроенная функция Meilisearch, не требующая дополнительной настройки.

---

### 5. 🔠 Prefix-поиск (поиск с начала слова)

Meilisearch поддерживает **prefix search** — начните набирать, и результаты появятся мгновенно.

| Ввод | Результаты |
|---|---|
| `виб` | Вибратор ..., Вибромассажёр ... |
| `пре` | Презерватив ..., Прелюдия ... |

## Архитектура индексации

### Индексируемые поля товара (`Product`)

```php
// app/Models/Product.php → toSearchableArray()
[
    'name'             => 'Вибратор Lola Dream',       // Оригинальное название
    'name_translit'    => 'Vibrator Lola Dream',        // RU → Латиница
    'name_cyrillic'    => 'вибратор лола дреам',        // EN → Кириллица
    'name_layout'      => 'db,hfnjh Lola Dream',       // Альтернативная раскладка
    'brand'            => 'Lola',                       // Название бренда
    'category'         => 'Вибраторы',                  // Название категории
    'description'      => '...',                        // Описание товара
    'sku'              => 'LOL-12345',                  // Артикул
    // + служебные поля для фильтрации и сортировки
]
```

### Индексируемые поля категории (`Category`)

```php
// app/Models/Category.php → toSearchableArray()
[
    'name'          => 'Вибраторы',
    'name_translit' => 'Vibratory',
    'name_cyrillic' => 'вибраторы',
    'name_layout'   => 'db,hfnjhs',
    // ...
]
```

### Индексируемые поля бренда (`Brand`)

```php
// app/Models/Brand.php → toSearchableArray()
[
    'name'          => 'Satisfyer',
    'name_translit' => 'satisfyer',       // RU → Латиница
    'name_cyrillic' => 'сатисфйер',       // EN → Кириллица
    'name_layout'   => 'ыфешыагуек',      // Альтернативная раскладка
]
```

### Индексируемые поля статьи (`Article`)

```php
// app/Models/Article.php → toSearchableArray()
[
    'title'             => 'Как выбрать подарок',
    'title_translit'    => 'kak vybrat podarok',
    'title_cyrillic'    => 'как выбрать подарок',
    'title_layout'      => 'rfr ds,hfnm gjlfhjr',
    'short_description' => 'Советы по выбору ...',
]
// shouldBeSearchable() — только опубликованные
```

### Индексируемые поля новости (`News`)

```php
// app/Models/News.php → toSearchableArray()
[
    'title'          => 'Открытие нового сезона',
    'title_translit' => 'otkrytie novogo sezona',
    'title_cyrillic' => 'открытие нового сезона',
    'title_layout'   => 'jnrhsnbt yjdjuj ctpjyf',
]
// shouldBeSearchable() — только опубликованные
```

### Приоритет поисковых полей

Конфигурация Meilisearch задаёт порядок приоритетов (чем выше — тем важнее совпадение):

```php
// config/scout.php → meilisearch.index-settings.products
'searchableAttributes' => [
    'name',            // 1. Название (высший приоритет)
    'name_translit',   // 2. Транслит
    'name_cyrillic',   // 3. Обратный транслит
    'name_layout',     // 4. Альтернативная раскладка
    'brand',           // 5. Бренд
    'category',        // 6. Категория
    'description',     // 7. Описание
    'sku',             // 8. Артикул
]
```

## Поисковые эндпоинты

### Основной поиск каталога

```
GET /catalog?search=вибратор
```

- Использует `Product::search($query)` через Laravel Scout
- Автоматически фильтрует товары **в наличии** (`in_stock = true`)
- При поиске игнорируется фильтр по категории (поиск глобальный)
- При отсутствии `search` — обычная постраничная выдача каталога

### Поисковые подсказки (Autocomplete)

```
GET /api/search/suggestions?q=виб
```

Возвращает JSON с двумя блоками:
- **products** (до 8 товаров) — id, название, цена, изображение, URL, рейтинг
- **categories** (до 4 категорий) — id, название, иконка, URL

Используется для мгновенных подсказок в строке поиска.

## Переиндексация

При необходимости полной переиндексации:

```bash
# Товары
php artisan scout:flush "App\Models\Product"
php artisan scout:import "App\Models\Product"

# Категории
php artisan scout:flush "App\Models\Category"
php artisan scout:import "App\Models\Category"
```

При обновлении или создании товара/категории через Eloquent индекс обновляется **автоматически** благодаря трейту `Searchable`.
