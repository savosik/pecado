## 4.9 — Параллельные `product.updated` без deadlock (v13.0)

- [ ] Атрибуты привязаны к категории через `insertOrIgnore`
- [ ] При временном deadlock срабатывает `retry([100, 250], ...)` и сообщение завершается успешно
