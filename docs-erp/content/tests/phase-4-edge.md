# Фаза 4: Edge-кейсы и негативные тесты

---

## 4.1 — Идемпотентность (повторное сообщение)

🔵 **1С отправляет** тот же `message_id` из теста 1.6 с другой ценой.

- [ ] Цена **НЕ** обновлена (исходная сохранена)
- [ ] В логах: «сообщение уже обработано»
- [ ] Сообщение удалено из очереди без ошибок

---

## 4.2 — Невалидный JSON

🔵 **1С отправляет** сломанный JSON: `{event: broken`

- [ ] В логах: «невалидный JSON»
- [ ] Сообщение удалено из очереди
- [ ] Другие сообщения **продолжают** обрабатываться

---

## 4.3 — Несуществующий UUID товара в `price.updated`

🔵 `price.updated` с `product_uuid: "non-existent-uuid"`.

- [ ] Событие проигнорировано
- [ ] Предупреждение в логах
- [ ] Другие сообщения не заблокированы

---

## 4.4 — Несуществующий UUID склада в `stock.updated`

🔵 `stock.updated` с `warehouse_uuid: "non-existent-uuid"`.

- [ ] Событие проигнорировано
- [ ] Остатки не изменились
- [ ] Предупреждение в логах

---

## 4.5 — Дочерняя категория раньше родительской

🔵 `category.created` с `parent_uuid`, для которого родитель ещё не заведён.

- [ ] Определить поведение: создана без родителя? DLQ? Отклонена?
- [ ] Зафиксировать фактическое поведение

---

## 4.6 — Валидация payload по JSON Schema

🔵 `partner.created` без обязательного поля `event`.

- [ ] Сообщение отклонено валидатором
- [ ] Запись в `erp_validation_errors`
- [ ] Другие сообщения продолжают обрабатываться
