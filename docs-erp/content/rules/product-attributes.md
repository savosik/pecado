# Атрибуты товаров

**Область:** Карточка номенклатуры в 1С

> Источник: митинг 07.04.2026

## Форматы значений атрибутов (Типизация)

Согласно спецификации обмена, атрибуты товаров (`value_type`) поддерживают строго типизированные значения:
- `string` — текстовое значение (по умолчанию)
- `number` — числовое значение
- `boolean` — булево значение (`true`/`false`)
- `reference` — ссылка на значение справочника (сохраняется внешний ID значения)
- **(v12.4)** `date-time` — дата и время в формате ISO 8601 (например, `2026-04-15T12:00:00Z`). Значение сохраняется в отдельную колонку `datetime_value` для корректной сортировки и фильтрации на сайте.

## Атрибуты

| Атрибут | Тип | Описание | Реализация |
|---|---|---|---|
| **Категория маржинальности** | Перечисление | Импорт / РФ / СТМ / Тюмень / Фикс | Реквизит номенклатуры |
| **Коэффициент наценки** | Число(5,2) | Множитель цены поставщика → цена продажи | Реквизит номенклатуры |
| **Снять с продажи** | Булево | Товар больше не закупается (аналог архива) | Реквизит номенклатуры |
| **Скрыть в интернете** | Булево | Не выгружать + не показывать на сайте | Поле `hidden` в обмене |

## Механизм «Новинка»

Галочка «Новинка» **не используется**. Вместо этого:

1. Создаётся **маркетинговое мероприятие** с типом «Новинка»
2. Включаются нужные товары
3. Устанавливается дата окончания
4. **Регламентное задание** (ежедневно) снимает флаг по истечении даты

## Критерии приёмки

- [ ] В карточке добавлены 4 реквизита
- [ ] «Скрыть в интернете» — **один флаг** (не два)
- [ ] `hidden = true` → товар не выгружается
- [ ] «Новинка» через маркетинговые мероприятия с датой окончания
- [ ] Тестеры: цена 1 руб. + `hidden = true`
