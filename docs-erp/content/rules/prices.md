# Цены

> **JSON Schema:** [`price.updated.json`](/docs/erp/schemas/price.updated.json) | [`exchange_rate.updated.json`](/docs/erp/schemas/exchange_rate.updated.json)  
> **AsyncAPI:** [Полная спецификация](/docs/erp/spec.yaml)

## Базовые цены (price.updated)

**Направление:** 1С → Сайт | **Очередь:** `erp_in.prices`

### Бизнес-правила

- Выгрузка цен использует вид цен из `ОсновнойВидЦен` настроек
- Если товар с UUID не найден — событие игнорируется
- Сайт **не** отправляет обновления цен в 1С

### Критерии приёмки

- [ ] Сайт принимает `price.updated` и обновляет цену товара по UUID
- [ ] Если товар не найден — событие игнорируется без ошибок

---

## Курсы валют (exchange_rate.updated)

**Направление:** 1С → Сайт | **Очередь:** `erp_in.prices`

### Бизнес-правила

- Все цены хранятся в базовой валюте (`RUB`)
- Сайт **не** обновляет курсы из сторонних источников — только из 1С
- `ВыгрузитьВсеКурсыВалют` выгружает **все валюты** из справочника

### Критерии приёмки

- [ ] Сайт сохраняет все три значения: `official_rate`, `rate_coefficient`, `rate`
- [ ] Курсы обновляются только через 1С
