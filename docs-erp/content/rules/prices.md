# Цены

## Базовые цены (price.updated)

**Направление:** 1С → Сайт | **Очередь:** `erp_in.prices`

### Бизнес-правила

- Выгрузка цен использует вид цен из `ОсновнойВидЦен` настроек
- Если товар с UUID не найден — событие игнорируется
- Сайт **не** отправляет обновления цен в 1С
- **Базовая цена карточки на сайте живёт только из `price.updated`.** `product.created` заводит товар с нулевой базовой ценой и никогда её не меняет. Пока по товару не пришёл ни один `price.updated`, базовая цена на сайте — 0, даже если в 1С цена назначена. Продаваться товар при этом может: клиентская цена приезжает отдельным каналом (см. [Индивидуальные цены](individual-prices.md)). Последствие для заказов — см. [Заказы → order.created](orders.md): сайт подставляет `base_price = final_price`, чтобы строка документа не встала нулём

#### ⚠️ Цена присылается агрегатом, без разреза по организациям

**Требование контракта** (зафиксировано в v15.8.0, подтверждено стороной 1С).

Сообщение `price.updated` содержит одну — лучшую — цену товара. Раздельные цены
по нашим организациям на один товар **не передаются**: сайт хранит одну цену на товар
и перезаписывает её каждым сообщением, поэтому второе значение молча затёрло бы первое.

Разрез по организациям существует только в документах и взаиморасчётах, см.
[Организации](organizations.md). То же требование для остатков — см.
[Остатки](stocks.md).

### Критерии приёмки

- [ ] Сайт принимает `price.updated` и обновляет цену товара по UUID
- [ ] Если товар не найден — событие игнорируется без ошибок
- [ ] По каждому товару, которому в 1С назначена цена, `price.updated` приходит хотя бы один раз — иначе базовая цена на сайте останется нулевой

## Курсы валют (exchange_rate.updated)

**Направление:** 1С → Сайт | **Очередь:** `erp_in.prices`

### Бизнес-правила

- Все цены хранятся в базовой валюте (`RUB`)
- Сайт **не** обновляет курсы из сторонних источников — только из 1С
- `ВыгрузитьВсеКурсыВалют` выгружает **все валюты** из справочника

### Критерии приёмки

- [ ] Сайт сохраняет все три значения: `official_rate`, `rate_coefficient`, `rate`
- [ ] Курсы обновляются только через 1С
