# Индивидуальные цены

> **JSON Schema:** [`individual_prices.ready.json`](/docs/erp/schemas/individual_prices.ready.json)  
> **AsyncAPI:** [Полная спецификация](/docs/erp/spec.yaml)

**Направление:** 1С → Сайт | **Транспорт:** MinIO (S3) + RabbitMQ  
**Очередь:** `erp_in.prices` | **Routing key:** `individual_prices.ready`

## Масштаб данных

- Товаров: ~10 000, Складов: ~5, Партнёров: ~800
- **Итого:** до **40 000 000** уникальных цен
- Передача поштучно через RabbitMQ невозможна — модель «Файл + Уведомление»

## Бизнес-правила

- **Один файл = один партнёр.** 1С формирует отдельный CSV на каждого партнёра
- Формат CSV: `product_uuid,warehouse_uuid,price` (без заголовка)
- CSV загружается в MinIO (бакет `prices-exchange`)
- После загрузки 1С отправляет `individual_prices.ready`

### Стратегия выгрузки

| Тип | Расписание | `upload_type` | Поведение на сайте |
|---|---|---|---|
| **Дельта** | Каждые 15–30 мин | `delta` | UPSERT (обновляет только пришедшие цены) |
| **Полная** | Ежедневно 03:00 | `full` | DELETE + INSERT (полная замена) |

### Оптимизация (v9)

- Дельта пересчитывает **только затронутые товары**
- Умная маршрутизация очереди по типу изменения
- Батчевая `ПолучитьКартуСегментов()` вместо N+1 запросов
- Регистр `ОчередьВыгрузкиИндивидуальныхЦенPecado` с измерением `Номенклатура`

## Критерии приёмки

- [ ] 1С формирует CSV на каждого партнёра и загружает в MinIO
- [ ] `individual_prices.ready` отправляется через `erp.events`
- [ ] **full:** DELETE + INSERT. **delta:** UPSERT
- [ ] Каталог отдаёт индивидуальную цену авторизованного пользователя
- [ ] CSV файл удаляется из MinIO после обработки
