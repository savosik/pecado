## Наименования партнёров (496 записей)

| Правило | Решение | Действие |
|---|---|---|
| «Закрыт/Закрылся» → пометка удаления (64) | **Отклонено.** Удалить слово из наименования. Новый реквизит «Статус клиента» = «Закрылся» | Скрипт обновления |
| Город в наименовании (472) | Удалить город, **НЕ** добавлять в комментарий. Заполнить «Бизнес-регион» | Скрипт очистки |
| Двойные пробелы (13) | Принято | Скрипт очистки |
| Пробелы в начале строки (1) | Принято | Скрипт очистки |

## Банковские счета (223 записи)

- При заполненном банке — подтянуть БИК/Наименование/КоррСчёт из классификатора
- При невозможности — перенести as-is

## Критерии приёмки

- [ ] Реквизит «Статус клиента» в справочнике «Партнёры»

- [ ] Банковские счета: автозаполнение из классификатора
