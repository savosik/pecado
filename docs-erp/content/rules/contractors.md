# Контрагенты

> **JSON Schema:** [`contractor.created.json`](/docs/erp/schemas/contractor.created.json)  
> **AsyncAPI:** [Полная спецификация](/docs/erp/spec.yaml)

**Направление:** 1С → Сайт | **Очередь:** `erp_in.partners`

## Бизнес-правила

- Пользователь создаёт контрагентов в ЛК сайта — в 1С **ничего не отправляется**
- 1С публикует `contractor.created` для синхронизации из 1С на сайт
- `country` гарантированно не `null` — фолбэк на `СтранаПоУмолчанию`
- Первый банковский счёт имеет `is_primary = true`
- Сопоставление контрагента при заказе — по ИНН (`tax_id`)
- **(v12.7)** Удалены поля `latitude`/`longitude` из контрагента — координаты больше не передаются в рамках заказа

## Критерии приёмки

- [ ] Сайт принимает `contractor.created` и создаёт контрагента с привязкой к партнёру через `partner_uuid`
- [ ] `country` не `null`
- [ ] Банковские счета создаются из `bank_accounts[]`
- [ ] Первый счёт — `is_primary = true`
- [ ] Если контрагент не найден по ИНН при заказе — 1С создаёт нового
