# 2.1 — Регистрация пользователя (`partner.created`)

**Фаза:** 2 — Сайт → 1С
**Статус:** 🔲 backlog
**Зависимости:** нет

## Описание

🟢 **Разработчик сайта** регистрирует нового пользователя (имя, email, телефон).

Сообщение публикуется **в момент регистрации** (событие `UserCreated`), не при активации.

> Структура payload → [JSON Schema](/docs/erp/schemas/partner.created.to_erp.json)

## Чек-лист (1С-ник проверяет)

- [ ] В `erp_out.partners` появилось сообщение сразу после регистрации
- [ ] Payload: `event: "partner.created"`, `uuid`, `login`, `name`, `phone`, `email`, `is_active`, `comment`
- [ ] `uuid` — валидный UUID
- [ ] `login = email`
- [ ] `is_active = false` (новый пользователь на рассмотрении)
- [ ] `comment` содержит URL вида `https://...../preview/user/...` (секретная ссылка на превью)
- [ ] URL из `comment` открывается без авторизации и показывает данные пользователя
- [ ] 1С ищет по email → если не найден — создаёт нового
- [ ] 1С **НЕ** использует `uuid` из payload — генерирует свой
