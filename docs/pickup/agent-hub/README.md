**Статус на 18.09.2026: отложено.** Решение заказчика — объединение делаем отдельным эпиком, не сейчас; топик на проде
не создан. Постановка `topic-ship-together.md` самодостаточна, `create-topic.sh` создаёт топик одной командой, когда
до него дойдёт очередь. Вопрос «кто создаёт расходный ордер вечером» из постановки убран: 1С создаёт ордера сама.

Эпик pick-00 к объединению готов: единица выдачи — расходный ордер на любое число заказов, письмо «собран» одно
на комплект, пропуск и экран склада работают с комплектом целиком.
