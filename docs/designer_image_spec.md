# Спецификация изображений для сайта Pecado

Документ для дизайнера. Описывает размеры, пропорции и требования к изображениям для каждого раздела сайта.

---

## Общие правила

- **Форматы**: WebP (предпочтительно), JPEG, PNG. Для баннеров и историй допустимы GIF, SVG и видео (MP4, WebM).
- **Цветовое пространство**: sRGB.
- **Все изображения обрезаются по центру** (CSS `object-fit: cover`), кроме слайдов Историй в полноэкранном режиме — они показываются целиком.
- **Важный контент (текст, лица, продукт) размещать по центру** с отступом от краёв — края могут обрезаться на разных экранах.

Два обязательных изображения. **Это самые заметные элементы сайта.**

| Назначение | Размер (px) | Пропорция | Макс. вес |
|---|---|---|---|
| **Desktop-баннер** | **2560 × 930** | 11:4 | 10 МБ |
| **Mobile-баннер** | **1280 × 720** | 16:9 | 10 МБ |

### Важно о баннерах

- Desktop и mobile — это **две разные картинки** с разной композицией.
- На мобильном показывается **только** mobile-версия, на десктопе — **только** desktop.
- Desktop-баннер: на узких экранах высота уменьшается с 460px до 200px, боковые части обрезаются → **весь важный контент строго по центру**.

## 5. Истории (Stories)

Одно изображение или видео на каждый слайд.

| Назначение | Размер (px) | Пропорция | Макс. вес |
|---|---|---|---|
| **Слайд истории** | **1080 × 1920** | 9:16 (вертикальная) | 20 МБ |

### Особенности

- Формат как в **Instagram Stories** — вертикальный.
- Превью на главной — маленькая прямоугольная карточка (143:255 ≈ 9:16), обрезается.
- В полноэкранном режиме изображение показывается **целиком** (не обрезается) на чёрном фоне.
- На десктопе в полноэкранном режиме вертикальная картинка будет с чёрными полями по бокам — это нормально.
- Внизу слайда накладывается название истории — **не размещайте текст в нижних ~200px**.
- Поддерживается **видео**: MP4, WebM (до 20 МБ).

### Безопасная зона — слайд

│                     │
│  ┌───────────────┐  │

│  │  ЗОНА         │  │
│  │  900 × 1400   │  │
│  │               │  │
│  └───────────────┘  │
│                     │
