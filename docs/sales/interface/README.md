# Макеты интерфейса

Кликабельные макеты рабочих мест в системе оплаты «за рост». Открывать [index.html](index.html) — оттуда ссылки на оба рабочих места.

| Файл | Что это |
|---|---|
| `index.html` | Обложка со ссылками и памяткой, на что смотреть при оценке |
| `menedzher.html` | Рабочее место менеджера, 11 экранов: ежедневные списки, недельные, справочные (база и свободные клиенты) и денежные (расчётный лист, обоснование плана, квартальная премия) |
| `rop.html` | Рабочее место руководителя, 7 экранов (формы B1–B7) |

Каждый файл самодостаточен: разметка, стили и данные внутри, внешних зависимостей нет (шрифт подгружается из сети, при его отсутствии подставляется системный). Открываются двойным кликом в браузере, переключение экранов — по меню слева.

**Данные вымышленные**, но масштаб взят из фактического августа 2026: планы 6,7 и 4,96 млн ₽, просрочка 1,88 и 0,82 млн ₽, доля крупнейшего клиента у Курочкиной 57 %, 173 ничейных клиента в пуле.

**Назначение** — проверить до разработки: хватает ли данных для принятия решения на каждом экране, видна ли цена бездействия в рублях, заканчивается ли каждая строка действием и нет ли лишнего. Часть колонок требует данных, которых сейчас в учёте нет — см. «Требования к данным» в `../formy-otchetov-i-raschetov.md`.
