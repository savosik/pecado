# BPMN-диаграммы отдела продаж

Две диаграммы, описывающие логику работы в рамках системы оплаты труда (см. `../polozhenie-ob-oplate-truda.md`).

| Диаграмма | Файлы | О чём |
|---|---|---|
| **Рабочий цикл менеджера** | [.pdf](rabochiy-cikl-menedzhera.pdf) · [.svg](rabochiy-cikl-menedzhera.svg) · [.bpmn](rabochiy-cikl-menedzhera.bpmn) | Ежедневный цикл: проверка положения к плану, приоритет работы, долги, контакты, фиксация. Ветвления: понедельник (недельный блок) и число месяца (расчётный лист, дожим) |
| **Решения руководителя** | [.pdf](resheniya-rukovoditelya.pdf) · [.svg](resheniya-rukovoditelya.svg) · [.bpmn](resheniya-rukovoditelya.bpmn) | Ежемесячный цикл: кран новых клиентов, концентрация базы, охват, раздача пула, сроки, утверждение ведомости, квартальные решения |

## Форматы

- **`.bpmn`** — BPMN 2.0 XML с координатами. Открывается в Camunda Modeler, [bpmn.io](https://demo.bpmn.io), draw.io. Редактируйте здесь, если нужно изменить логику.
- **`.svg`** — векторная картинка для вставки в презентации и документы.
- **`.pdf`** — для печати, лист A3.

## Пересборка

Диаграммы генерируются из описания в коде — это гарантирует, что XML и картинка не разойдутся:

```bash
python3 build.py    # рабочий цикл менеджера
python3 build2.py   # решения руководителя
```

`gen.py` — генератор: принимает узлы и связи с координатами, выдаёт SVG и BPMN 2.0 XML.
Пути вывода прописаны в `build*.py`. После генерации SVG в PDF переводится headless-браузером:

```bash
google-chrome --headless=new --print-to-pdf=имя.pdf file:///путь/к/обёртке.html
```

## Обозначения

- **Круг тонкой линией** — начало процесса, **круг жирной линией** — конец.
- **Прямоугольник** — действие.
- **Ромб с крестом** — исключающее ветвление: идёт ровно одна ветка. Ромб без подписи — точка слияния веток.
- Подпись слева от ромба — условие, подпись у стрелки — ответ.
