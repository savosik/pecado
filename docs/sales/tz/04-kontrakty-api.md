# 04. Контракты данных

## Назначение

Что именно сервер отдаёт каждому экрану: маршрут, право, параметры, структура ответа, объём строк
и способ обновления.

## Область

Входит: серверные контракты экранов раздела. Не входит: внутреннее устройство сервисов и формулы.

## Основания

Экраны — разделы [05](05-ux-menedzher.md) и [06](06-ux-rop.md); объёмы —
[профиль данных](prilozhenie-profil-dannyh.md); конвенции — действующий раздел зарплаты
(`routes/crm.php`, `app/Http/Controllers/Crm/Salary*`).

## Общие правила

1. **Страница получает первый снимок вместе с разметкой**, дальнейшие обновления — отдельным
   запросом, отдающим тот же по структуре ответ. Две ветки кода на одну страницу не заводятся.
2. **Всё считает сервер.** Производные величины («что это стоит вам», «даст вам», «до зачёта»)
   приходят готовыми. Клиент не умножает суммы на ставки.
3. **Каждая расчётная величина сопровождается объяснением** — текстом с подставленными числами
   этого периода, и по возможности перечнем строк, из которых сложилась.
4. **Списки — серверная сортировка и пагинация.** Параметры сортировки и фильтров живут в адресе
   страницы; смена фильтра сбрасывает страницу на первую.
5. **Утверждённый период отдаётся из снимка**, а не пересчитывается. Ответ содержит признак
   заморозки и дату утверждения.
6. **Денежные величины** передаются числами в рублях с двумя знаками; проценты и доли — долями
   единицы; даты — в формате «год-месяц-день».
7. **Ошибки** отдаются с человекочитаемым сообщением на русском: оно показывается пользователю
   как есть.

## 3. Списки партнёров

Единый контракт для «Моей базы», «Кто выпал из ритма», «Кого разбудить», «Свободных клиентов».
Отличаются набором колонок и отбором, но не структурой.

**Параметры:** `month`, `filter`, `sort`, `direction`, `page`, `per_page`, `search`.

```json
{
  "month": "2026-08-01",
  "summary": { "total": 113, "active": 33, "silent": 80, "never_bought": 58 },
  "rows": {
    "data": [
      { "id": 17, "name": "ООО «Гевея»",
        "usual_monthly": 890000.00,
        "current_month": 1093000.00,
        "best_month": { "amount": 1420000.00, "period": "2025-11" },
        "potential": 327000.00,
        "your_gain": 6213.00,
        "assortment": { "taken": 7, "total": 12 },
        "last_purchase_on": "2026-08-29",
        "silent_days": 10,
        "cycle_days": 14,
        "debt": { "amount": 561000.00, "overdue": true, "days": 34 },
        "in_novelty": false }
    ],
    "current_page": 1, "per_page": 50, "total": 113, "last_page": 3
  },
  "sort": { "column": "potential", "direction": "desc" },
  "hint": "Потенциал — разница между лучшим месяцем партнёра и его нынешней закупкой."

```

`your_gain` считает сервер по действующей ставке. При изменении ставки в приказе величина меняется
без правки клиента.

**Объёмы:** «Моя база» 113 и 103; «Кто выпал из ритма» 9 и 17 при включённых фильтрах, до 80 без них;
«Кого разбудить» от 0 до 9; «Свободные клиенты» 618 с фильтром по умолчанию «есть история покупок».

## 4. «Долги»

Двухуровневый ответ: партнёры, накладные внутри.

```json
{
  "month": "2026-08-01",
  "summary": { "overdue_total": 2976000.00, "daily_cost": 1488.00, "deducted_this_month": 27098.00,
               "needs_review_count": 196 },
  "partners": [
    { "id": 17, "name": "ООО «Гевея»",
      "debt": 561000.00, "oldest_days": 34, "daily_cost": 280.50,
      "deducted_this_month": 8420.00, "debt_level": "overdue",
      "promised_on": "2026-09-15",
      "invoices": [
        { "id": 9912, "number": "РН-004512", "date": "2026-07-02",
          "amount": 168000.00, "due_on": "2026-07-16", "overdue_days": 34,
          "daily_cost": 84.00, "settled_on": null, "needs_review": false }
      ] }
  ]

```

Накладные внутри партнёра отдаются сразу: их не более двадцати на партнёра. Общий объём —

`deducted_this_month` в сумме по партнёрам равно показателю К1 в расчёте — это инвариант,
проверяемый тестом.

### Предпросмотр эффекта

**Запрос:** изменённые значения и месяц, на котором считать.

```json
{ "month": "2026-08-01", "values": { "rate_overdue": 0.0002 } }
```

**Ответ:**

```json
{
  "month": "2026-08-01",
  "rows": [
    { "manager_id": 1, "name": "Сухов Иван",
      "current": 137982.90, "projected": 154241.70, "delta": 16258.80 },
    { "manager_id": 2, "name": "Курочкина Елена Валерьевна",
      "current": 88533.32, "projected": 103471.52, "delta": 14938.20 }
  ],
  "payroll": { "current": 226516.22, "projected": 257713.22, "delta": 31197.00 },
  "warnings": []
}
```

Считает тот же серверный калькулятор на фактических входах месяца. Изменения не сохраняются.

### Издание приказа

Запрос содержит полный набор значений, дату начала действия, номер и дату приказа, комментарий.
Ответ — созданный приказ либо перечень нарушенных правил проверки с человекочитаемыми
формулировками. Если период начала действия перекрывает утверждённые расчёты, ответ содержит
предупреждение с их перечнем, но операцию не блокирует.

## 8. Калькулятор

**Запрос:** месяц и гипотетические значения — отгрузки базы, отгрузки новым, отгрузки перечня,
база начисления вычета.
**Ответ:** та же структура, что у «Моего месяца», плюс разница с фактическим расчётом.

Ползунки инициализируются фактическими значениями месяца. При работе с прошлым месяцем расчёт
ведётся по параметрам того периода, а не текущим.

## 9. Объёмы и производительность

| Ответ | Строк | Замечание |
|---|---|---|
| «Мой месяц» | фиксировано | перечни строк — отдельным запросом |
| «Моя база» | 113 | пагинация 50 |
| «Кто выпал из ритма» | 9–80 | пагинация 50 |
| «Долги» | 16 партнёров, 198 накладных | двухуровневый ответ целиком |
| «Свободные клиенты» | 618 | пагинация 50 обязательна |
| Фокус-перечень | 83 позиции | целиком |
| Очередь разметки | 240 | пагинация 50 |
| Сводка отдела | 2 | целиком |

Тяжёлых ответов нет. Единственное место, требующее внимания, — помесячная выборка отгрузок
по позициям перечня: 45 946 строк отгрузок за восемь месяцев, соединение с товарами. При
измеримом замедлении показатель материализуется помесячно.
