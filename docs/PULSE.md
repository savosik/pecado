# Laravel Pulse — мониторинг производительности

## Что это и зачем

Laravel Pulse — дашборд для мониторинга производительности приложения в реальном времени. Показывает:

- нагрузку CPU и потребление памяти сервера
- медленные SQL-запросы (отслеживаются обе БД: `mysql` и `prices`)
- медленные HTTP-запросы и исходящие запросы
- медленные jobs в очередях
- количество и типы исключений
- активность пользователей (запросы и jobs по пользователям)

## Конфигурация

Конфиг: `config/pulse.php`

| Параметр | Значение |
|----------|----------|
| Порог медленного запроса | 1000 мс |
| Отслеживаемые БД | `mysql`, `prices` |
| Хранение данных | 7 дней |
| Игнорируемые таблицы | `pulse_*`, `telescope_*` |

---

## Инфраструктура

Pulse работает через постоянный фоновый процесс под управлением Supervisor:

```
docker/supervisor/conf.d/pulse.conf
```

Процесс: `php artisan pulse:check` — агрегирует метрики и записывает их в БД.

---

## Переменные окружения

```env
PULSE_ENABLED=true
PULSE_PATH=pulse
```

Полный список переменных: `config/pulse.php` (все параметры переопределяются через `.env`).
