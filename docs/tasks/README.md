# Канбан на папках

Управление задачами через файловую структуру. Каждая задача — отдельный `.md` файл.  
Перемещение задачи между этапами = перемещение файла между папками.

## Структура

```
docs/tasks/
├── backlog/        ← Идеи, не приоритизированные задачи
├── todo/           ← Запланировано, следующее к выполнению
├── in-progress/    ← В работе
├── review/         ← На проверке / ревью
└── done/           ← Завершено
```

## Формат файла задачи

Имя файла: `YYYY-MM-DD_краткое-описание.md`

```markdown
# Краткое описание задачи

**Приоритет:** высокий | средний | низкий
**Исполнитель:** Имя
**Создано:** 2026-04-15

## Описание

Что нужно сделать.

## Критерии готовности

- [ ] Критерий 1
- [ ] Критерий 2
```

## Перемещение

```bash
# Взять в работу
mv docs/tasks/todo/задача.md docs/tasks/in-progress/

# На ревью
mv docs/tasks/in-progress/задача.md docs/tasks/review/

# Готово
mv docs/tasks/review/задача.md docs/tasks/done/
```
