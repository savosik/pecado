# sub-05: письма клиенту и механика дожима

**Приоритет:** высокий
**Эпик:** [sub-00](2026-08-14_sub-00-epic.md)
**Зависит от:** sub-02, sub-04 (ссылка ведёт на страницу)
**Создано:** 2026-08-14

## Описание

### Письмо-извинение (главное)

Паттерн back-in-stock офферов: система готовит **черновик**, менеджер правит и
отправляет из карточки (sub-03). Волна 1 — автоотправки нет вообще.

- **От имени персонального менеджера** клиента (имя, подпись, контакты) — не noreply.
  Шаблон через `CrmEmailTemplate`, переменные: имя контакта, номер заказа, строки
  недобора, дата прихода (если слой 0), ссылка на подборку.
- Тон: извинение + конкретика («не прошли контроль качества при сборке»),
  без канцелярита.
- Отправка фиксируется в `CrmEmail` (история переписки клиента уже там).
- Если включены подписки на изменения заказов (`MAIL_FEATURE_ENTITY_SUBSCRIPTIONS`) —
  блок «подобрана замена» добавляется и в их письмо, но письмо-извинение первично:
  уходит и неподписанным.

### Дожим (планировщик, без участия менеджера)

| Условие | Действие |
|---|---|
| `sent` + 24 ч, не открыто | Автонапоминание клиенту (одно, вежливое) |
| `viewed` + 48 ч, не согласовано | `CrmTask` менеджеру «позвонить по недобору» |
| `expires_at` наступил | Оффер → `expired`, финальная задача менеджеру: продлить / закрыть |

Открытие/согласование между тиками отменяет соответствующие шаги.
Напоминание — строго одно: оптовик не должен получать капельную рассылку.

### Уведомления менеджеру (тихие)

«Клиент открыл подборку», «Клиент согласовал: создан заказ №…» — нотификация
в CRM, не задача. Информируют, не требуют действий.

## Критерии готовности

- [ ] Черновик генерируется при создании оффера, редактируется и отправляется из карточки
- [ ] Отправитель — персональный менеджер; фолбэк на `MAIL_ORDER_FALLBACK_RECIPIENTS`-логику при его отсутствии
- [ ] Письмо в `CrmEmail`-истории клиента
- [ ] Все три правила дожима работают и отменяются при реакции клиента; напоминание не дублируется
- [ ] Тексты писем на русском, вычитаны; Mailpit-проверка вёрстки
- [ ] Тесты переходов дожима на замороженном времени
