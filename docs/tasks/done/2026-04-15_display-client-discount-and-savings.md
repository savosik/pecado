# Отображение индивидуальной скидки и экономии клиента

**Приоритет:** высокий
**Исполнитель:** -
**Создано:** 2026-04-15
**Выполнено:** 2026-04-17

## Описание

В проекте существует 2 типа цен: базовая цена товара и индивидуальная цена клиента. Необходимо показывать клиенту на сайте размер его скидки и величину экономии. Самая главная фишка - скидка клиента нигде напрямую не хранится, она должна высчитываться на основе разницы между базовой ценой и индивидуальной ценой пользователя. Чрезвычайно важно продемонстрировать пользователю, какую выгоду (сколько он сэкономил) он получает.

## Требования

### Frontend (Корзина, Заказы, Реализации)
Для каждого из разделов: корзина (строки корзины), заказы (строки заказов), реализации (строки реализаций) необходимо:
- [x] Показывать базовую цену позиции.
- [x] Показывать размер скидки пользователя (её нужно высчитывать на основе разницы базовой и индивидуальной цены).
- [x] Показывать индивидуальную цену пользователя.
- [x] Показывать экономию пользователя для визуализации его выгоды. 
- [x] Применить перевод на русский язык для всех созданных надписей в интерфейсе, чтобы соответствовать общему стилю проекта. (Скидка, Ваша выгода, Экономия и т.д.)

### Backend
- [x] Убедиться, что по каждой позиции (в корзине, заказе при сохранении, реализации) передаются данные `base_price` (базовая цена) и `price` (индивидуальная цена), чтобы на фронтенде или бэкенде можно было корректно произвести расчет.

## Критерии готовности

- [x] В деталях позиций (строках) в корзине, в деталях заказа и деталях реализаций (отгрузок) показаны: базовая цена, скидка, индивидуальная цена.
- [x] Пользователь четко видит величину своей экономии ("Ваша выгода").
- [x] Все расчёты происходят динамически на лету опираясь на разницу двух цен.
- [x] Весь интерфейс новых полей полностью на русском языке.

## Реализация

### Backend
- `app/Http/Controllers/User/OrderController.php` — добавлены поля `base_price`, `final_price`, `discount_percent` в ответ по позициям заказа.

### Frontend
- `CartTable.jsx` — добавлен бейдж `-X%` скидки, строка "Экономия: X" по каждой позиции, "Ваша выгода: X" в итогах.
- `Orders/Show.jsx` — базовая цена (зачёркнута), бейдж скидки %, индивидуальная цена, "Экономия" в сумме позиции, "Ваша выгода" в блоке "Итого".
- `Shipments/Show.jsx` — колонки переименованы: "Базовая цена", "Скидка", "Ваша цена"; "Экономия" в итоге позиции; "Ваша выгода" в заголовке отгрузки.
