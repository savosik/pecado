# Рефакторинг формы управления контрагентами в ЛК

**Приоритет:** средний
**Исполнитель:** -
**Создано:** 2026-04-15

## Описание

Форма создания/редактирования компании (контрагента) в личном кабинете пользователя (`resources/js/Pages/User/Cabinet/Companies/Form.jsx`) требует улучшения UX. Сейчас обязательные поля разбросаны по разным вкладкам (Tabs), и не все из них визуально обозначены звездочкой. 

Необходимо переработать форму так, чтобы она была максимально простой, понятной и быстрой для заполнения.

## Текущее состояние
- Используются вкладки: "Данные компании", "Юридические реквизиты", "Банковские реквизиты".
- Обязательными считаются только Название и Страна.
- Нет единообразного обозначения обязательных полей.

## Критерии готовности

- [ ] **Визуальные маркеры:** Добавить `*` ко всем обязательным полям в UI и убедиться, что они корректно подсвечиваются при ошибках валидации.
- [ ] **Реорганизация полей:** 
    - Вынести критически важные поля (ИНН/Tax ID, Юридическое название) на первый план.
    - Сгруппировать поля логически (например, "Основная информация", "Адреса", "Контакты").
- [ ] **Оптимизация структуры (UX):**
    - Избавиться от структуры с табами (Tabs) в пользу одной вертикальной формы с четкими секциями (разделенными заголовками или карточками), чтобы пользователь видел весь объем работы сразу.
    - Для длинных форм обеспечить удобный скролл или компактное расположение (SimpleGrid).
- [ ] **Банковские счета:** Сохранить возможность управления банковскими счетами (сейчас это модальное окно), но интегрировать кнопку управления так, чтобы она была логичным завершением формы.
- [ ] **Валидация:** Проверить и при необходимости расширить клиентскую и серверную валидацию для новых обязательных полей.
