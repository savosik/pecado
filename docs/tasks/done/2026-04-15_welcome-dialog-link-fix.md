# Исправление ссылки в WelcomeDialog (JSON вместо каталога)

**Приоритет:** средний
**Исполнитель:** -
**Создано:** 2026-04-15

## Описание

После прохождения onboarding-анкеты новому пользователю показывается диалог «Добро пожаловать». В этом диалоге есть кнопка «Перейти в каталог» (компонент `WelcomeDialog.jsx`). При нажатии на неё сейчас открывается «сырой» JSON вместо рендера страницы каталога. 

Причина в том, что в компоненте используется ссылка `href="/catalog"`. Маршрут `/catalog` (в `routes/web.php` и контроллере `CatalogController`) предназначен для выдачи JSON API для поиска/фильтрации. Правильная веб-страница каталога находится по адресу `/products` (контроллер `User\ProductController@index`).

## Критерии готовности

- [ ] В компоненте `resources/js/components/common/WelcomeDialog.jsx` ссылка в кнопке изменена с `/catalog` на `/products`.
- [ ] Осуществлен глобальный поиск по проекту на предмет других некорректных ссылок на `/catalog` (вместо `/products`) в React-компонентах и Inertia-ссылках. При обнаружении — исправить.
- [ ] Проверить работоспособность исправленной кнопки (открывается страница каталога с товарами).
