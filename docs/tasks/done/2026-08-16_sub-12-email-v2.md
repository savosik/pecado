## Описание

Главное письмо домена — подборка замен — собирается `sprintf`-ом прямо в
`ShortageEmailDraftService::render()`: голый HTML без шапки, стилей и подписи
бренда, у кандидатов только имя и цена. При этом три письма домена рендерятся
тремя разными механиками (sprintf в сервисе / `MailMessage` / blade).

### Шаблон

- Blade-шаблон письма-подборки в общем фирменном layout (шапка, подпись
  персонального менеджера, контакты) — по образцу
  `mail/substitutions/purchasing-report.blade.php`.
- Блок отменённой строки: фото, название, «отменено N шт».
- Блок кандидата: фото, название, **причина подбора** (принцип эпика: «замена
  без объяснения не продаётся»), бейдж «уценка» с описанием дефекта,
  индивидуальная цена клиента, кнопка/ссылка на страницу выбора.
- Тема и тексты согласовать с заказчиком до вёрстки (сейчас: «Заказ N: часть
  позиций не прошла контроль при сборке» — заказчик утверждает формулировки).
- Поддержка `CrmEmailTemplate` сохраняется: плейсхолдеры работают поверх нового
  рендера; блок `lines` наполняется новой вёрсткой.

### Механика

- `render()` уходит из сервиса в blade; сервис готовит данные.
- Привести письма домена (`SubstitutionReminderNotification` — напоминание)
  к тому же визуальному шаблону.
- Проверка в Mailpit на dev: десктоп + мобильный клиент, картинки с прода.

## Критерии готовности

- [ ] Письмо-подборка рендерится blade-шаблоном в фирменном layout; sprintf-HTML удалён
- [ ] У кандидатов: фото, причина, бейдж уценки, индивидуальная цена (снапшот-тест HTML)
- [ ] Тема и тексты утверждены заказчиком
- [ ] Напоминание клиенту в том же стиле
- [ ] Существующие тесты домена зелёные; письмо проверено в Mailpit на dev (десктоп/мобилка)
