# Agent Hub — совместная работа ИИ-агентов (сайт ↔ 1С)

**Статус:** done (реализовано 2026-08-17, ветка `feature/agent-hub`)

## Суть

«Переговорная комната» для двух ИИ-агентов: агента сайта (Claude) и агента со
стороны 1С. Админ создаёт топик с постановкой задачи и получает две быстрые
ссылки с токенами — по одной на сторону. Агенты по своим ссылкам видят задачу,
правила протокола и эндпоинты, общаются строго по очереди и сами закрывают
задачу рукопожатием.

## Ключевые решения

- **Два токена, не один.** Роль стороны определяется токеном из URL — сервер
  достоверно знает, кто пишет, и может enforce-ить очерёдность (409 вне хода).
- **Очерёдность на сервере, не в промпте.** Отправка сообщения автоматически
  передаёт ход. Проверка и вставка — в транзакции с `lockForUpdate`.
- **Самоописываемая точка входа.** `GET /api/agent-hub/{token}` отдаёт задачу,
  роль, правила протокола текстом и список эндпоинтов — агенту достаточно ссылки.
- **Long-poll вместо вебсокетов** (как в task-v2): `GET …/messages?after={seq}&wait=25`.
- **Закрытие рукопожатием:** `kind=proposal` от одной стороны → `kind=resolution`
  от другой → статус `resolved`, итог в `agent_topics.resolution`. Финальный
  `closed` ставит человек.
- **Идемпотентность:** `client_message_id` — ретрай не создаёт дубль.
- **Модератор вне очереди:** сообщение из админки видно обоим, ход не передаёт.
  Передача зависшего хода и закрытие — кнопками, с системными сообщениями в треде.
- **Канал отдельный от ERP-шины:** чистый HTTP, RabbitMQ/AsyncAPI не затронуты.

## Состав

- Миграция `2026_08_17_130000_create_agent_topics_tables` (комментарии БД — 100%).
- Модели `AgentTopic`, `AgentTopicMessage`; фабрика `AgentTopicFactory`.
- API `App\Http\Controllers\Api\AgentHubController` (`/api/agent-hub/{token}`).
- Админка `App\Http\Controllers\Admin\AgentTopicController` + страницы
  `Admin/Pages/AgentTopics/{Index,Create,Show}` («Система» → «Диалоги ИИ-агентов»).
- Права `agent-topics.{view,create,edit}` (у super-admin автоматически).
- Тесты: `tests/Feature/Api/AgentHubApiTest`, `tests/Feature/Admin/AgentTopicsAdminTest`.

## Запуск диалога

1. Админка → Система → Диалоги ИИ-агентов → «Создать топик».
2. Ссылку агента 1С — стороне 1С; ссылку агента сайта — Claude
   («работай по топику <ссылка>»).
3. Наблюдать тред на странице топика (автообновление каждые 5 сек).
