# note-09 — «Письма» становятся рабочим ящиком

**Эпик:** `note-00`
**Статус:** сделано 2026-08-26
**Зависит от:** `note-04`

## Задача

Заказчик: «раздел письма распилить на рассылки и письма от менеджера»,
«у менеджера в письмах есть самолётик», «навигация неочевидная и скачет».

Проверено: из «Писем» до «Поводов» и «Стоп-листа» **вообще не добраться** —
только через «Правила». У каждой из четырёх страниц свой набор ссылок.

## Что делаем

**«Письма» = только письма менеджера.** Уведомления отфильтрованы (`note-04`).
Список, самолётик, отслеживание открытий.

**Постоянное горизонтальное подменю**, одинаковое на всех страницах раздела,
с подсветкой активного пункта. Не кнопки в шапке, разные на каждой странице.

**Короткий текст «зачем этот раздел»** в каждом разделе — одна-две строки
под заголовком. Заказчик просил прямо.

## Рассылки

Механизма массовых рассылок сегодня нет вовсе (`campaigns` встречается только
в `NotificationSuppression`). Заводим раздел-заглушку с честной надписью,
движок кампаний не изобретаем, пока он не понадобится.

## Проверка

- уведомления не попадают в список писем менеджера;
- подменю одинаково на всех страницах, активный пункт подсвечен;
- каждый раздел имеет пояснение.
