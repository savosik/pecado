# Создание компании через диалог на странице Checkout

**Приоритет:** высокий
**Исполнитель:** -
**Создано:** 2026-04-15

## Описание

В процессе оформления заказа (`/checkout`), если у пользователя еще нет ни одной зарегистрированной компании (контрагента), кнопка «Оформить заказ» заблокирована, и пользователю предлагается обратиться к менеджеру или вернуться в личный кабинет. Это разрывает воронку продаж.

Необходимо добавить возможность создания компании прямо на странице оформления заказа через модальное окно (диалог), чтобы пользователь мог завершить покупку без перехода на другие страницы.

## Критерии готовности

- [ ] **UI Диалога:** На странице `resources/js/Pages/User/Checkout/Index.jsx` добавить кнопку «Добавить компанию» (если их нет или если нужно добавить новую) и модальное окно с формой.
- [ ] **Общая форма:** Использовать упрощенную, но полную версию формы из задачи по рефакторингу (без табов, только необходимые поля).
- [ ] **Обязательные поля:** В форме должны быть обязательными: Название, Страна, Юридическое название, ИНН (Tax ID).
- [ ] **Валидация насквозь:** 
    - Обеспечить проверку уникальности ИНН (Tax ID) по всей базе данных (не только среди компаний текущего пользователя).
    - При попытке ввести существующий ИНН выводить ошибку: "Компания с таким ИНН уже зарегистрирована в системе".
- [ ] **Автовыбор:** После успешного создания компании через диалог, она должна автоматически выбираться в селекторе компаний на странице оформления заказа.
- [ ] **Backend:** Убедиться, что `CompanyController@store` или новый API-метод корректно обрабатывают запрос и возвращают созданную сущность.
