# Временно отключить вход через социальные сети

## Цель
Скрыть кнопки входа через социальные сети на страницах регистрации и авторизации.

## Затронутые файлы

- Форма авторизации (Login)
- Форма регистрации (Register)

## Примечания

- Скрыть UI-элементы (кнопки соцсетей, разделители «или войти через»)
- Бэкенд-роуты Socialite не трогать — только фронтенд
- Задача временная — при возврате достаточно раскомментировать/вернуть JSX
