# Отображение временного пароля в админке для новых пользователей

**Приоритет:** низкий
**Исполнитель:** -
**Создано:** 2026-04-15

## Описание

Для пользователей, созданных через ERP (1C) или вручную, у которых установлен флаг `must_change_password = true`, необходимо отображать их временный пароль в административной панели. Это поможет менеджерам консультировать партнеров, которые не могут войти в систему.

Пароль вычисляется как десятичный CRC32 от email пользователя.

## Критерии готовности

- [x] В модели `User` добавлен метод (илиAccessor) для получения временного пароля: `sprintf('%u', crc32($this->email))`.
- [x] В `app/Http/Controllers/Admin/UserController.php` в метод `edit` (и, возможно, `index`) добавлена передача этого значения в масив данных пользователя, если `must_change_password` истинно.
- [x] В React-компоненте `resources/js/Admin/Pages/Users/Edit.jsx` добавлено информационное поле (alert или текстовый блок), которое показывает временный пароль, если флаг `must_change_password` активен.
- [x] (Опционально) В списке пользователей `resources/js/Admin/Pages/Users/Index.jsx` добавлена иконка или тултип с временным паролем для таких пользователей.
