# Защита от предзаказов «на автомате»: срок, две кнопки, флаг клиента

**Приоритет:** высокий
**Исполнитель:** Claude
**Создано:** 2026-08-29
**Завершено:** 2026-08-29

## Описание

Клиенты набивают количества по прайсу, корзина молча переливает лишнее в
предзаказ-близнец, чекаут одной кнопкой оформляет оба документа. Через день —
«а что у нас был предзаказ? 7–9 дней? удаляйте». По данным на 28.08: 63
предзаказа, 54 — близнецы из чекаута, 33 удалены в 1С (19 — в тот же/следующий
день), 17 клиентов, у 6 повторяется. Срок «7–9 дней» нигде на сайте не был написан.

Требование заказчика: защитить, не усложняя чекаут — число кликов то же.

## Сделано

1. **Срок поставки — данные, не устное знание.** `config/preorder.php`
   (`PREORDER_LEAD_DAYS_MIN/MAX`, умолчание 7–9) → `App\Support\Preorder\PreorderTerms`
   → shared-проп Inertia `preorder.lead_label`. Показан в карточке товара (плитка,
   список, страница), подсказке счётчика, мобильной корзине, итогах корзины,
   чекауте, карточке предзаказа в кабинете, сообщении после оформления.
2. **Чекаут: кнопка называет цифры, рядом — выход в один клик.** С предзаказом
   в корзине primary = «Заказ N шт. + предзаказ M шт.», outline = «Только со склада
   (N шт.)» (`instock_only` → предзаказные строки удаляются, обычный заказ уходит).
   Только предзаказ в корзине → «Оформить предзаказ (M шт.)». Оранжевый блок
   переименован в «Предзаказ — сейчас нет на складе» с объяснением и бейджем срока.
3. **Флаг клиента `users.preorders_enabled`** (умолчание true). Выключенный —
   `StockService::regionWarehouseIds()` отдаёт пустой список предзаказных складов:
   карточка, каталог, поиск, корзина, чекаут, client-API и выгрузки видят только
   наличие, ни один из них не знает о флаге. Переключает клиент в «Моих данных»
   (`PUT /cabinet/profile/preorders`) и менеджер в карточке партнёра
   (`PUT /crm/partners/{id}/preorders`, право `crm-profile.edit`) через
   `ClientLifecycleService::changePreorders`: журнал `crm_client_status_changes`
   (`field = preorders`, автор различим), чистка предзаказных строк из корзин,
   сброс кеша выгрузок.

## Не делали (сознательно)

- Самообслуживаемую отмену предзаказа из кабинета/письма — трогает контракт с 1С
  и отзыв резерва у поставщика; заказчик снял с этого захода.
- Автопроставление флага по истории отмен — решение за менеджером, как и у
  страхового запаса. Кандидаты по данным: Гевея (4/4), Исько (2/2), Елисеев (2/2),
  Третьяков (2/3), Гибадулина (4/14), Степашкин (3/10).
