# Улучшение отображения отгрузок

## Задача

Улучшить отображение отгрузок в личном кабинете пользователя.

## Проблемы

1. **Номер отгрузки** — в списке и детальном виде отгрузок (`/cabinet/shipments`) пользователь видит внутренний ID отгрузки на сайте вместо номера отгрузки из 1С.

2. **Список заказов в деталях отгрузки** — в разделе "Заказы по отгрузке" на странице детального просмотра отгрузки список заказов должен выглядеть идентично списку на странице `/cabinet/orders` (но отфильтрованный только по заказам данной отгрузки).

## Ожидаемое поведение

- В списке отгрузок и на странице `/cabinet/shipments/{id}` отображать номер отгрузки из 1С (поле из ERP), а не внутренний `id` записи в БД сайта.
- Список заказов внутри детальной страницы отгрузки визуально и функционально повторяет компонент списка заказов из `/cabinet/orders`.
