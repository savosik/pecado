# Логирование сообщений RabbitMQ (ERP Bus)

**Приоритет:** высокий
**Исполнитель:** -
**Создано:** 2026-04-15

## Описание

Необходимо реализовать систему логирования всех сообщений, проходящих через RabbitMQ (как входящих из 1С, так и исходящих с сайта), с последующей визуализацией в панели администратора.

## Требования

- [ ] **Модель и БД:** Создать миграцию и модель `ErpBusMessage` для хранения:
    - `direction` (incoming/outgoing)
    - `topic` / `routing_key`
    - `payload` (JSON)
    - `status` (success/failed)
    - `error_message` (если есть)
    - `message_id` (для дедупликации и отслеживания)
    - `created_at`
- [ ] **Логика логирования:**
    - Для входящих: Добавить хук в `app/Queue/Jobs/ErpIncomingJob.php`.
    - Для исходящих: Добавить хук в слушатели `Publish...ToErp`.
    - **Важно:** Логирование должно быть опциональным. Добавить переменную окружения `ERP_BUS_LOGGING_ENABLED=true/false`.
    - В среде `production` по умолчанию выключено.
- [ ] **Admin UI:**
    - Создать страницу `/admin/erp-bus` (на базе текущего стека Inertia/React/Chakra).
    - Список сообщений с фильтрацией по дате, типу и теме.
    - Просмотр деталей сообщения с красивым форматированием JSON (визуальный вьювер).
- [ ] **Оптимизация:**
    - Предусмотреть автоматическую очистку старых логов через Artisan-команду (например, старше 30 дней), чтобы не забивать диск.

## Критерии готовности

- Входящие и исходящие сообщения отображаются в админке.
- Можно посмотреть JSON каждого сообщения.
- Логирование не работает на проде, если явно не включено в `.env`.
