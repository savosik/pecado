# Админка: просмотр soft deleted записей и массовая очистка через очередь

**Приоритет:** средний
**Исполнитель:** -
**Создано:** 2026-04-17

## Описание

В административной панели записи с `soft delete` сейчас недоступны для полноценного контроля. Администратор должен видеть такие записи в списках, отличать их от активных и иметь возможность удалять их окончательно как поштучно, так и массово.

Необходимо добавить в админке отображение `soft deleted` записей и действия для их окончательного удаления. Для массовой очистки нужна отдельная кнопка «Удалить все», которая не выполняет удаление синхронно, а ставит задачу в очередь.

## Критерии готовности

- [x] **Отображение удалённых записей:** В админке показываются записи со статусом `soft deleted`, чтобы администратор мог их просматривать вместе с активными или через отдельный фильтр.
- [x] **Визуальное различие:** Для `soft deleted` записей в интерфейсе есть явное визуальное обозначение, что запись уже помечена на удаление.
- [x] **Поштучное окончательное удаление:** Администратор может выполнить `force delete` отдельной `soft deleted` записи из интерфейса админки.
- [x] **Массовое удаление через очередь:** Кнопка «Удалить все» запускает фоновую задачу на окончательное удаление всех подходящих `soft deleted` записей.
- [x] **Безопасность операции:** Массовое удаление защищено подтверждением действия и не удаляет активные записи.
- [x] **Обратная связь в админке:** После запуска массового удаления администратор получает понятное уведомление, что очистка поставлена в очередь.
- [x] **Покрытие тестами:** Добавлены тесты на отображение `soft deleted` записей, поштучный `force delete` и постановку массовой очистки в очередь.
