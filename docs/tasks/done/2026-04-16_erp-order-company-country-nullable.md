# ERP: Поле country компании — nullable + default RU

**Приоритет:** средний (P1)
**Исполнитель:** -
**Создано:** 2026-04-16

## Описание

1С не передаёт поле `country` компании покупателя в сообщении `order.created`, а колонка `companies.country` в БД объявлена `NOT NULL`. Заказы падают с ошибкой:

```
SQLSTATE[23000]: Column 'country' cannot be null
(SQL: insert into `companies` (`user_id`, `country`, ...) values (?, ?, ...))
```

**Масштаб:** 200 failed-сообщений в очереди.

Это двусторонняя проблема: 1С должна добавить `country` в payload, но до этого исправления нужно сделать поле устойчивым на стороне сайта.

## Требования

- [x] Создать миграцию: сделать `companies.country` nullable или добавить DEFAULT `'RU'`
- [x] В обработчике `order.created` подставлять `'RU'` если `country` не пришло
- [x] Покрыть интеграционным тестом: `order.created` без поля `country` → заказ создаётся, `country = 'RU'`

## Примечание

Отдельно сообщить команде 1С, что поле `country` компании должно передаваться в payload.

## Критерии готовности

- `order.created` без `country` не падает, заказ создаётся с дефолтным значением
- Интеграционный тест проходит
