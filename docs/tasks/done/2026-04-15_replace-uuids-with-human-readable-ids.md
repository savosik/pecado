# Замена UUID на человекочитаемые номера (Заказы и Реализации)

**Приоритет:** средний
**Исполнитель:** -
**Создано:** 2026-04-15

## Описание

UUID (например, `550e8400-e29b...`) не информативны для пользователей и менеджеров. Необходимо заменить их отображение на номер из 1С во всех разделах личного кабинета и панели администратора. UUID продолжает использоваться внутренне для связей — его лишь не нужно показывать в UI.

## Примечания

- `ContractorBalances` — UUID-поля оставить: это технический ввод для связи с 1С, не пользовательский контент.
- UUID продолжает использоваться в backend для поиска и связей — это нормально.

## Критерии готовности

- В личном кабинете пользователя UUID не отображаются нигде.
- В admin-панели во всех карточках заказов, реализаций и возвратов вместо UUID/хэша показывается номер из 1С.
