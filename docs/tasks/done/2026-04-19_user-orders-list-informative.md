# Улучшение списка заказов пользователя

## Цель
Сделать карточки заказов в личном кабинете более информативными и читаемыми.

## Требования к отображению каждого заказа

| Поле | Детали |
|------|--------|
| Номер заказа | Не переносится, фиксированная ширина, моноширинный шрифт |
| Тип | Бейдж «Заказ» / «Предзаказ» |
| Статус | Бейдж с датой последнего обновления (`updated_at`) рядом |
| Компания | Название компании клиента |
| Сумма | Итоговая сумма заказа |
| Кол-во отгрузок | Число отгрузок по заказу (нужно добавить `shipments_count` в контроллер) |
| Комментарий | Комментарий пользователя (одна строка, курсив) |
| Адрес доставки | Адрес (одна строка с иконкой) |

## Затронутые файлы

- `resources/js/Pages/User/Cabinet/Orders/Index.jsx` — вёрстка карточки
- `app/Http/Controllers/User/OrderController.php` — добавить `shipments_count` в маппинг

## Примечания

- Номер заказа не должен сползать при длинных значениях (`whiteSpace="nowrap"`, `flexShrink="0"`)
- Дата обновления статуса — рядом со статусом, небольшим серым текстом
- `shipments_count` — через `withCount('shipments')` на модели
