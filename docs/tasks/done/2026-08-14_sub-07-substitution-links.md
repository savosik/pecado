# sub-07: справочник замен — самообучение и очередь подтверждений

**Приоритет:** средний
**Эпик:** [sub-00](2026-08-14_sub-00-epic.md)
**Зависит от:** sub-06 (и данные волны 1)
**Создано:** 2026-08-14

## Описание

Справочник `product_substitutions` растёт тремя путями и обслуживается
еженедельной 15-минутной рутиной менеджера.

### Источники связей

1. **`manual`** — менеджер добавил кандидата руками в карточке (sub-03).
   Активна сразу (`confirmed_at` = создание).
2. **`learned`** — клиент согласовал замену: слушатель подтверждения оффера
   создаёт/усиливает связь «отменённый товар → выбранный» с `kind` по слою,
   из которого пришёл кандидат. Требует подтверждения менеджером
   (кроме пары, уже подтверждавшейся ранее).
3. **`ai`** — предразметка агентом, строго ограниченная **дефицитным ядром**:
   товары с ≥ 2 недоборами за 90 дней (сегодня это ~14 позиций) и новые товары,
   приземлившиеся в категорию из дефицитного ядра. Никакой массовой разметки
   9 000 карточек. Всегда `confirmed_at = NULL` до решения человека.

### Очередь подтверждений (в /crm/shortages, вкладка «Связи»)

- Список неподтверждённых `learned`/`ai`-связей: пара товаров с фото, ценами,
  остатками, предлагаемый `kind` и `note`; кнопки Подтвердить / Отклонить.
- Отклонение ставит `rejected_at` — пара больше не предлагается автоподбором
  и не создаётся заново (защита от зацикливания).
- Негативные сигналы (`manager_removed` из sub-03, `client_skipped` из sub-04)
  видны в строке — они аргумент против подтверждения.
- Новый товар в дефицитной категории попадает в очередь автоматически
  (слушатель `product.created` по категориям ядра) — это ответ на «связывать
  всегда, когда появился новый товар», без надежды на память людей.

### ИИ-агент (три узкие задачи, не больше)

- нормализация функционального типа (головного слова) — словарь для слоя 4 sub-06;
- генерация `note` — заготовки причины для клиента;
- предразметка пар по дефицитному ядру.

## Критерии готовности

- [ ] `learned`-связь создаётся при согласовании оффера, идемпотентно
- [ ] Очередь подтверждений: подтверждение/отклонение, отклонённые не воскресают
- [ ] Новый товар в дефицитной категории попадает в очередь сам
- [ ] Подтверждённые связи реально всплывают слоем 1 в автоподборе (сквозной тест)
- [ ] Команда предразметки ядра агентом + отчёт что создано, для ручного прогона
- [ ] UI на русском
