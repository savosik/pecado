# Исправить мигание fallback-шрифта при авторизации

## Проблема
После авторизации пользователь видит fallback-шрифт до принудительного обновления страницы (Ctrl+F5). При обычной навигации через Inertia кастомный шрифт не применяется.

## Вероятные причины

- Шрифт подключается через `@font-face` в CSS, но при SPA-переходе Inertia не перезагружает `<head>` — шрифт не переинициализируется
- Либо шрифт загружается асинхронно и `font-display: swap` показывает fallback до загрузки

## Что проверить

1. Как подключён шрифт — через `<link rel="stylesheet">` в `app.blade.php` или через `@import` в CSS/JS
2. Есть ли `font-display: block` / `swap` в `@font-face`
3. Происходит ли проблема только после логина или при любом Inertia-переходе

## Ожидаемое решение

- Шрифт должен быть preload-ован в `<head>` через `<link rel="preload" as="font">`
- Либо принудительно применяться после Inertia-навигации через `router.on('navigate', ...)`

## Затронутые файлы

- `resources/views/app.blade.php` — preload шрифтов
- `resources/css/` или `resources/js/` — подключение `@font-face`
