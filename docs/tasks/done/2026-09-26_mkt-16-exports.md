## Описание

Формат согласован заказчиком: **одна строка на товар**, в ней лучшая цена (та, по которой
этот клиент купит дешевле всего, с НДС) и общий остаток, а дальше отдельные колонки:
цена с НДС 0 / 5 / 20 и остаток с НДС 0 / 5 / 20.

Продавец в выгрузке не раскрывается — разрез идёт по ставкам.
Состав колонок считается по скоупу клиента: чего ему не открыто, того в файле нет.

## Критерии готовности

- [ ] Новый формат в выгрузках каталога и остатков, документирован для клиентов
- [ ] Колонки ставок заполняются из доступных клиенту офферов
- [ ] Существующие потребители (в т. ч. выгрузки для Гевеи) не сломались
- [ ] Выгрузка на боевом объёме укладывается в прежнее окно
