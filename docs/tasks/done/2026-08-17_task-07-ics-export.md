# task-07: экспорт задач в Google/Яндекс Календарь (ICS-фид)

**Приоритет:** средний
**Эпик:** [task-00](2026-08-17_task-00-epic.md)
**Зависит от:** task-01 (соисполнители в фиде), task-03 (переносы двигают события)
**Создано:** 2026-08-17

## Описание

Подписной ICS-фид: менеджер один раз добавляет ссылку в свой Google/Яндекс
Календарь — дальше календарь сам подтягивает изменения. Не разовые .ics-файлы
и не OAuth-синхронизация (границы эпика).

### Фид

`GET /crm/tasks/feed/{token}.ics` — **вне** auth-middleware: внешние календари
ходят без сессии, доступ только по токену.

- Токен — персональный, случайный (64 hex), хранится в новой таблице
  `crm_calendar_tokens` (user_id, token unique, last_fetched_at, timestamps +
  комментарии). `last_fetched_at` обновляется при каждом запросе — видно,
  живая ли подписка.
- Перевыпуск токена в UI инвалидирует старую ссылку (утёкшую ссылку можно отозвать).
- Содержимое: открытые задачи актора (ответственный или соисполнитель) +
  задачи «на контроле», горизонт — от «месяц назад» до «+1 год»; закрытые
  и отменённые из фида пропадают.
- Для РОПа — переключатель «мои / отдел» при генерации ссылки (два разных фида).

### Формат VEVENT

- `UID` стабильный: `crm-task-{id}@pecado.ru` — перенос срока обновляет событие,
  а не плодит копии; `SEQUENCE` = `postponed_count`, `DTSTAMP`/`LAST-MODIFIED`
  из `updated_at`.
- Задача со временем → событие на 30 мин (или `estimate_minutes`, если задана);
  время полуночи считаем «без времени» → событие на весь день (`VALUE=DATE`).
- `SUMMARY` = заголовок (+ префикс «⚠» у высокого приоритета), `DESCRIPTION` =
  описание + ссылка на задачу (`/crm/tasks?task=ID`), `URL` — та же ссылка.
- Даты в `Europe/…` зоне приложения с `VTIMEZONE`-блоком — Google и Яндекс
  одинаково корректно съедают.
- Писать генератор руками (это ~60 строк), пакет типа `spatie/icalendar-generator`
  допустим, если уже совместим со стеком — решить по факту, в спеку не зашивать.

### UI подключения

Диалог «Подписаться в календаре» в разделе задач (иконка календаря в шапке):
готовая ссылка с кнопкой «Скопировать», перевыпуск, краткая инструкция двумя
табами — «Google Календарь» (Настройки → Добавить календарь → По URL) и
«Яндекс Календарь» (Добавить → По ссылке). Показ `last_fetched_at`
(«календарь забирал фид 2 часа назад»).

### Предупреждение в UI

Google обновляет внешние фиды раз в несколько часов (до 24 ч) — написать это в
диалоге честно, иначе будут жалобы «перенёс задачу, а в телефоне старое время».

## Критерии готовности

- [ ] Миграция токенов с комментариями; `bi:sync-grants` прогнан
- [ ] Фид отдаёт валидный ICS (прогнать через валидатор), c VTIMEZONE, стабильными UID и SEQUENCE
- [ ] Перенос срока меняет событие в фиде (тест: SEQUENCE растёт, DTSTART новый)
- [ ] Закрытая задача исчезает из фида; задача соисполнителя и «на контроле» присутствуют
- [ ] Токен перевыпускается, старый отдаёт 404; `last_fetched_at` обновляется
- [ ] Фид РОПа «отдел» отличается от личного
- [ ] Диалог подключения с инструкциями Google/Яндекс и честным дисклеймером про частоту обновления
- [ ] Feature-тесты (авторизация по токену, скоуп, формат); UI на русском; проверка живой подпиской на dev
