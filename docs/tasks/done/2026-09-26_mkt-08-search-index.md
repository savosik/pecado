## Описание

Гостю — одна товарная карточка и никаких продавцов (решение заказчика: SEO не страдает,
продавцы наружу не светятся). Авторизованному — плоская сетка офферов в пределах его скоупа.

Развилка задачи: индексировать товары и раскрывать офферы после выдачи, либо индексировать
офферы и фильтровать по скоупу. Выбрать по замерам: 9 114 товаров против ~3 500 позиций
с остатком сегодня — оба варианта проходят, но релевантность и сортировка «в наличии выше»
ведут себя по-разному.

Помнить про грабли проекта: индекс от старой базы даёт пустую выдачу при живом сервисе
(`flush` + `import`), keyword-first остаётся, семантика — только fallback.

## Критерии готовности

- [ ] Вариант индексации выбран по замерам, обоснование в карточке
- [ ] Гостевая выдача не содержит продавцов и офферов ни в одном поле
- [ ] Скрытый продавец не влияет на выдачу тем, кому не открыт
- [ ] Переиндексация на боевом объёме уложилась в окно, время записано
