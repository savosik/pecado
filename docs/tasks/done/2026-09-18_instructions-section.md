# Раздел «Инструкции» — клиентам, менеджерам (CRM) и складу (WMS)

**Приоритет:** высокий
**Исполнитель:** Claude
**Создано:** 2026-09-18
**Ветка:** `feature/instructions`

## Описание

Заказ РОПа: единый раздел инструкций для трёх аудиторий. Инструкция — заголовок,
краткое описание (о чём она), дата создания и обновления, тело одного из трёх форматов:
текст «красивыми блоками как новости», PDF или видео.

## Что сделано

- **Сущность** `instructions`: `type` (text | pdf | video), `content` (блоки Editor.js),
  `video_url`, флаги `for_clients` / `for_crm` / `for_wms` (одна инструкция — нескольким
  аудиториям), `is_published`; файлы в media — `cover`, `file` (PDF), `video`
  (MP4/WebM/MOV до 50 МБ). Ссылки на ролики: YouTube, Rutube, VK Видео, Vimeo
  (`App\Support\VideoEmbed`), остальное форма отклоняет.
- **Админка** `/admin/instructions` (право `instructions.*`, выдано content-manager):
  реестр с фильтрами по аудитории и формату, форма с переключателем формата,
  галочками аудиторий, редактором блоков, загрузкой PDF/видео/обложки.
  Смена формата стирает тело прежнего формата; снятый файл удаляется.
- **Читалки** без отдельного права, общий трейт `ReadsInstructions`:
  `/cabinet/instructions` (меню «Поддержка»), `/crm/instructions` (группа «Справка»),
  `/wms/instructions` (группа «Справка»). Карточки в стиле новостей с бейджем формата
  и датой «Добавлена / Обновлена», страница с блоками, PDF во фрейме + скачивание,
  видео — встраивание площадки или `<video>`. Компоненты — `resources/js/shared/Instructions/*`.
- Чужая аудитории или скрытая инструкция по id — 404.
