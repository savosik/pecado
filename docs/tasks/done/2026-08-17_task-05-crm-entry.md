# task-05: вход в CRM — просрочено / сегодня / неделя, счётчик в меню

**Приоритет:** средний
**Эпик:** [task-00](2026-08-17_task-00-epic.md)
**Зависит от:** task-03, task-04
**Создано:** 2026-08-17

## Описание

«При входе в CRM показываются просроченные задачи, задачи на сегодня, задачи на
неделю». Решение эпика: **без модальных окон на входе** — блок на дашборде +
постоянный счётчик в меню; «выскакивание» делают тосты (task-08).

### Блок задач на дашборде v2

Сейчас (`DashboardController:90-109`) — топ-8 «сегодня + просрочено» одним списком.
Заменить на три вкладки/колонки: **Просрочено (N) · Сегодня (N) · Неделя (N)** —
списки строк той же компактной разметки, что в разделе (переиспользовать компонент
строки из task-04, не форкать). Действия прямо из строки: закрыть (диалог исходов),
перенести, открыть. Ссылка «Все задачи →» ведёт в раздел с соответствующим
пресетом/фильтром срока.

Для РОПа — переключатель «мои / отдел» (существующий `ScopeToggle`), в режиме
отдела строки показывают ответственного.

### Счётчик в меню

`menuConfig.ts` у пункта «Задачи» получает `counter` (механизм уже есть — у
«Недоборов» работает). Значение — просроченные + сегодняшние актора; красный тон
при наличии просрочки. Эндпоинт каунтера лёгкий (два count-запроса по индексу
`assignee_status_due`), обновляется тем же polling-контуром, что тосты task-08
(до task-08 — при навигации).

### Мелочи входа

- Заголовок блока здоровается по времени суток и сразу говорит главное:
  «3 просроченные задачи» — а не нейтральное «Задачи».
- Пустое состояние честное: «Просрочек нет, на сегодня всё закрыто» — редкий
  повод похвалить.

- [ ] Из строки на дашборде работают закрытие с исходом и перенос
