## Описание

### Страница `/crm/debt` (право `crm-finance.view`)

Рабочий список, не настройки (анти-боинг): клиенты с уровнем ≠ `clean` —
уровень, просрочка, доля от оборота, возраст, активные обещания/диспуты/паузы,
столбец «почему» (тот самый однострочный `reason`). Профили `marketplace`/`legal` —
отдельными строками-сводками для РОП. Фильтры по менеджеру и уровню. Клик —
существующая CRM-карточка клиента, в неё добавляется финансовый блок (уровень,
история переходов, кнопки: платёжка, обещание, пауза, профиль).

### Автозадачи (`CrmTaskService::create`)

| Триггер | Кому | Задача |
|---|---|---|
| Переход в `prepay_only` | персональный менеджер | «Позвонить: клиент переведён на предоплату» + чек-лист |
| Переход в `hold` | менеджер + уведомление РОП | «Стоп-отгрузка: согласовать план погашения» |
| Нарушенное обещание | менеджер | «Обещание не выполнено» (related — promise) |
| Диспут (из debt-08) | менеджер | SLA 2 рабочих дня |
| Пауза истекла без оплаты | поставивший паузу | «Пауза истекла, ограничения вернулись» |

Идемпотентность — паттерн `CrmTaskRecurrenceService`: одна живая задача на
(клиент, триггер), повторный пересчёт не плодит дубли.

### Ручная пауза `debt_overrides` (решение 21.08)

Единственный клиентский оверрайд: «пауза автоматики до даты». Причина обязательна,
бессрочной паузы нет ни у кого: менеджер ≤ 7 дней, РОП ≤ 30. По истечении —
автоснятие + задача. Пауза замораживает эскалацию, но не скрывает клиента со
страницы (виден со значком паузы). Журнал: кто, когда, причина.
