# capi-07: корзины через API

**Приоритет:** средний
**Создано:** 2026-09-16
**Эпик:** capi-00
**Зависимости:** capi-04

## Описание

Секция `carts` (14 операций). `CartService` уже транспортно-независим (22 метода), выносить нужно
только две ветки из `User\CartController`.

| Операция | Сервис |
|---|---|
| `carts.list` GET `carts` | `CartService::getCartsSummary` |
| `carts.get` GET `carts/{cart}` | `CartService::getCartDetails` |
| `carts.create` POST `carts` (I) | `CartService::createCart` |
| `carts.rename` PATCH `carts/{cart}` | `CartService::renameCart` |
| `carts.activate` POST `carts/{cart}/activate` | `CartService::switchActiveCart` |
| `carts.delete` DELETE `carts/{cart}` | `CartService::deleteCart` — корзина не бизнес-документ, удаление допустимо |
| `carts.set-quantity` PUT `carts/{cart}/items` (`identifier`, `quantity`; 0 = удалить) | `ProductIdentifierResolver` + `CartService::setProductQuantity` |
| `carts.set-quantities` PUT `carts/{cart}/items/bulk` (`rows[]`) | `CartService::setProductsQuantity` |
| `carts.add-by-barcode` POST `carts/{cart}/barcode` | **вынести** `CartController::addByBarcode` (~70 строк) → `CartService::addByBarcode`; контроллер на него |
| `carts.import` POST `carts/{cart}/import` (`rows[{identifier, quantity}]`, `mode merge\|replace`) | `OrderImportService::resolve` + `setProductsQuantity`; ответ `resolved/unresolved` |
| `carts.clear` POST `carts/{cart}/clear` | `Cart::clear()` |
| `carts.promotions` GET `carts/{cart}/promotions` | `CartPromotionProgress::forCart` |
| `carts.promo-select` POST `carts/{cart}/promotions/select` (`rule_id`, `reward_index`, `variant`) | **вынести** `CartController::selectPromo/declinePromo/promoRewardIsOptional` → `App\Services\Promotion\CartPromoChoice`; контроллер на него |
| `carts.promo-decline` POST `carts/{cart}/promotions/decline` | то же |

Без `cart` в пути операции работают с активной корзиной (`getOrCreateActiveCart`) — отдельно описать в
документе. Уценка (`addDefect`) в v1 не включается — это отдельный контур закупщика.

## Критерии готовности

- [ ] `ClientApiCartCheckoutTest` (часть корзины): сценарий «создать корзину → импорт строк → задать количества → промо → итоги»; `unresolved` возвращаются с причиной.
- [ ] Чужая корзина → 404 на всех операциях.
- [ ] Кабинетные `CartController::addByBarcode/selectPromo/declinePromo` работают через новые сервисы; `tests/Feature/CartControllerTest.php` зелёный.
- [ ] `make lint` зелёный.
