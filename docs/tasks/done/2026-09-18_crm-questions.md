# Раздел «Вопросы клиентов» в CRM — менеджер видит и отвечает

**Приоритет:** высокий
**Исполнитель:** Claude
**Создано:** 2026-09-18
**Ветка:** `feature/crm-questions`

## Описание

Вопросы менеджеру (форма на `/faq`, кабинет `/cabinet/questions`, клиентский API
`questions.create` и MCP `client-ask-manager`) жили только в админке под правом
`user-questions.*`. Письмо о новом вопросе уходило на адреса из
`MAIL_USER_QUESTION_RECIPIENTS`; строка матрицы `system.question_received` с адресатом
`manager` не срабатывала, потому что домен `system` в потоке писем выключен
(`MAIL_STREAM_SYSTEM=false`). Итог: менеджеры не знали, что партнёры их о чём-то
спрашивают, и ответить не могли — в CRM раздела не было.

## Что сделано

- Право `crm-questions` (`view`, `edit`) — у `sales-manager`, `sales-manager-crm`, `sales-head`;
  три реестра (сидер, `RoleController`, меню) обновлены.
- `/crm/questions` — список с чипами «Ждут ответа / Отвечены / Отклонены / Все», поиском,
  разрезом «только мои / весь отдел» (`UserQuestionCrmQuery`: граница — партнёры менеджера;
  гости и партнёры без менеджера — в разрезе отдела). Карточка `/crm/questions/{id}`:
  открытие переводит «в работу», ответ уходит клиенту письмом, отклонение тихое.
- Пункт «Вопросы клиентов» в группе «Главная» со счётчиком ждущих ответа (`crmCounters.questions`).
- `UserQuestionService::create` шлёт персональному менеджеру клиента
  `NewQuestionAdminNotification` со ссылкой в CRM (уважает «Мои уведомления»,
  `staff.question_received`; без дубля, если менеджер уже в общем списке адресов).
  Ответ/отклонение вынесены в сервис — админка и CRM используют один код.
- Исправлено тело письма матрицы: `$question->question` → `$question->body`.
