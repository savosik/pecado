# ЭПИК: доставка в кабинете и API — трек, расчёт, объединение, самовывоз (dlv-00)

**Приоритет:** средний
**Создано:** 2026-09-16
**Статус:** backlog; заведён из карты «рутина без менеджера» эпика capi-00 (capi-16) по итогам аудита доставок 04.09.2026
**Источники:** `docs/delivery-audit/README.md`, `docs/delivery-audit/survey-notes.md` (п. 5, 6, 7, 11, 12, 13, 17, 19–22, 25–28, 30, 34, 35)

## Идея

Самый частый вопрос клиента менеджеру — «где мой заказ, дайте трек». Данные уже есть в WMS
(`DeliveryShipment`: `carrier_name`, `tracking_url`, `provider_number`, `apiship_status_name`,
`statusHistories`), но клиенту не показываются. Следом — расчёт стоимости и порога бесплатной
доставки, объединение заказов в одну отправку, запись на самовывоз. Целевой процесс — раздел 34
аудита: «самообслуживание кабинета». Порядок внедрения по аудиту: «сначала дёшево и болеутоляюще —
треки и статусы в кабинет».

## Волны

- **dlv-01 Трек и статус доставки клиенту.** Блок `delivery` в карточке реализации и заказа
  (кабинет + `shipments.get` / `orders.get` в API v1 — место зарезервировано в `ClientShipmentPresenter`),
  только отправки после «черновика», без `delivery_cost`, `last_error`, `sender`. Уведомление о смене
  статуса доставки — новый тип в `config/mail_occasions.php`. Решение заказчика 16.09.2026: не в capi-00.
- **dlv-02 Расчёт доставки для корзины.** `checkout.delivery-estimate` (API) и блок в чекауте:
  виртуальная отправка + `DeliveryRateCalculator` (ApiShip), пороги бесплатной доставки
  (Москва 15 000 ₽, регионы 20 000 ₽ — сегодня «только в головах менеджеров») в конфиг.
- **dlv-03 Объединение заказов в отправку («корзина отправки»).** Требует решения 1С по консолидации
  (ERP-протокол, spec-first). Разные юрлица клиента (ООО + ИП) — регулярный случай (п. 28).
- **dlv-04 Самовывоз и курьер клиента.** Слоты, идентификация курьера, «мой курьер заберёт»
  (п. 11, 27); отдельная модель.
- **dlv-05 «Жду предзаказ, не отправляйте частями».** Пометка на заказе и в протоколе 1С
  (ERP/res-00); до неё — `comment` в `orders.create` / `checkout.submit`.

## Критерии готовности (эпик)

- [ ] Клиент видит трек и последний статус доставки в кабинете и в API без обращения к менеджеру.
- [ ] Порог бесплатной доставки и стоимость платной считаются в чекауте и API до оформления.
- [ ] Объединение заказов и самовывоз — по решениям заказчика и 1С, каждая волна отдельной карточкой.
