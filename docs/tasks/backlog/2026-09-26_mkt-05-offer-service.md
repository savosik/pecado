# mkt-05. Чтение предложений для клиента: префильтр, торговое имя, подпись НДС

**Приоритет:** высокий · **Создано:** 2026-09-26 · **Переписано:** 2026-10-03 · **Волна:** 1 · **Эпик:** mkt-00
**Зависит от:** mkt-03, mkt-06
**Оценка (ориентир):** 2 дня чтение + 0,5–1 торговое имя + 1 подпись НДС

## Описание

Один сервис, через который витрина, карточка, фильтры, корзина и оформление спрашивают «какие предложения
этого товара видит этот клиент». Сервис **ничего не считает** — отбирает строки снимка (mkt-03) и готовит
подписи.

- **Отбор**: предложения товара по складам, доступным клиенту (склады региона «в наличии»), сужение
  префильтром партнёра из mkt-06 (организации, склады, ставки, позже бренды по складам); организации,
  не отмеченные как продавец витрины («Реклама», `is_active = 0`), не показываются никому.
- **Порог остатка по складам** (mkt-06): если задан — показанное количество не выше порога. Как это сочетается
  со страховым запасом, который считается по товару, — решить здесь и записать (риск 8 эпика); показанное
  число должно оставаться честным: заказать можно только показанное.
- **Количество** — точное число от 1С, сайт его не меняет (решение 03.10, п. 4).
- **Цена** — прежними каналами (`PriceService`: базовая + файл партнёра), одна, с налогом. В разрезе
  продавца — после ответа 1С (mkt-01); до этого цена предложения = цена товара для клиента.
- **Торговое имя продавца** — поле в `organizations` (миграция с `->comment()`), на витрине, в корзине и письме
  показывается оно; в заказе и документах рядом — юрлицо и ИНН (как кабинет показывает сегодня).
  **Имена не названы — открыто**, до ответа заказчика на витрине показывается то, что есть.
- **Подпись НДС** — текст ставки ровно как прислала 1С («НДС 22 %», «НДС 5 %», «НДС 0 %», «без НДС»),
  у каждого товара везде: плитка, карточка, корзина, заказ. Без разбивки, без тултипа, без «выгоднее
  с вычетом» (снято 03.10).
- Карты для списков, чтобы каталог и корзина не делали N+1.

Клиентский API, выгрузки, WMS и CRM этот сервис **не используют** — они продолжают читать
`product_warehouse` (надстройка).

## Критерии готовности

- [ ] Единственная точка ответа «какие предложения видит клиент»; потребители не читают таблицу предложений
      напрямую
- [ ] Клиенту, которому организация не открыта префильтром, она не видна нигде: ни в плитках, ни в карточке,
      ни в фильтрах, ни в счётчиках
- [ ] Порог остатка применяется к показанному количеству; решение по страховому запасу записано в карточке
- [ ] Миграция: торговое имя организации с комментарием; подпись продавца берётся из него
- [ ] Тексты ставок — из `vat_code` 1С, без арифметики на сайте
- [ ] Тесты: отбор по складам региона и префильтру, порог, пустой набор предложений, организация вне витрины
