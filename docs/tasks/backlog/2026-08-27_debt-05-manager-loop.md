# debt-05: контур менеджера — список «Дебиторка», разблокировка до даты, задачи

## Описание

### Видимость (главная защита от дырявого гейта)

- Бейдж ступени в CRM-карточке клиента и в списке клиентов — менеджер видит
  его **до** того, как заведёт заказ в 1С.
- `/crm/debt` (право `crm-finance.view`): клиенты со ступенью ≠ `clean` —
  ступень, просрочка, возраст, контрагент, активная разблокировка, «почему».
  Фильтр по менеджеру. Отдельный блок РОП: **заказы, заведённые в 1С**
  (`orders.checkout_uuid IS NULL`) клиентам на `no_orders`/`hold` за 30 дней.

### Разблокировка до даты — `debt_pauses`

`user_id`, `company_id` (NULL — весь партнёр), `until`, `reason` (обязательна),
`created_by`, `released_at`. Менеджер ≤ 14 дней, РОП ≤ 30, бессрочной нет.
Действует как «клиент обещал оплатить до …»: гейт снят, ступень остаётся
и видна. Истекла без оплаты — ограничение вернулось само, задача поставившему
«обещание не выполнено». Продление = новая запись; история — в карточке. Разблокировка на партнёра
(`company_id = NULL`) снимает гейт по всем его контрагентам — для Гевеи с её 12 юрлицами
это единственный рабочий вариант.

### Автозадачи (`CrmTaskService::create`, идемпотентно по образцу `CrmTaskRecurrenceService`)

| Переход | Задача |
|---|---|
| → `no_orders` | менеджеру «Позвонить: заказы контрагента закрыты» |
| → `hold` | менеджеру «Подготовить и отправить досудебную претензию» (акт сверки и печатные формы — из существующих разделов; генератора пакета нет) + уведомление РОП |
| пауза истекла | поставившему «Разблокировка истекла, ограничения вернулись» |

## Критерии готовности

- [ ] Миграция `debt_pauses` с комментариями, `bi:sync-grants`
- [ ] Бейдж, `/crm/debt`, блок РОП по заказам из 1С; всё на русском, действия строк по стандарту RowActions
- [ ] Права разблокировки по ролям, автовозврат, задача при истечении — тесты
- [ ] Автозадачи без дублей — тесты
- [ ] Право: переиспользовать `crm-finance.*` (новое не заводить)
