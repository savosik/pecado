# task-06: календарь задач — отдел и отдельный менеджер

**Приоритет:** средний
**Эпик:** [task-00](2026-08-17_task-00-epic.md)
**Зависит от:** task-01, task-03
**Создано:** 2026-08-17

## Описание

Календарный вид задач «как в Google Календаре»: месяц и неделя, весь отдел или
один менеджер. Задача попадает в календарь по `due_at`; задачи без срока в
календаре не живут (для них есть список).

### Страница

`GET /crm/tasks/calendar` → `Crm/Pages/Tasks/Calendar.jsx`, право `crm-tasks.view`.
Вкладка-переключатель «Список | Календарь» в шапке раздела задач (состояние выбора
запоминается в localStorage).

- **Сетка месяца** — по образцу существующего `PaymentCalendarGrid` (платежи):
  без сторонних календарных библиотек. В ячейке дня — до 4 плашек задач + «ещё N»
  (клик — поповер со всеми задачами дня).
- **Режим недели** — 7 колонок, задачи дня списком сверху вниз по времени `due_at`
  (у большинства задач время условное — 08:30 от автоповторов; сортировка по
  времени, без почасовой сетки — она пустует и жрёт экран).
- Плашка: время (если не полночь), заголовок, точка-приоритет, значок контроля.
  Просроченные незакрытые — красным на сегодняшней «линии времени» не размазываем:
  просрочка живёт в своём дне, но плашка красная.
- Клик по плашке — существующий `TaskDialog` (deep-link `?task=ID` уже работает).
- Клик по пустому месту дня — создание задачи с предзаполненным `due_at`.

### Отдел / менеджер

- Переключатель «Мои / Отдел» — существующий `ScopeToggle` (section="tasks").
- В режиме отдела каждому менеджеру — стабильный цвет плашки (палитра по
  `user_id`, легенда сверху); фильтр-мультиселект менеджеров, чтобы смотреть
  одного или сравнить двоих — это и есть «отдельно по менеджеру».
- Учитывать соисполнителей: задача видна в календаре каждого участника.
- Сумма трудоёмкости дня в заголовке ячейки («~5 ч») — перегруз дня виден сразу;
  подсветка, если сумма > 8 ч.

### Перенос перетаскиванием

Drag плашки на другой день = `POST /crm/tasks/{task}/postpone` (механика task-03:
счётчик, системный комментарий). HTML5 DnD без библиотек; на тач-устройствах —
через диалог переноса (DnD не обязателен).

### Данные

Эндпоинт `GET /crm/tasks/calendar-feed?from=&to=` — JSON задач диапазона
(месяц ±1 неделя), только нужные поля; индекс по `due_at` есть в составном —
проверить план запроса, при необходимости добавить отдельный индекс на `due_at`.

## Критерии готовности

- [ ] Месяц и неделя; переключение периодов (← сегодня →) без полной перезагрузки
- [ ] «Мои / Отдел», цвета менеджеров с легендой, мультиселект менеджеров
- [ ] Задачи соисполнителя видны в его календаре
- [ ] Клик по дню создаёт задачу с датой; клик по плашке открывает карточку
- [ ] Drag на другой день = перенос со счётчиком и комментарием (task-03); на тач — диалог
- [ ] Сумма трудоёмкости дня, подсветка перегруза
- [ ] Границы дня/недели — в таймзоне приложения (тест)
- [ ] Feature-тест фида (диапазон, скоуп, права); UI на русском; браузерная проверка на dev
