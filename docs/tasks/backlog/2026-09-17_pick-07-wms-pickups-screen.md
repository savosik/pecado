# pick-07 · Экран склада /wms/pickups: список к выдаче и ручная выдача

**Приоритет:** высокий
**Создано:** 2026-09-17

**Зависимости:** pick-03, pick-06
**Волна:** 1

## Описание

Кладовщик работает с телефона у стойки выдачи. Экран строится от **расходного ордера**, а не от
реализации (существующая вкладка «Самовывоз» в `/wms/delivery-candidates` стартует от реализации,
которая появляется уже по факту отгрузки, и для выдачи не годится).

- `app/Http/Controllers/Wms/PickupController.php` (наследник `WmsController`), маршруты в
  `routes/wms.php` под `permission:wms-pickups.*`, пункт «Выдача заказов» в группе «Отгрузка»
  (`resources/js/Wms/config/menuConfig.ts`).
- `resources/js/Wms/Pages/Pickups/Index.jsx`, mobile-first, карточки вместо таблицы на узком экране:
  - **«Ждут выдачи»** — самовывоз, `shipped`, `status_changed_at >= handover_since`, выдачи нет.
    Группировка по клиенту; в карточке: клиент, юрлицо, номера заказов, номер РО, мест, сколько ждёт.
  - **«Собираются»** — РО в `prepared…to_ship` с таймером от `promisedReadyAt`; просрочка SLA
    подсвечена.
  - **«Выдано сегодня»** — кто, когда, каким способом; действие отмены (право `cancel`).
  - **«Зависшие»** — ждут дольше `pickup.stale_days`; действие «Закрыть без выдачи».
- Поиск по названию клиента, номеру заказа, номеру РО; авто-обновление раз в 30 секунд.
- **Ручная выдача** (запасной путь без пропуска): карточка РО → «Выдать» → диалог с именем
  получателя и комментарием → `HandoverService::issue(method: manual)`. Крупная кнопка, звуковой
  сигнал успеха и ошибки (WebAudio, как в `Cart/BarcodeScanner.jsx`).
- Действия строк — стандарт `RowActions` (глаз открывает карточку РО; доменное «Выдать» — в `extra`
  со своей иконкой). Chakra — только из `@/components/ui/*`.
- Плитка «Ждут выдачи: N / просрочено сборок: M» на рабочем столе склада.

## Критерии готовности

- [ ] Смешанный РО виден с пометкой «часть заказов — доставка»; РО без заказа находится поиском.
- [ ] История до `handover_since` в «Ждут выдачи» не попадает.
- [ ] Экран удобен на 360 px: одна колонка, кнопки не меньше 44 px.
- [ ] Feature-тесты контроллера: права, фильтры вкладок, выдача, отмена.
