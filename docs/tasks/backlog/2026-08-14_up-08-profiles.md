# up-08: профили клиентов — заполнить поля, от которых зависят фильтры

**Приоритет:** средний
**Эпик:** [up-00](2026-08-14_up-00-epic.md)
**Зависит от:** up-03 (менеджеры уже видят, что табу-фильтры работают)
**Создано:** 2026-08-14

## Описание

Сквозные фильтры эпика стоят на полях профиля, которые пустуют:
`order_cycle_days` — 75/184, `taboo_categories` — 0, `novelty_attitude` — 1.
Пустое табу = риск предложить запретное; пустой цикл = дайджест не в такт.

### Расчётные подсказки (система)

- `order_cycle_days`: предложить рассчитанное значение — медиану интервалов
  заказов клиента (паттерн `lifecycle_hint`: система предлагает, человек
  подтверждает). Расчётный цикл всегда приоритетнее заявленного (принцип
  эпика), поле остаётся фолбэком для клиентов без истории.
- `taboo_categories`-кандидаты: клиент за 12+ месяцев ни разу не брал крупную
  ветку каталога, которую берут похожие — это либо табу, либо дыра матрицы;
  разложить может только менеджер, система лишь ставит вопрос.

### Кампания дозаполнения

Расширить существующий `crm:enrich-profiles` (уже дозаполнял город/
периодичность/интересы из документов) полями домена; остаток — задачами
менеджерам порциями: «у 5 твоих клиентов не заполнено табу — спроси при
следующем звонке». Не анкета-простыня, а по одному вопросу к живому контакту.

### Санитария адресации

Разово починить клиентов с «Контент-менеджером» и без персонального менеджера
(двойная работа с sub-02 — сделать один раз, отметить в обеих карточках).

## Критерии готовности

- [ ] Подсказка расчётного цикла в профиле: показ, принять/отклонить
- [ ] Кандидаты в табу — списком в профиле с разметкой менеджером «табу / дыра»
- [ ] `crm:enrich-profiles` расширен; отчёт по покрытию полей до/после
- [ ] Задачи дозаполнения менеджерам генерируются порциями, не разом
- [ ] Покрытие: `order_cycle_days` и табу-разметка ≥ 80 % активных клиентов — числа в карточку ревью
