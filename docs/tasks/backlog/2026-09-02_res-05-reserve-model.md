# res-05 · Модель резерва: статус, срок, отключаемость

## Описание

Фундамент режима резерва на стороне сайта. **Скорректировано по resolution топика №5
(03.09.2026)**: нового статуса НЕ будет — резерв определяется аддитивными полями.

### Признак резерва (вместо статуса)

- Поля `reserve` (bool) и `reserved_until` у заказа (новая миграция, комментарии БД).
  Входящие `order.created`/`order.updated` от 1С несут `reserve`, **фактический**
  `reserved_until` (1С может урезать наш срок до своего предела) и `items_version` —
  все три сохраняются на заказе. Резервные заказы приезжают со статусом
  `ready_for_shipment` — различать ТОЛЬКО по флагу, статусные выборки не трогаем.
- `OrderStatus`/`OrderStatusMapper` не расширяются.

### Срок резерва

- Умолчание срока — конфиг (**24 часа**, решение владельцев обеих сторон 03.09.2026;
  предел удержания на стороне 1С — их настройка, 24 ч от создания заказа);
  индивидуальный срок по партнёру — тем же механизмом отклонений, что и отключение.
  Клиенту показывается фактический `reserved_until`, вернувшийся из 1С.

### Флаг участника режима — мастер 1С

- Входящие `partner.created`/`partner.updated` несут `reserve_allowed` (bool) —
  сохранять на партнёре; radio в чекауте показывается только участникам.
  Точечные отключения сайта — дополнительное сужение поверх флага 1С (сузить можно,
  расширить нельзя).
- **Сверка списков при раскатке**: выгрузить 1С наши 84 партнёра-интернетчика по uuid
  (профиль CRM: `business_type='online'` или `has_online_store`), 1С разметит
  `reserve_allowed` и вернёт фактический состав через `partner.updated`
  (договорённость из resolution, их флаг сейчас у 73 из 1270 — списки не совпадают).

### Отключаемость

- Глобальный рубильник — env-флаг (тихая выкатка, аварийное гашение при инциденте 1С).
- Точечное отключение по партнёру — по принципу «только отклонения от умолчания»
  (как `notification_preferences`): умолчание «включено» в конфиге, в таблице — лишь
  отключения и индивидуальные сроки. Комментарии БД обязательны.
- Рычаг отключения — экран в CRM (карточка партнёра), права по образцу домена `crm-`.
- У партнёра с отключённой опцией: чекаут без radio, раздел резервов скрыт, уже висящие
  резервы доживают штатно (до подтверждения или таймаута).

## Критерии готовности

- [ ] Поля `reserve`/`reserved_until`/`items_version` принимаются из 1С и сохраняются на заказе.
- [ ] `reserve_allowed` принимается из `partner.*` и сохраняется на партнёре.
- [ ] Существующие выборки по статусам не сломаны (прогон полного test suite).
- [ ] Миграции с комментариями БД, `db:comments:audit` чистый.
- [ ] Глобальный флаг и точечное отключение работают; хранение — только отклонения.
- [ ] После новой таблицы выполнен `bi:sync-grants`.
- [ ] Feature-тесты на включённость: умолчание, отклонение, глобальный рубильник.
