# debt-03: касания — письма и баннеры эскалации через пульт

**Приоритет:** высокий
**Эпик:** [debt-00](2026-08-21_debt-00-epic.md)
**Зависит от:** debt-02
**Создано:** 2026-08-21

## Описание

Все исходящие касания идут **через пульт уведомлений** — журнал, suppressions,
тихие часы и адресная книга уже там. Домен `finance` пульта включается
(`PULSE_DOMAIN_FINANCE`), существующие события (`payment_due_soon`,
`overdue_started/grew/cleared`) дополняются событиями переходов уровней:

- `finance.debt_level_raised` — клиент поднялся по лестнице (данные: старый/новый
  уровень, просрочка, документы);
- `finance.debt_level_cleared` — вернулся в `clean` («доступ восстановлен», уходит
  из debt-07);
- `finance.debt_restriction_warning` — предупреждение перед ограничением
  (инвариант: без этого письма debt-06 ограничивать не имеет права).

### Отправитель по ступеням (решение 21.08)

- Мягкие напоминания (`reminder`) — от имени персонального менеджера, reply-to
  менеджера: отвечается в живом диалоге;
- предупреждение об ограничении, перевод на предоплату, арест — от компании
  (официальный отправитель): жёсткие письма не портят отношения менеджера.

### Получатели

Пресет правил поверх существующего пресета «Бухгалтерия»: контакт с ролью
`accountant` (из `client_contacts`) + контакт самого партнёра; `personal_manager`
в копии на жёстких ступенях. Правила редактируются РОП в конструкторе пульта —
код не фиксирует получателей.

### Кабинет (решение 21.08)

- `reminder` — спокойная плашка на дашборде кабинета (не модалка);
- `prepay_only` / `hold` — заметный сквозной баннер на всех страницах кабинета
  с кнопкой «оплатить» (ведёт в debt-04/05);
- модальных тостов при логине нет — быстро слепнут.

### Ритм

Каскад внутри `reminder` (T+0 мягкое, T+7 повтор, T+14 предупреждение об
ограничении) — расписанием в конфиге, не новыми сущностями. Дедупликация —
существующим `DeliveryGuard::throttled`.

## Критерии готовности

- [ ] События зарегистрированы в `config/notification_pulse.php`, контракт `NotificationEventContract`, shadow-прогон в журнале
- [ ] Шаблоны писем: мягкое/повтор/предупреждение/предоплата/арест/восстановление — на русском, тексты согласованы с РОП
- [ ] Отправитель и reply-to переключаются по ступени
- [ ] Плашка и сквозной баннер в кабинете (Chakra-обёртки, только русский)
- [ ] Инвариант «ограничение только после `debt_restriction_warning`» — интеграционный тест
- [ ] Каскад T+0/T+7/T+14 идемпотентен (повторный запуск не дублирует письма)
