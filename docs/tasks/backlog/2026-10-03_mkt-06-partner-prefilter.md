# mkt-06. Префильтр партнёра в CRM: организации, склады, ставки, бренды по складам, порог остатка

**Приоритет:** высокий · **Создано:** 2026-10-03 (заменяет mkt-06 «Скоуп видимости» от 26.09, снята) · **Волна:** 1 · **Эпик:** mkt-00
**Зависит от:** mkt-03
**Оценка (ориентир):** 3–4 дня

## Описание

Решение заказчика 03.10.2026 (п. 11 опроса). Предложения приходят из 1С по товару, **одинаковые для всех**;
**фильтрация показа — на сайте**, свойством партнёра. Что партнёру показывать — строка таблицы, не вычисление:
**никаких шаблонов, журнала, условий и расписаний** (от шаблонов и журнала из решения 26.09 отказались).

На карточке партнёра в CRM — блок префильтра:

- **доступные организации** (продавцы);
- **доступные склады**;
- **доступные ставки НДС**;
- далее — **доступные бренды по складам** (**второй этап**, открыто);
- **порог остатка по складам**: если задан — клиенту показывается остаток не выше порога (клиентам не всегда
  хотят светить все остатки).

Правило: **не выбрано = доступны все, выбрано = только они.** Таблица хранит только заданное (по аналогии
с `notification_preferences` — только отклонения от умолчания).

Это заменяет прежнюю идею «через настройку региона клиента»: регион остаётся механизмом «в наличии / под
заказ», доступ ко второму продавцу задаётся префильтром. Менеджер продаёт в пределах префильтра клиента
(mkt-19). Кому организация не открыта — тот не видит её нигде, включая фильтры и счётчики (mkt-05).

Право на правку префильтра — в духе `project_crm_domain` (роли РОП/админ), конкретика при реализации;
новые права заводятся в трёх реестрах (сидер, группы, меню).

## Критерии готовности

- [ ] Миграция таблицы префильтра с `->comment()` на таблице и столбцах; отметка для `bi:sync-grants`
- [ ] Блок на карточке партнёра в CRM: организации, склады, ставки, порог остатка по складам; UI на русском,
      действия строк по стандарту проекта
- [ ] Пустой префильтр = всё доступно; заданный — только перечисленное
- [ ] Порог остатка применяется в mkt-05; показанное число не выше порога
- [ ] Права заведены в трёх реестрах, тест дрейфа прав зелёный
- [ ] Тест: партнёр без организации в префильтре не видит её нигде
- [ ] Бренды по складам — отмечены как второй этап, в интерфейсе не обещаны
