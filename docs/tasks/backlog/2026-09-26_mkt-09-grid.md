# mkt-09. Каталог: плоская сетка — плитка на каждое предложение

**Приоритет:** высокий · **Создано:** 2026-09-26 · **Переписано:** 2026-10-03 · **Волна:** 2 · **Эпик:** mkt-00
**Зависит от:** mkt-05
**Оценка (ориентир):** 5–7 дней (следствие опроса: плоская сетка поверх концепции 22–30)

## Описание

**Решение заказчика 03.10.2026 (п. 1, подтверждает 26.09): отдельная плитка на каждое предложение.** Товар
стоит в каталоге столько раз, сколько у него доступных клиенту предложений; у плитки свой продавец
(торговое имя), ставка подписью, **точное число остатка**, свой счётчик. Покупка — в один клик с плитки.
Пример: «Масло массажное 100 мл» — три плитки подряд с одним фото: «Пекадо · НДС 5 % · 12 шт»,
«Пекадо · НДС 22 % · 4 шт», «<имя 2> · НДС 5 % · 30 шт».

Что показываем и чего нет:

- на плитке — продавец, ставка подписью («НДС 5 %»), остаток числом, цена одна (с налогом), счётчик;
  **склад не показываем** (п. 5);
- у товара с одним предложением плитка как сегодня плюс подпись ставки (п. 14);
- гость — товарная плитка без цен и продавцов, как сейчас (низ плитки гостю не показывается);
- предзаказ — отдельная плитка/строка не решена для каталога: в карточке предзаказ — своя строка (mkt-10);
  как плитка «под заказ» выглядит в сетке — решить при реализации по образцу сегодняшнего статуса «Предзаказ»;
- без новых анимаций и отдельных блоков (`feedback_ui_effects_minimal`, `feedback_ui_no_extra_blocks`).

Техника: индекс Meilisearch остаётся товарным (в нём нет ни остатка, ни склада, ни продавца — mkt-08 снята);
**раскрытие товара в плитки-предложения делается после выдачи**. Сортировка «По умолчанию» и скрытие брендов
без остатков считаются по товару, как сейчас; сортировка по цене — по меньшей цене товара. Постраничный
вывод при раскрытии — вмешательство в пагинацию, за это и доплата 5–7 дней; избранное и подборки считаются
по товару, плитки — по предложению (риск 3 эпика).

## Критерии готовности

- [ ] Одна плитка на доступное клиенту предложение; у товара с одним предложением — одна плитка
- [ ] На плитке: торговое имя продавца, подпись ставки, остаток числом, счётчик, ограниченный остатком
      предложения; склада нет
- [ ] Гость: товарная плитка, без цен и без продавцов
- [ ] Сортировка «По умолчанию» и скрытие брендов без остатков не изменились; пагинация не теряет и не
      дублирует предложения на границах страниц
- [ ] Избранное и подборки работают по товару
- [ ] Вёрстка не ломается на телефоне, тексты на русском
- [ ] Замер времени выдачи каталога до и после — в карточке
