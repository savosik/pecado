# capi-15: инструкции MCP-сервера, подключение из кабинета, сквозной сценарий на dev

**Приоритет:** средний
**Создано:** 2026-09-16
**Эпик:** capi-00
**Зависимости:** capi-14

## Описание

1. **`$instructions` `ClientServer`** — рабочая методичка, не справка API (образец —
   `PurchasingServer`, `CrmServer`). Тезисы:
   - порядок `client-catalog` → `client-describe` → `client-call`; ярлыки дешевле трёх вызовов;
   - **запись необратима и идёт от имени клиента**: заказ уходит в 1С и в сборку, «пробных» заказов
     нет; отмена возможна только до сборки и только при включённом режиме;
   - **юрлицо**: заказ, документы и долг привязаны к контрагенту; при нескольких компаниях — спросить
     человека, не выбирать самому;
   - **идемпотентность**: на создание заказа всегда передавать `idempotency_key`; при обрыве повторять
     с тем же ключом, а не новым;
   - **флаги**: часть разделов может быть выключена — смотреть `allowed` в каталоге, не спорить с 403;
   - остатки и цены — по региону клиента; «нет в наличии» ≠ «нет товара» (есть предзаказ со сроком
     из профиля);
   - где взять и как отозвать токен — `/api-tokens`; один токен даёт всё;
   - что API **не решает** (объединить заказы в одну отправку, «подождите предзаказ», самовывоз к
     часу, трек доставки до эпика доставки) — через `client-ask-manager`, не выдумывать;
   - аналитики и CRM здесь нет, это другие серверы с другими токенами.
2. **Экран `/api-tokens`**: блок «Подключить агента» — URL `/mcp/client`, готовые JSON-сниппеты для
   Claude Desktop / Claude Code / Cursor с `Authorization: Bearer`, кнопка «скопировать». На русском.
3. **Сквозной сценарий на dev**: реальным MCP-клиентом по токену тестового клиента — `client-prices`
   → `carts.import` через `client-call` → `client-create-order` (с ключом, дважды) → `client-order-status`
   → `client-ask-manager`. Результат фиксируется в карточке (что увидел агент, где споткнулся) и
   закрепляется тестом `client_agent_walks_through_prices_cart_order_status`.
4. Правки инструкций по итогам прогона — в той же карточке.

## Критерии готовности

- [ ] Сценарий проходит на dev реальным MCP-клиентом; в 1С уходит ровно один заказ при двойном вызове.
- [ ] Тест `client_agent_walks_through_prices_cart_order_status` зелёный (через `ClientServer::actingAs`).
- [ ] Сниппеты на `/api-tokens` работают при копировании без правок (проверено Claude Desktop и Cursor).
- [ ] Инструкции на русском, без ссылок на несуществующие инструменты (тест: каждое `client-*` из текста есть в `$tools`).
- [ ] `docker exec pecado-node npm run lint:js`, `make build` зелёные.
