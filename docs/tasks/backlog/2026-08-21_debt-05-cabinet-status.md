# debt-05: финансовый статус в кабинете — «норма невидима»

**Приоритет:** средний
**Эпик:** [debt-00](2026-08-21_debt-00-epic.md)
**Зависит от:** debt-02, debt-04
**Создано:** 2026-08-21

## Описание

Подача статуса клиенту (решения 21.08):

- **Норма невидима.** У клиента уровня `clean` никакой шкалы, лимита и «рейтинга»
  нет — только привычный баланс в разделе оплат. Финансовый статус появляется
  в кабинете только при значимой просрочке.
- **Кредитный лимит клиенту не показывается никогда** — знание лимита стимулирует
  сидеть под завязку (эффект кредитной карты). Лимит — внутренняя механика гейта.
- **Следующая ступень и даты переходов не показываются** — никаких «до блокировки
  осталось N дней». Предупреждение об ограничении приходит письмом
  (`debt_restriction_warning`), а не таймером в интерфейсе.

### Что видит клиент с просрочкой

Блок в разделе «Оплаты» (и плашка/баннер из debt-03):

1. статус словами: «Есть просроченные оплаты на 287 934 ₽» / «Отгрузка по
   предоплате» / «Оформление заказов приостановлено»;
2. расшифровка по документам из `contractor_balance_overdue_details`: документ,
   дата, срок, сумма, дней просрочки — в разрезе контрагентов и наших организаций;
3. действия: «Оплатить просрочку» / «Оплатить всё» / «Оплатить этот документ»
   (→ платёжка debt-04), «Сообщить об оплате» (→ обещание, debt-08), «Не согласен
   с документом» (→ диспут, debt-08);
4. у `prepay_only`: спокойное объяснение режима — «до погашения просрочки заказы
   отгружаются после оплаты», без угроз.

Тон текстов — деловой и нейтральный: констатация и кнопка решения, ни обратных
отсчётов, ни красных сирен. Семантический цвет статуса (жёлтый/оранжевый) — да,
паника — нет.

## Критерии готовности

- [ ] Блок статуса рендерится только при уровне ≠ `clean`; у чистого клиента DOM не содержит финансового статуса вовсе
- [ ] Расшифровка сходится с `debt:explain` по тому же клиенту (один источник данных)
- [ ] Все four действия ведут в существующие флоу (платёжка/обещание/диспут); недоступные до debt-08 кнопки не показываются, а не задизейблены
- [ ] Тексты согласованы с РОП; всё на русском, включая склонения сумм и дней
- [ ] Chakra-компоненты из `@/components/ui/*`; guard на `product`-паттерн загрузки (optional chaining до скелетона)
