# up-07: справочник сопутствия — статистика, обучение, подтверждения

**Приоритет:** средний
**Эпик:** [up-00](2026-08-14_up-00-epic.md)
**Зависит от:** up-02; сигналы обучения приходят из up-04/up-05/up-06
**Создано:** 2026-08-14

## Описание

Наполнение и жизнь `product_complements` — механика зеркалит sub-07
(очередь подтверждений одна и та же, вкладки соседние).

### Источники

1. **`stats`** — co-occurrence по всем заказам: команда
   `upsell:mine-complements` считает пары «категория игрушек → SKU расходника»
   (lift/support по заказам за 12 мес), кандидаты выше порога → в очередь
   подтверждений. Направленность обязательна: смазка сопутствует игрушке,
   не наоборот.
2. **`learned`** — клиент добавил предложенное в корзину и заказ состоялся
   (`upsell_signals.status = ordered`) → связь усиливается/создаётся.
3. **`manual`** — менеджер добавил из карточки клиента или каталога.
4. **`ai`** — предразметка агентом по категориям-якорям (игрушки с питанием →
   батарейки нужного типа из атрибута «Количество и тип батареек»; материал →
   совместимая смазка: силикон + силиконовая смазка = порча товара, это
   знание каталога, не статистика). Всегда через подтверждение.

### Очередь подтверждений

Вкладка «Сопутствие» рядом с очередью замен (sub-07): пара, lift/статистика,
негативные сигналы (`dismissed` клиентов), Подтвердить / Отклонить;
отклонённые не воскресают.

### Уровень категории

Правила `from_category_id → to_product_id` («ко всем виброяйцам — эта смазка»)
сокращают ручную работу с 9 000 товаров до ~170 листовых категорий.
SKU-правило приоритетнее категорийного.

## Критерии готовности

- [ ] `upsell:mine-complements`: пары с lift/support, порог в конфиге, отчёт что найдено
- [ ] `learned` из фактических заказов по сигналам, идемпотентно
- [ ] ai-предразметка: батарейки по атрибуту питания, смазки по материалу — через очередь
- [ ] Очередь подтверждений; отклонённые помнятся
- [ ] Категорийные правила работают и перекрываются SKU-правилами
- [ ] Агрегатные запросы майнинга проверены на локальной MySQL
