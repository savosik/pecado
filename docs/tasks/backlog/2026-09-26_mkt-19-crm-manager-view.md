# mkt-19. Корзина менеджера: как у клиента, плюс название склада

**Приоритет:** средний · **Создано:** 2026-09-26 · **Переписано:** 2026-10-03 · **Волна:** 4 · **Эпик:** mkt-00
**Зависит от:** mkt-06, mkt-12
**Оценка (ориентир):** 3–4 дня (следствие опроса)

## Описание

**Решение заказчика 03.10.2026 (п. 12): менеджер видит то же, что клиент, плюс название склада.**
В корзине менеджера (`Admin/CartController`, оформление за клиента) — те же предложения, что видит клиент
по своему префильтру (mkt-06), в каждой строке дополнительно склад («Москва Основной», «Москва
персональный»). Менеджер может подобрать клиенту нужную ставку и продавца, но **продаёт только в пределах
доступа клиента**: доступ меняют в префильтре партнёра, а не в момент продажи. Попытка взять предложение
вне доступа отклоняется с понятным сообщением на русском.

Строка заказа менеджера несёт `offer_key`, как клиентская. Заказы менеджеров без выбора предложения
(сегодняшний путь) остаются валидны — строка без ключа, продавца подставит 1С.

В карточке заказа админки и CRM — продавец, склад и ставка по строкам (mkt-15). Действия строк —
стандартные глаз / карандаш / корзина (`feedback_row_actions_standard`).

## Критерии готовности

- [ ] Корзина менеджера показывает предложения клиента по его префильтру, с названием склада в строке
- [ ] Предложение вне доступа клиента в корзину не кладётся; сообщение на русском
- [ ] Строка заказа менеджера с выбранным предложением уходит в 1С с `offer_key`; без выбора — как сегодня
- [ ] В карточке заказа виден продавец, склад и ставка по строкам
- [ ] Действия строк — стандартные глаз / карандаш / корзина
