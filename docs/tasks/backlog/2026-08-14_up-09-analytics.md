# up-09: аналитика допродаж — выручка из сигналов

**Приоритет:** средний
**Эпик:** [up-00](2026-08-14_up-00-epic.md)
**Зависит от:** волны 2–3 (данные копятся с них)
**Создано:** 2026-08-14

## Описание

Срез в `/crm/analytics` (движок — `ShipmentAnalyticsService`/`AnalyticsContext`,
второго расчёта выручки не появляется; бизнес-даты — `erp_created_at`).

### Метрики домена

- **Выручка из сигналов**: заказы/строки, рождённые из сигналов
  (`upsell_source`, `upsell_signals.order_item_id`) — точно, без эвристик;
  разрез по поверхностям (`cart` / `post_order` / `shortage_page` / `digest` /
  `cabinet`) и слоям — что реально продаёт;
- **Attach rate** по месяцам: смазки (старт 31 %), уход (8 %), батарейки (0,2 %)
  к заказам с игрушками — метрика поверхности «корзина»;
- **Закрытые просроченные циклы**: сколько из ~6,1 млн потенциала
  конвертировано; динамика суммы просрочки;
- **Ширина матрицы**: медиана категорий на активного клиента по кварталам —
  главная стратегическая метрика (корреляция с выручкой: 4–10 категорий →
  71 тыс ₽, 31+ → 1,69 млн ₽);
- **Конверсия дайджестов**: воронка sent → viewed → корзина → заказ;
- **Гигиена канала**: доля `dismissed`, отписки — ранний сигнал спама.

### Решения, которые принимаются по этим цифрам

Порог для фазы автоотправки дайджестов (за скоупом эпика): конверсия и
`dismissed`-доля волны 3 определяют, можно ли убирать менеджера из цикла.
Зафиксировать пороги в карточке при закрытии.

### Витрина BI

Вьюхи analytics по сигналам/дайджестам/циклам + `bi:sync-grants` — ИИ-агент
менеджеров и руководителя отвечает на «что продали допродажи в июле».

## Критерии готовности

- [ ] Срез в /crm/analytics со всеми метриками, разрезы по менеджерам/поверхностям/слоям
- [ ] Attach rate и просрочка циклов считаются воспроизводимо (зафиксированные запросы), стартовые точки записаны
- [ ] Агрегаты проверены на локальной MySQL (only_full_group_by)
- [ ] Вьюхи + гранты
- [ ] UI на русском
