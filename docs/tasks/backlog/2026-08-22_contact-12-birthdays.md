# contact-12 · Дни рождения

**Приоритет:** низкий
**Создано:** 2026-08-22
**Эпик:** [contact-00](2026-08-22_contact-00-epic.md)
**Зависимости:** [contact-02](../review/2026-08-22_contact-02-section.md)
**Оценка:** ~1 день

## Описание

Одна из двух причин, по которым менеджеру выгодно завести контакт для себя, а не «для системы»
(вторая — выгрузка в телефон). Поздравить бухгалтера контрагента дешевле любой скидки.

## Что делаем

- Виджет «Дни рождения на неделе» на рабочем столе CRM: аватар, ФИО, у кого работает, дата.
- Страница `/crm/contacts/birthdays` — ближайший месяц с группировкой по дням.
- Автозадача «Поздравить» через существующий `CrmTaskService` — за день до даты, на персонального
  менеджера партнёра. Идемпотентно: повторный прогон планировщика не плодит задачи (образец —
  `CrmTaskRecurrenceService`).

Учитывается `birthday_has_year`: без года показываем «17 мая», а не считаем возраст.

Виджет и страница гейтятся правом `crm-contacts.view`, задача создаётся только если у партнёра
есть персональный менеджер.

## Критерии готовности

- [ ] Виджет на рабочем столе; пустой — не показывается вовсе
- [ ] Страница ближайших дней рождения
- [ ] Автозадача «Поздравить», повторный прогон не плодит дублей
- [ ] Дата без года показывается как «17 мая», возраст не считается
