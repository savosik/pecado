## Описание

Правила живут внутри раздела «Письма» — отдельного пункта меню не заводим. Именно
дробление на разделы сделало прошлый подход непонятным.

```
Письма   [Черновики] [Отправленные] [Не ушли] [Правила]
```

## Форма правила

Один экран, без шагов и мастеров:

```
Название       [Акты Афониной                    ]

Если письмо
  [содержит ▾] [инн:7701234567    ▾]
  [содержит ▾] [акт-сверки        ▾]           [+ ещё условие]

Отправить на   [buh@romashka.ru, glavbuh@romashka.ru]

☐ отправлять автоматически, без моего участия

──────────────────────────────────────────
Под фильтр попадает 4 письма:
  Акт сверки № 1023 от 20.08 — ООО Ромашка
  Акт сверки № 998 от 12.08  — ООО Ромашка
  …
```

Значения условий выбираются из подсказки (метки) либо набираются свободно (текст).
Список подошедших писем обновляется по мере набора условий — видно сразу, что ловится.

## Список правил

Плоский список: имя, условия человеческим текстом, получатели, тумблер, сколько писем
поймано за последний месяц. Правило, не поймавшее ничего, помечается — скорее всего
условие набрано с ошибкой.

## Критерии готовности

- [ ] Правила — вкладка внутри «Писем», отдельного пункта меню нет
- [ ] Форма на одном экране, без шагов
- [ ] Превью обновляется по мере набора условий
- [ ] Значения меток выбираются из подсказки
- [ ] В списке видно, сколько писем правило поймало; пустые помечены
- [ ] Весь интерфейс на русском
