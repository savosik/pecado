# debt-10: досудебный пакет одной кнопкой

**Приоритет:** низкий
**Эпик:** [debt-00](2026-08-21_debt-00-epic.md)
**Зависит от:** debt-09
**Создано:** 2026-08-21

## Описание

Кнопка «Сформировать претензию» в CRM-карточке клиента (уровень `hold` или
профиль `legal`). Пакет собирается автоматически, **отправка всегда ручная** —
досудебка не бывает автоматической.

### Состав пакета

1. **Претензия** по шаблону: реквизиты сторон (наша `organization` × контрагент),
   реестр просроченных документов (номер, дата, срок, сумма, дней просрочки —
   из `contractor_balance_overdue_details` и графиков), итоговая сумма требования;
2. **Расчёт процентов по ст. 395 ГК** (решение 21.08): по ключевой ставке, по дням
   из графиков оплат; отдельным листом-таблицей. Менеджер может править ставку
   (договорная неустойка) или убрать расчёт перед отправкой;
3. **Акт сверки** за период — готовый `ReconciliationService` (XLSX/PDF);
4. **Реестр приложений**: печатные формы УПД/накладных по спорным отгрузкам
   из раздела «Документы» (`printed_documents`, PDF из 1С уже в хранилище).

Черновик пакета редактируем (даты, шапка, состав приложений), итог — ZIP или
единый PDF. Факт формирования и отправки пишется в журнал переходов клиента
(`debt_level_transitions` / отдельная запись) — виден в истории и в debt-11.

Юридическую формулу шаблона согласовать с юристом до релиза; ключевую ставку
хранить в конфиге с датами периодов (история ставок для расчёта по дням).

## Критерии готовности

- [ ] Шаблон претензии согласован с юристом; тексты на русском
- [ ] Расчёт 395 ГК: юнит-тесты на периоды с разными ставками и частичные оплаты
- [ ] Пакет собирается по клиенту с 29 юрлицами (кейс Гевеи) — по каждому контрагенту отдельная претензия
- [ ] Печатные формы подтягиваются по спорным отгрузкам; отсутствующие формы показаны предупреждением, а не молча пропущены
- [ ] Отправка фиксируется в истории клиента; повторная генерация не дублирует запись
