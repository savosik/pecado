# sub-13: клиентская страница замен v2

**Приоритет:** средний
**Эпик:** [sub-00](../review/2026-08-14_sub-00-epic.md)
**Зависит от:** sub-10 (группировка/причины), sub-12 (консистентность с письмом)
**Создано:** 2026-08-16

## Описание

Страница `/substitutions/{uuid}` функционально работает (выбор, кап количества,
постинг новых заказов), но выглядит и читается сыро. Доводим до состояния,
за которое не стыдно перед клиентом, пришедшим по письму-извинению.

### Контекст отменённой позиции

Сейчас отменённая строка — только зачёркнутый текст. Добавить полноценную
карточку: фото, название, цена за штуку × количество, сумма потери — клиент
должен сразу узнать «свой» товар.

### Кандидаты

- Группировка и порядок по слоям из sub-10, причина подбора у каждого —
  заметным текстом, не мелкой строкой.
- Честность при живом пересчёте: если кандидат из письма уже разобрали
  (остаток 0), сейчас он молча исчезает — показывать «Увы, этот вариант уже
  разобрали» вместо тихого расхождения с письмом.
- Фото крупнее 44px, состояние выбора очевидное.

### Исходы

- Новый исход «Ничего не подходит — свяжитесь со мной»: создаёт `CrmTask`
  менеджеру (в связке с механикой задач из sub-11) и подтверждает клиенту,
  что менеджер позвонит. Сейчас у клиента только «без замены» по каждой строке
  и телефон текстом.
- «Подождать прихода» — показывать прогноз, если есть предзаказный остаток
  («ожидаем поступление»), не голую радио-кнопку.

### Вёрстка

- Мобильная вёрстка: страницу открывают из письма с телефона — sticky-итог,
  крупные зоны нажатия, проверка на узких экранах.
- Сохранение выбора в localStorage и сценарий входа не ломаются (регресс).

## Критерии готовности

- [ ] Карточка отменённой позиции с фото и ценой за штуку
- [ ] Кандидаты сгруппированы, причины читаемы; разобранные варианты показываются честно, не исчезают (тест на живой пересчёт)
- [ ] Исход «свяжитесь со мной» создаёт задачу менеджеру и виден в CRM (feature-тест)
- [ ] Мобильная вёрстка проверена на dev; выбор переживает вход (регресс `SubstitutionClientPageTest`)
- [ ] UI на Chakra-обёртках `@/components/ui/*`, весь интерфейс на русском
