# Промо 11 — Склад «Москва реклама», пробники и WMS

**Приоритет:** средний
**Создано:** 2026-07-27
**Roadmap:** [docs/promo-constructor-roadmap.md → Волна 3](../../promo-constructor-roadmap.md)
**Зависит от:** [promo-09-erp-order-types](2026-07-27_promo-09-erp-order-types.md)

## Контекст

Пробники — обычные товары, которые лежат на складе «Москва реклама». Заказчик подтвердил:
в 1С они поступают **как обычный заказ** и списываются **как обычный товар**; отличие только
в том, что клиенту в накладную они не попадают.

Склад на момент проектирования **не заведён** — ни в 1С, ни на сайте. Это внешний блокер
карточки, ровно как было со складом некондиции.

## Задача

### 1. Флаг склада

Новая миграция: `warehouses.is_promo_sample` (boolean, default false) с русским
комментарием. Образец — `2026_07_20_100100_add_is_defect_to_warehouses_table.php`.

В [`Warehouse`](../../../app/Models/Warehouse.php): добавить в `$fillable`, в `casts`,
скоуп `promoSample()` по образцу
[`scopeDefect()`](../../../app/Models/Warehouse.php#L57) — **вместе с его док-блоком про
регионы**: «такой склад не входит в регионы, поэтому его остатки не попадают в наличие и
предзаказ на витрине». Для рекламного склада это критично: пробники не должны продаваться
как обычный товар.

### 2. Админка складов

Флаг некондиции уже выведен в интерфейс — повторить для рекламного:

- [Warehouses/Create.jsx:69](../../../resources/js/Admin/Pages/Warehouses/Create.jsx#L69) и
  [Edit.jsx:72](../../../resources/js/Admin/Pages/Warehouses/Edit.jsx#L72) — чекбокс
  «Склад рекламных образцов»;
- [Show.jsx:47](../../../resources/js/Admin/Pages/Warehouses/Show.jsx#L47) — строка «Тип»
  сейчас двухзначная (`is_defect ? 'Склад некондиции' : 'Обычный'`), переделать в
  вычисление по трём вариантам;
- [Index.jsx:54](../../../resources/js/Admin/Pages/Warehouses/Index.jsx#L54) — колонка типа;
- [WarehouseController](../../../app/Http/Controllers/Admin/WarehouseController.php#L58) —
  валидация и передача поля (строки 58, 76, 101).

Взаимоисключающесть: склад не может быть одновременно некондиции и рекламным — валидация с
русским сообщением.

### 3. Заведение склада

Склад приезжает из 1С по шине вместе с остатками
([HandleStockUpdated](../../../app/Services/Erp/Handlers/HandleStockUpdated.php) ищет склад по
`external_id` и **не создаёт** его). Поэтому:

1. получить UUID склада «Москва реклама» от 1С;
2. миграция, проставляющая `external_id` и `is_promo_sample` конкретной записи — образец
   `2026_07_20_100500_set_defect_warehouse_external_id.php`;
3. убедиться, что склад **не привязан** ни к одному региону в `region_warehouse`.

До выполнения п. 1 гейт публикации из карточки 09 не даёт заказам `promo_sample` уйти в 1С
с пустым `warehouse_uuids` — это ожидаемое поведение, а не поломка.

### 4. Лист отбора

`App\Services\Promotion\PromoPickListFormatter` по образцу
[DefectPickListFormatter](../../../app/Services/Defect/DefectPickListFormatter.php).
Мотивация та же и записана в его док-блоке: кладовщики собирают заказ по печатному документу
из 1С и в WMS заходят редко, поэтому конкретика дописывается в `warehouse_comment`, который
уходит в 1С.

Формат строки:
```
Рекламные образцы — отобрать со склада «Москва реклама»:
арт. {sku} — {название} — {N} шт. — по акции «{название акции}»
```

Подключение — в сборке промо-заказа, как это сделано для уценки в
[CheckoutService:152–165](../../../app/Services/Order/CheckoutService.php#L152): существующий
`warehouse_comment` не затирается, лист дописывается через `\n\n`.

Для подотчётных промо-позиций (`promo`) лист тоже полезен — они отбираются с обычного
склада вперемешку с товаром, и кладовщику надо понимать, что позиция акционная. Формат тот
же, заголовок другой.

### 5. WMS

[Кабинет склада](../../../routes/wms.php) сейчас содержит дашборд и раздел некондиции.
Добавить раздел рекламных образцов:

- права `wms-promo.view` (и `wms-promo.edit`, если появится ведение остатков) — по образцу
  `wms-defects.*`;
- пункт меню в [Wms/config/menuConfig.ts](../../../resources/js/Wms/config/menuConfig.ts)
  рядом с «Партии брака» / «К отгрузке»;
- страница «Остатки рекламного склада» — таблица товаров с остатком на «Москва реклама»
  (данные из `product_warehouse`, приходят по шине; редактирования нет — источник правды 1С,
  это надо явно написать на странице);
- страница «К отгрузке» — очередь заказов `promo` и `promo_sample`, аналог
  [Wms/Pages/Defects/Shipping.jsx](../../../resources/js/Wms/Pages/Defects/Shipping.jsx).

## Нюансы

- **Пробники не должны появиться на витрине.** Главная проверка карточки: товар, у которого
  остаток есть **только** на «Москва реклама», не показывается как «в наличии» и не
  добавляется в обычную корзину. Гарантируется невключением склада в регионы, но тест
  обязателен — цена ошибки высока.
- **Уценка и реклама не пересекаются.** Партии брака привязаны к складу некондиции; проверить,
  что WMS-разделы не начинают показывать чужие данные.
- **Остатки только на чтение.** Кладовщик не правит остатки рекламного склада на сайте —
  они приходят по шине. На странице должна быть явная пометка, иначе появятся обращения
  «почему не сохраняется».
- Интерфейс WMS рассчитан на работу с телефона/ТСД — таблицы должны быть компактными и
  читаемыми на узком экране, как остальные страницы раздела.

## Критерии готовности

- [ ] Миграция флага применена, комментарии на русском, `db:comments:audit --strict` чистый.
- [ ] Флаг выведен во все четыре страницы админки складов; взаимоисключающесть с
      некондицией валидируется.
- [ ] Склад «Москва реклама» заведён с `external_id`, не входит ни в один регион.
- [ ] **Тест: товар с остатком только на рекламном складе не попадает в витринное наличие
      и не добавляется в корзину как обычный.**
- [ ] `PromoPickListFormatter` покрыт тестом; лист дописывается к существующему
      `warehouse_comment`, не затирая его.
- [ ] Раздел WMS доступен по правам, показывает остатки и очередь отгрузки.
- [ ] Гейт публикации снят: заказы `promo_sample` уходят в 1С с корректным
      `warehouse_uuids` (интеграционный тест).
- [ ] Проверено на узком экране.

## ⚠️ WMS промо-позиции не отбирает

Решение заказчика (2026-08-01): кабинет склада сделан **под некондицию** — чтобы
кладовщик визуально отличал дефектные экземпляры и знал, какую именно партию отдать.
Промо-позиции — обычные товары, отдельного отбора им не нужно, в WMS их показывать
не надо. Ни `promo`, ни `promo_sample` в очередь отбора не добавлять.
