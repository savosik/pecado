## Описание

Отдельный пункт меню и полноценный раздел `/crm/contacts` — то, ради чего затевался эпик.
Сегодня контакты закопаны в карточках; теперь есть одно место, где виден весь справочник.

## Строка списка — человек, а не привязка

Ключевое решение по виду. Если строкой сделать привязку, Мария Афонина — бухгалтер трёх юрлиц
одного партнёра — займёт три строки, и менеджер решит, что в базе дубли. Поэтому строка одна,
а роли и «где» показываются агрегатом:

```
[фото] Афонина Мария Петровна          Гл. бухгалтер
       [Партнёр]                        Бухгалтер +1
       Ромашка ООО · Одуванчик ООО      +7 912 345-67-89  ✉ buh@romashka.ru  ✈
       17 мая
```

Колонки: Контакт (аватар, ФИО, бейдж источника), Должность, Роли (до 3 бейджей цветом, дальше
«ещё N»), Где (до 2 чипов привязок со ссылками), Связь (телефон, почта, иконка предпочитаемого
канала), День рождения.

Привязки догружаются через `morphWith` с явным списком колонок. Без этого на каждую строку летит
запрос на каждую привязку — при 25 строках это сотня запросов.

## Фильтры

Поиск (ФИО, телефон, почта, должность), роль, партнёр, контрагент, источник, «есть почта»,
«есть телефон», «есть день рождения», активность, `ScopeToggle` (мои / отдел).
Сортировка: ФИО, дата создания, ближайший день рождения.

Поиск по телефону идёт по `phone_digits` — цифры из запроса чистятся так же, как в
`ClientListService`. Поиск по ФИО — `LIKE 'x%'` по индексу; `%x%` включается от трёх символов.

## Карточка контакта

Шапка: аватар, ФИО, «как обращаться», должность, все каналы связи, день рождения, бейджи
источника и активности. Блок привязок с добавлением и удалением. Вкладки «Комментарии»,
«Задачи», «Файлы» через готовый `EntityCrmPanel` с `entityType="contact"` — работает бесплатно
после `contact-03`. Вкладка «Письма» — заготовка, наполняется в `contact-06`.

## Что делаем

- `routes/crm.php`: группы по одному праву, имена `crm.contacts.*`, `whereNumber('contact')`.
  Статические сегменты (`/contacts/vcf`, `/contacts/export`, `/contacts/for-entity`) — **до**
  `/contacts/{contact}`, иначе уйдут в биндинг модели.
- `app/Http/Controllers/Crm/ContactController.php` extends `CrmController`; чужой контакт → 404,
  не 403 — как у контрагентов.
- `app/Http/Requests/Crm/{Store,Update}ContactRequest.php` — русские сообщения, проверка дубля
  по почте и телефону в рамках партнёра.
- `app/Services/Crm/ContactListService.php` — пагинация, фильтры, `morphWith`.
- Фронт: `resources/js/Crm/Pages/Contacts/{Index,Show}.jsx`,
  `resources/js/Crm/Components/ContactForm.jsx`. Chakra только из `@/components/ui/*`;
  телефоны — через `resources/js/components/common/PhoneInput.jsx`; аватар — `ImageUploader`.
- Пункт меню в `resources/js/Crm/config/menuConfig.ts`, группа «Клиенты», после «Контрагентов».
