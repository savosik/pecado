# UI для генерации токена AI Content Manager

**Приоритет:** средний
**Исполнитель:** -
**Создано:** 2026-04-15

## Описание

Сейчас Sanctum-токен для пользователя `ai-content-bot@pecado.ru` (`ai-content-agent`), который нужен для API работы с контентом, генерируется только через `AiContentManagerSeeder`. Это требует заходить на dev-сервер через SSH и запускать консольные команды вручную (в dockere), что неудобно. 

Необходимо реализовать интерфейс генерации токена непосредственно из админки (Inertia / React), например, в разделе «Настройки» (`SettingsController`).

## Критерии готовности

- [ ] В `SettingsController` добавлены необходимые методы (или создан отдельный контроллер/API) для пересоздания Sanctum-токена сервисного юзера `ai-content-bot@pecado.ru`.
- [ ] Логика должна повторять сидер: найти/создать юзера, удалить старые токены (`->tokens()->delete()`), выпустить новый.
- [ ] Зарегистрирован POST-роут в `routes/admin.php` (например, `/admin/settings/generate-content-token`).
- [ ] В React-шаблоне раздела настроек (или отдельной вкладке интеграций) добавлена секция "AI Content API Token".
- [ ] Реализована кнопка «Сгенерировать токен». При успешном ответе от сервера токен (`plainTextToken`) показывается в интерфейсе один раз с кнопкой для удобного копирования в буфер обмена.
- [ ] Учтены и корректно настроены доступы (middleware `permission:settings.edit` и т.д.).
