# up-03: CRM — пресет «Просроченные циклы SKU» и вкладка «Сигналы»

**Приоритет:** высокий
**Эпик:** [up-00](2026-08-14_up-00-epic.md)
**Зависит от:** up-02
**Создано:** 2026-08-14

## Описание

Менеджер — первый потребитель сигналов: до всякой клиентской поверхности
данные должны пройти проверку людьми, которые знают клиентов.

### Пресет в Возможностях (`OpportunityService`)

Новый `OpportunityPreset::STALE_CYCLES` («Просроченные циклы товаров»):
клиенты с просроченными парами из `purchase_cycles`, сортировка общим
ранжированием (как у остальных пресетов — принцип единого скоринга),
в строке — число просроченных SKU и сумма типового объёма.
Сегодня список = 53 клиента на ~6,1 млн ₽.

Провал в клиента — таблица просроченных пар: товар, обычный интервал,
дней просрочки, типовое количество/сумма, остаток на складе.
Действия из строки: позвонить (`CrmCall`), письмо (`CrmEmail`, черновик
с перечнем — паттерн back-in-stock), собрать дайджест (появится в up-06 —
до того кнопка скрыта).

### Вкладка «Сигналы» в карточке клиента

Все слои по клиенту одним экраном:
- просроченные циклы (слой 1);
- дыры матрицы (слой 3, `GapAnalysisService` + сравнение с «похожими» по
  `business_type`/`price_segment`/`specialization`, агрегаты от ≥5 клиентов);
- новинки/возвраты/уценка в его категориях (слои 4–6);
- фильтры-табу применены и **видимы**: «скрыто N сигналов по табу-категориям» —
  чтобы менеджер видел, что профиль работает, и хотел его заполнять.

Существующий back-in-stock контур подключается сюда же: его предложения
видны на вкладке, его защита от повторов (`CrmBackInStockOffer`) остаётся.

### Витрина для ИИ-агента менеджеров

Вьюхи analytics по циклам/сигналам + гранты — агент отвечает на
«что у моего клиента заканчивается».

## Критерии готовности

- [ ] Пресет в Возможностях с общим ранжированием и причиной у каждой строки
- [ ] Вкладка «Сигналы»: все слои, табу-фильтры применены и показаны счётчиком
- [ ] Выручка/обороты — только через `ShipmentAnalyticsService` (второго движка не появляется)
- [ ] Действия: звонок, письмо-черновик из строки
- [ ] Вьюхи + `bi:sync-grants`
- [ ] UI на русском; feature-тесты; браузерная проверка на dev
