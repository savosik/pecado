## Описание

Сейчас ИИ-агентам приходится **не верить собственному API**. В ответах висят предупреждения:

> «Это остаток по документам, а НЕ долг клиента… На вопрос "сколько клиент должен" отвечайте
> по `payment.balances`»

> «Сколько клиент должен» — только `contractor_balances`. …на реальных клиентах сумма по
> документам оказывалась в 5–20 раз больше настоящего долга»

После перехода долг — это долг. Костыли снимаются, и это лучший индикатор, что эпик сделан.

## Что делаем

### Аналитический MCP (`app/Mcp/Servers/AnalyticsServer.php`)

Переписать денежный раздел инструкций (стр. ~60–95). Убрать «деньги ≠ отгрузка», «план ≠ факт»,
«только `contractor_balances`». Заменить на прямые формулы из
[эпика](2026-08-09_fin-00-epic.md#как-считается-всё-что-нужно-бизнесу):

```
Фактический баланс:  SUM(amount) WHERE nature='fact' AND date <= :on_date
Долг сейчас:         SUM(amount - settled_amount) WHERE nature='plan' AND date <= today
Просрочка:           то же, date < today
Поток по дням:       то же, date > today, GROUP BY date
Переплата:           GREATEST(SUM(amount) WHERE nature='fact', 0)
```

Обязательно оставить **одно** предупреждение — про знак: `amount` со знаком, «+» в пользу
клиента. Агент, не знающий этого, выдаст долг с обратным знаком и не заметит.

Вьюхи `analytics` — добавить `v_settlement_entries` с человекочитаемыми подписями типов
(`type_label`) и разрезами. `php artisan bi:sync-grants` после миграции — иначе `bi_agent`
таблиц не увидит.

Реестр — `app/Services/Crm/Api/OperationRegistry.php:133-243`. Право `crm-clients.view`,

знака и указание, что регистр ведётся с 01.01.2026.

## Edge-кейсы

- **Флаг `SETTLEMENTS_LEDGER_ENABLED` выключен** → старые операции работают, предупреждения
  на месте. Снимать их только вместе с флагом, иначе агент начнёт врать с полной уверенностью.
- **Агент спрашивает про период до 01.01.2026** → явный ответ «регистр ведётся с этой даты»,
  а не пустой результат.
- **Клиент вне скоупа менеджера** → пусто, как сейчас; факт запроса не подтверждаем.
- **Удаление `payment.unpaid-shipments`** — ломающее для существующих агентов. Оставить на
  переходный период отдающей ошибку с текстом «используйте `settlement.balance`», удалить
  в `fin-11`.
- **Себестоимость** остаётся в `CONFIDENTIAL_COLUMNS` — регистр её не раскрывает.
