# contact-08 · Мастер наполнения из данных сайта

**Приоритет:** средний
**Создано:** 2026-08-22
**Эпик:** [contact-00](2026-08-22_contact-00-epic.md)
**Зависимости:** [contact-02](2026-08-22_contact-02-section.md)
**Оценка:** ~2 дня

## Описание

Третий путь наполнения — и самый быстрый. Адреса и телефоны в системе уже есть, просто лежат
не карточками. Мастер предлагает кандидатов, менеджер подтверждает пачкой.

## Источники и что в них есть на проде

| Источник | Объём |
|---|---|
| `companies.email` / `companies.phone` | 442 почты из 1440 контрагентов |
| `users` (клиенты) — имя, почта, телефон | 824 с почтой |
| Адресаты `sent_emails` и `crm_emails.to/cc` | 3768 записей журнала |
| `entity_subscriptions.destination` | валидированные адреса, заведённые самими клиентами |
| `crm_leads` — имя, телефон, почта, мессенджер, ЛПР | контакты до конверсии; после `converted_user_id` становятся контактами партнёра |

## Как работает

Команда `contacts:seed-from-corpus --dry-run` печатает сводку по источникам; экран «Собрать
контакты» показывает кандидатов с галочками. `source = 'directory_import'`.

Повторный прогон не плодит дублей: сверка по почте и `phone_digits` с учётом мягко удалённых.
Кандидат, у которого нет ни почты, ни телефона, не предлагается вовсе.

Подтверждение — обязательно и пачкой. Автоматически заводить 442 карточки нельзя: часть почт
контрагентов — общие ящики (`info@`, `zakaz@`), и человек за ними не стоит. Менеджер это видит
и решает.

## Критерии готовности

- [ ] `--dry-run` печатает сводку по каждому источнику
- [ ] Экран с кандидатами, подтверждение пачкой
- [ ] Повторный прогон не создаёт дублей
- [ ] Кандидат без почты и телефона не предлагается
- [ ] Лид после конверсии превращается в контакт партнёра
