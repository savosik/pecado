# mail-01 · Папки в письмах

**Создано:** 2026-08-21
**Эпик:** [mail-00](2026-08-21_mail-00-epic.md)
**Зависимости:** нет — стартовая карточка
**Оценка:** ~2 дня

## Описание

Сейчас `/crm/emails` — один плоский список с фильтрами по статусу. Работает, но
не даёт ориентироваться: непонятно, что ждёт отправки, а что уже ушло.

Раскладываем по папкам. Это не новая сущность, а другой показ того же списка:
статус письма и есть папка.

```
Черновики      status = draft         ждут отправки, здесь самолётик
Отправленные   status = sent
Не ушли        status = failed        ошибка адреса, отписка
Мимо фильтров  (появится в mail-07)
```

## Что делаем

- Боковой список папок со счётчиками вместо фильтра по статусу.
- «Черновики» открываются по умолчанию: это рабочая папка.
- В строке письма видно, кто его создал: менеджер или система (значок + подпись).
  Пока автоматических писем нет, все письма менеджерские — колонка появляется заранее,
  чтобы потом не переучиваться.
- Массовые действия в «Черновиках»: отправить выбранные, удалить выбранные.
- Поиск по теме, адресу и клиенту работает внутри текущей папки.

## Чего НЕ делаем

Не трогаем механику отправки: тот же самолётик, тот же `SendCrmEmailJob`,
тот же журнал. Меняется только раскладка списка.

## Критерии готовности

- [ ] Папки со счётчиками; «Черновики» открываются первыми
- [ ] В строке письма видно, кем оно создано
- [ ] Массовая отправка и удаление в «Черновиках»
- [ ] Поиск работает внутри папки
- [ ] Существующие тесты `/crm/emails` зелёные без правок
- [ ] Весь интерфейс на русском; Chakra из `@/components/ui/*`
