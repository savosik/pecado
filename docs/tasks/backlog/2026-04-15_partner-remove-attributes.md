# Убрать атрибуты "Наша компания" и "Координаты" у контрагентов (Company)

**Приоритет:** средний
**Исполнитель:** -
**Создано:** 2026-04-15

## Описание

У контрагентов (модель `Company`) необходимо убрать атрибуты "Наша компания" (`is_our_company`) и "Координаты" (`latitude`/`longitude`).

## Критерии готовности

- [ ] Создана новая миграция для удаления колонок `is_our_company`, `latitude`, `longitude` из таблицы `companies` (в соответствии с правилами не менять старые миграции).
- [ ] Обновлена модель `Company` — атрибуты удалены из свойств `$fillable` и `$casts`.
- [ ] Внесены изменения в админку (`CompanyController` и соответствующие React-компоненты/страницы) — убраны поля ввода для этих атрибутов.
- [ ] Убрана карта для контрагента из админки (React-компоненты).
- [ ] Обновлены ERP-обработчики, валидация Request-ов (FormRequests), DTO и фабрики (`CompanyFactory`), если эти атрибуты в них задействованы.
