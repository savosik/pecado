# up-04: сопутствие в корзине и пост-заказное окно

**Приоритет:** средний
**Эпик:** [up-00](2026-08-14_up-00-epic.md)
**Зависит от:** up-02; вердикт up-01 по консолидации отгрузок
**Создано:** 2026-08-14

## Описание

Две первые клиентские поверхности. Обе за флагом `UPSELL_ENABLED`.

### Корзина: «к товарам в корзине»

Блок под составом корзины (не рядом с кнопкой оформления — **не конкурировать
с чекаутом**): расходники/уход/питание к тому, что уже в корзине.

- Источник: `product_complements` (подтверждённые) + пары `stats` с высоким
  score; **приоритет — SKU, которые клиент уже покупал** (пополнение
  безрисково), незнакомое — после и меньше.
- Сегодняшняя точка отсчёта: смазки в 31 % «игрушечных» заказов, уход в 8 %,
  батарейки в 0,2 % — рост attach rate и есть метрика этой поверхности.
- Сквозные фильтры эпика (табу, остаток, индивидуальные цены) обязательны.
- Добавление в корзину из блока → `upsell_signals` `added_to_cart`
  с `surface = cart`.

### Пост-заказ: экран подтверждения + письмо (окно 0–4 часа)

69 % дозаказов происходят в первые 4 часа сами — окно уже живёт, ему нужна
подсказка и консолидация.

- **Экран «заказ оформлен»**: блок «Забыли что-то? До начала сборки можно
  дозаказать — уедет одной отгрузкой»: слой 1 (просроченные циклы клиента)
  + слой 2 (сопутствие к только что заказанному). Никаких новинок.
- **Письмо-подтверждение заказа**: тот же блок сжато (топ-3 + ссылка).
- Формулировка «одной отгрузкой» показывается **только** если up-01 подтвердил
  консолидацию и заказ ещё в статусе до сборки; иначе — нейтральное
  «можно дозаказать». Врать про логистику нельзя.
- Дозаказ — обычный заказ через корзину; `upsell_source = post_order`.

## Критерии готовности

- [ ] Блок в корзине: приоритет уже покупавшегося, фильтры эпика, не конкурирует с оформлением визуально
- [ ] Экран подтверждения + письмо с блоком дозаказа; плашка про отгрузку строго по правилу up-01
- [ ] Все показы/клики/добавления пишутся в `upsell_signals` с поверхностью
- [ ] Живой сигнал по паре не дублируется между поверхностями
- [ ] Замер до/после: attach rate смазок и ухода — цифры в карточку ревью
- [ ] UI на русском; мобильная вёрстка письма (Mailpit); флаг выключен → поверхности отсутствуют полностью
