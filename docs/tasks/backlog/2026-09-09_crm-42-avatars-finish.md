# crm-42 · Дорисовать аватарки партнёров после пополнения OpenRouter

**Приоритет:** низкий
**Создано:** 2026-09-09
**Блокировано:** баланс OpenRouter (решение РОПа 09.09.2026 — пока не пополняем)
**Связано:** [crm-41](../review/2026-09-08_crm-41-partner-avatars.md) (сама функция, в бою)

## Где остановились

Аватарки работают на проде: загрузка менеджером, рисование ИИ в два хода, превью
по наведению, портретный промт. Прогон по партнёрам Сухова и Курочкиной (210 человек)
уперся в баланс.

| | |
|---|---|
| Нарисовано и лежит на диске | **38** |
| Осталось без картинки | **172** |
| Причина | `402 This request would exceed your credit balance` (≈85 подряд), плюс 5 осечек «модель не вернула изображение» |

Битых ссылок нет: записи без файлов обнулены, `rsync --delete` больше не стирает
`storage/app/private` (фикс `9c6a2f54`).

## Что сделать, когда баланс появится

```bash
# на проде, из /srv/pecado
docker compose -f docker-compose.yml -f docker-compose.prod.yml exec -T app \
  php artisan crm:avatars-generate --manager=Сухов --manager=Курочкина --limit=300 --force
```

`--force` обязателен: у 172 партнёров счётчик попыток уже не нулевой, и без него
команда будет ждать суточной паузы после осечки. Ручные аватарки `--force` не трогает.

Проверить после прогона:

```bash
php artisan tinker --execute="
echo App\Models\CrmClientAvatar::whereNotNull('path')->count();
echo App\Models\CrmClientAvatar::whereNull('path')->where('attempts','>',0)->count();"
```

Прикинуть расходы заранее: один партнёр — два обращения (текст + картинка),
210 партнёров ≈ 420 обращений. Остальной отдел (Трипуть, 610 партнёров) —
отдельное решение, автоматом не запускать.

## Пока баланса нет

Ночная пачка `crm:avatars-generate` стоит в расписании на 04:40 и каждую ночь будет
получать 402. Денег это не стоит (запрос отбивается до списания), но счётчик попыток
дойдёт до `max_attempts` (3) за две-три ночи, после чего партнёры выпадут из отбора
до ручного `--force` — то есть само по себе ничего не сломается и не потратится.

Если шум в логах мешает — выключить генерацию, не трогая уже нарисованное:

```
CRM_AVATARS_AI_ENABLED=false   # в /srv/pecado/.env, затем artisan config:cache
```

Загрузка аватарок менеджером и показ существующих при этом продолжают работать —
флаг гасит только рисование.

## Хвосты поменьше

- 5 партнёров получили «модель не вернула изображение» — обычная осечка модели,
  лечится тем же повторным прогоном.
- Стоит посмотреть глазами уже нарисованные 38 и решить, устраивает ли тон и план,
  **до** того как тратить остаток: правка промта после массового прогона означает
  перерисовку всей пачки за деньги.
