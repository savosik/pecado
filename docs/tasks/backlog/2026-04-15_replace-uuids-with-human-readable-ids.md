# Замена UUID на человекочитаемые номера (Заказы и Реализации)

**Приоритет:** средний
**Исполнитель:** -
**Создано:** 2026-04-15

## Описание

UUID (например, `550e8400-e29b...`) не информативны для пользователей и менеджеров. Необходимо заменить их отображение на комбинацию "Номер + Дата" во всех разделах личного кабинета и панели администратора.

## Требования

### Backend
- [ ] **Миграция для Реализаций:** Добавить поле `number` в таблицу `shipments`.
- [ ] **Обновление Handlers:**
    - В `HandleShipmentCreated` / `HandleShipmentUpdated` добавить сохранение номера из сообщения 1С.
    - Убедиться, что для заказов номер также корректно синхронизируется.
- [ ] **API ресурсах:** Убедиться, что `number` и `date` возвращаются во всех API ответах для заказов, реализаций и возвратов.

### Frontend (Личный кабинет)
- [ ] **Заказы:** Заменить `uuid` на "Заказ №... от [дата]" в списке и на странице просмотра.
- [ ] **Реализации:** Заменить `uuid` на "Реализация №... от [дата]" в списке и на странице просмотра.
- [ ] **Возвраты:** Аналогично, если есть номер в 1С.

### Панель администратора
- [ ] Обновить все таблицы и страницы просмотра (Orders, Shipments, Returns), заменив UUID на Номер + Дата.
- [ ] Проверить поиск: поиск по номеру должен работать так же хорошо, как и по UUID.

## Критерии готовности

- В личном кабинете пользователя UUID не отображаются.
- В админке UUID заменены на Номера во всех основных списках и детальных страницах.
- Реализации имеют поле `number`, заполняемое из 1С.
