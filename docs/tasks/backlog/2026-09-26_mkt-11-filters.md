# mkt-11. Фильтры каталога: «Продавец» и «НДС» сверху, рядом с «Наличие»

**Приоритет:** средний · **Создано:** 2026-09-26 · **Переписано:** 2026-10-03 · **Волна:** 2 · **Эпик:** mkt-00
**Зависит от:** mkt-09
**Оценка (ориентир):** 1,5–2 дня

## Описание

**Решение заказчика 03.10.2026 (п. 7): фильтры сверху, в строке управления рядом с «Сортировка» и «Наличие»**,
два выпадающих списка — **«Продавец»** и **«НДС»**. **Фильтра по складу нет** (п. 5, склад клиенту не
показываем).

- Значения строятся из предложений, фактически доступных клиенту (mkt-05): чего не открыто префильтром —
  того нет в списке. Это слой сужения, не расширения.
- **Фильтр с одним значением скрыт** — клиенту с одним продавцом и одной ставкой строка управления не
  усложняется.
- Фильтр оставляет товары (плитки), у которых есть такое предложение: строится как сегодняшний «в наличии /
  под заказ» — `whereExists` по таблице предложений, без переиндексации поиска.
- Подписи ставок — тексты от 1С («НДС 5 %», «НДС 22 %», «без НДС»); продавцы — торговыми именами.
- На телефоне строка управления уже плотная — проверить вёрстку (риск назван в опросе).

Известные классы багов фильтров проекта: round-trip ключа, объект вместо тега, потеря значения в коллекции
(`feedback_filter_bug_classes`).

## Критерии готовности

- [ ] «Продавец» и «НДС» — выпадающие списки в строке управления сверху; слева, в боковой панели, их нет
- [ ] Значения — только из доступных клиенту предложений; фильтр с единственным значением скрыт
- [ ] Значения переживают перезагрузку страницы и пагинацию
- [ ] Русские подписи, счётчики совпадают с выдачей
- [ ] На телефоне строка управления не ломается
