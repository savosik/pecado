# Промо 14 — Компактный конструктор правил

**Приоритет:** средний
**Создано:** 2026-07-28
**Roadmap:** [docs/promo-constructor-roadmap.md](../../promo-constructor-roadmap.md)
**Зависит от:** [promo-03-admin-constructor](../review/2026-07-27_promo-03-admin-constructor.md)

## Контекст

Первая же реальная акция показала, что форма громоздкая. Одна карточка условия — это
переключатель «вся корзина», селектор товаров, две колонки категорий и брендов, чекбокс
подкатегорий, теги, чекбоксы групп 1С, сегмент «считать», выбор сравнения и поле порога.
Карточка награды — ещё десяток полей. Два условия и две награды дают форму на несколько
экранов, при том что в реальной акции почти все поля остаются пустыми.

Список правил тоже разъезжается: восемь колонок, из которых «Условие» и «Награда» —
длинные текстовые строки.

## Задача

Сократить путь «настроить типовую акцию» до нескольких полей, не теряя возможности
настроить нетиповую.

**Форма условия.** Свернуть селекторы в один компонент «Что попадает под условие» с
выбором типа (товары / категории / бренды / теги / группы 1С / вся корзина) — вместо
шести всегда развёрнутых блоков. Пустые селекторы не показывать вовсе; добавлять по
кнопке «ещё критерий».

**Карточки списком.** Условия и награды в свёрнутом виде — по строке: «Количество товаров
«…» ≥ 6 шт.» с раскрытием по клику. Сейчас всё всегда развёрнуто.

**Награда.** Поля «вид промо-позиции», «склад-источник» и «кратность» прятать под
«Дополнительно»: в типовой акции это подарок за 0 ₽ с обычного склада один раз.

**Список правил.** Группировать по акции: строка акции с числом правил, правила —
вложенным списком. Сейчас пятнадцать правил одной акции идут вперемешку с остальными.

## Нюансы

- **Chakra — только через `@/components/ui/*`**, недостающие компоненты ставить через
  CLI (`npx @chakra-ui/cli snippet add …`). Обратите внимание: CLI пишет в `src/`, файлы
  нужно перенести в `resources/js/components/ui/`.
- **Никаких тяжёлых эффектов** — see `feedback_ui_effects_minimal`: анимации раскрытия
  минимальные, без «вау».
- **Ширина.** Проверить на узком экране: сейчас таблица списка скроллится внутри
  `DataTable`, при группировке это не должно сломаться.
- Форму трогаем **после** [promo-13](2026-07-28_promo-13-per-item-multiplicity.md), если
  та поменяет модель кратности, — иначе переделывать дважды.

## Критерии готовности

- [ ] Типовая акция «за N штук — подарок» настраивается без раскрытия «Дополнительно».
- [ ] Форма с двумя условиями и двумя наградами помещается в один-два экрана.
- [ ] Список правил читается, когда у одной акции полтора десятка правил.
- [ ] Проверено на узком экране.
