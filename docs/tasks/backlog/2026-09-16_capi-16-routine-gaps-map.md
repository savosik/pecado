# capi-16: карта «рутина без менеджера — чего не хватает» (без кода)

**Приоритет:** низкий
**Создано:** 2026-09-16
**Эпик:** capi-00
**Зависимости:** нет; актуализируется при закрытии каждой волны

## Описание

Цель эпика — чтобы клиент через агента решал рутину без менеджера. Часть рутины API закрывает
данными, которые уже есть; часть упирается в отсутствующие домены или решения 1С. Эта карточка —
реестр зависимостей: что закрыто в capi-00, что ждёт чужих эпиков, и что агент направляет в
`client-ask-manager`. Источник списка рутины — аудит доставок 04.09.2026 (`docs/delivery-audit/`),
эпики doc-00, res-00, up-00, pcol-00, debt-00, chat-00.

| Рутина клиента | Как сейчас | В capi-00 | Куда дальше |
|---|---|---|---|
| Цены, остатки, поиск, штрихкод | legacy API / витрина | capi-04 | — |
| Статус заказа, состав, изменения от 1С | кабинет | capi-05 | — |
| Оформить заказ, повторить, отменить | кабинет / звонок | capi-06, capi-08 (отмена — за `ORDER_RESERVE_ENABLED`) | включение режима — решение заказчика + готовность 1С |
| Резерв: подтвердить, уменьшить, снять | звонок менеджеру | capi-06 (за флагом) | то же |
| Счёт, УПД, счёт-фактура, акт сверки | письмо/звонок → 1С → PDF | capi-10, capi-11 (за `DOCUMENTS_ENABLED`, `CABINET_FINANCE_*`) | включение флагов после сверки цифр с 1С (doc-00, fin-*) |
| Сколько должен, по каким накладным, когда платить | менеджер смотрит в 1С | capi-11 (за флагом) | то же |

| Объединить заказы в одну отправку | переписка с менеджером/складом | нет | ERP-протокол (консолидация, вопрос 1С), эпик доставки («корзина отправки») |
| «Жду предзаказ, не отправляйте частями» | договорённость в голове менеджера | нет; временно — `comment` в `orders.create`/`checkout.submit` | ERP/res-00: пометка на заказе и в протоколе |

| Когда приедет предзаказ | устно «7–9 дней» | `profile.get` отдаёт срок из `config/preorder.php` | ERP: фактическая дата по позиции |
| «Что мне пора закупить» | менеджер звонит | нет; секция `insights` зарезервирована | up-00 (up-02 циклы, up-06 закупочный лист), pcol-00 — после них `insights.replenishment` |
