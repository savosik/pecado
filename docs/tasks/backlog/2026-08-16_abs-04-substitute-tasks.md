# abs-04: замещение в задачах по недоборам + напоминание о сдаче табеля

**Приоритет:** низкий (опционально)
**Создано:** 2026-08-16
**Эпик:** `abs-00`

## Что сделать

1. **Задачи по недоборам — замещающему.** Сейчас
   `SubstitutionOfferService`/`SubstitutionsFollowUp` назначают задачу учётке
   `order.user.personalManager.user` с fallback «первый sales-head». На время
   отсутствия менеджера назначать `ManagerAbsenceResolver::effectiveManager($card)->user`,
   fallback не трогать.
2. **Напоминание о сдаче табеля.** Scheduled-нотификация РОПу (право
   `crm-timesheet.view`) за 2 рабочих дня до конца месяца: «Пора сдавать табель ОП
   за {месяц}» со ссылкой на /crm/timesheet. Образец —
   `app/Notifications/Crm/TaskAssignedNotification.php`.
3. Опционально: протухшие лиды (`CrmLeadsRemindStale`) — задача замещающему.

## DoD

- Тесты: задача по недобору уходит замещающему в период отсутствия и менеджеру вне его.
- Напоминание не дублируется при повторном запуске в тот же день.
