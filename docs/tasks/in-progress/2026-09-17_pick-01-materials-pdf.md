## Описание

Новый график не должен стать снегом на голову. Три документа в PDF (Markdown адресаты не
открывают), исходники рядом, чтобы пересобрать после изменений интерфейса.

Папка `docs/pickup/`: `_src/*.src.html` → `*.pdf`. Сборка как принято в проекте:

```
google-chrome --headless=new --no-pdf-header-footer --print-to-pdf=docs/pickup/<имя>.pdf file://…/_src/<имя>.src.html
```

Оформление: постраничный шаблон из `docs/shortage-manager-manual.html` (`.page` 210×296 мм,
колонтитул со страницами), фирменный бордовый `#9e1b32`, шрифт Jost из `public/fonts/jost/`,
логотип `public/logo.png`. Скрипт сборки — `docs/pickup/build.sh`.

1. **`buklet-klientam.pdf` — для владельцев и операторов интернет-магазинов.**
   Зачем это магазину (вечер и суббота — пик спроса, срочные заказы, конкуренция с доставкой
   маркетплейсов за 4 часа); схема цикла на одной картинке; шаги со скриншотами: резерв в
   чекауте, раздел «Резервы», «В отгрузку», «Отменить», стадии заказа, раздел «Самовывоз»,
   пропуск курьеру; памятка курьеру на отдельной странице (можно переслать одну её): адрес,
   часы, что показать, как забрать часть заказов; правило 20:00; «менеджеры на связи пн–пт
   9–18, всё остальное работает без них»; вопросы и ответы (долг, недобор, истёк резерв,
   потерял пропуск, два курьера).
2. **`instrukciya-sklad.pdf` — для кладовщиков.** Крупно, по шагам, для чтения с телефона и
   для распечатки у стойки: как открыть экран, три вкладки, скан пропуска, ввод кода, выдача
   по одному и «Выдать всё», частичная выдача, скан расходного листа, курьер без пропуска,
   ошибочная выдача и отмена, просрочка SLA, закрытие смены в 21:00, куда писать при сбое.
3. **`instrukciya-otdel-prodazh.pdf` — для менеджеров и РОПа.** Что изменилось, что клиент
   теперь делает сам, готовые ответы клиентам, где смотреть стадию заказа и факт выдачи,
   утренняя сводка, что считается форс-мажором, долг как единственный стоп, как включить
   клиенту режим резервов.

Скриншоты: `puppeteer-core` с системным Chrome против локального стенда, демо-клиент, без
реальных клиентских данных. Экраны резервов снимаются сразу. Новые экраны (стадии, самовывоз,
склад) в первой редакции — макеты в стиле интерфейса, заменяются снимками после волн 1–2.

## Критерии готовности

- [x] Три PDF собраны, постранично проверены, A4 без обрезки.
- [x] Памятка курьеру — самостоятельная страница (стр. 7 буклета).
