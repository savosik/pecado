# «Документы» в кабинете: привести к стайлгайду кабинета (не «серым по серому»)

**Статус:** todo, поставлено 2026-08-29
**Повод:** заказчик 29.08 показал `/cabinet/documents` (просмотр от имени партнёра) —
раздел серый на сером. Постановка от 28.08 («в кабинете есть разделы не по стайлгайду»)
была понята наоборот: «Документы» взяли за эталон и подогнали под них «Уведомления»,
«Договоры», «Контакты» (`6b4815b1`, `3da93d7a`). Сами «Документы» не трогали, карточки
задачи не было — потерялась.

## Что не так сейчас (`resources/js/Pages/User/Cabinet/Documents/Index.jsx`)

- Строка документа — `Box` без `bg="bg"`: на сером фоне контента карточка сливается
  с подложкой; нет hover-состояния (у «Мои заказы» — `borderColor: pecado.200`, `shadow: sm`).
- Почти весь текст строки — `fg.muted`: период, контрагент, продавец, размер, дата.
  Читается только номер. Вторая строка целиком серая.
- Бейдж вида документа мелкий `subtle`, без иконки типа; формат «Excel (XLSX)» —
  ещё один зелёный бейдж в той же строке, шум.
- Панель фильтров — голый `Card.Root` без `bg`/`borderRadius="xl"`, отличается от карточек списка.
- Кнопка «Скачать» — `outline sm`, теряется; размер «0 МБ» — бессмысленная подпись
  (бэкенд не знает размера — либо не показывать, либо считать).
- Пустое состояние — тоже голый `Card.Root`, не как в «Мои заказы» (круг `bg.muted` + иконка).

## Эталон

`Orders/Index.jsx` («Мои заказы»): `bg="bg"`, `borderRadius="xl"`, `border.muted`, `p="4"`,
hover с `pecado.200` + `shadow="sm"`, мета-строка мелкая, название/номер — `fg` и весом 600,
разделители групп по дате. Заголовок и кнопки — только через `<CabinetLayout title actions>`.

## Сделать

1. Карточка документа: `bg="bg"`, hover как у заказов; номер + вид документа — основным
   цветом; контрагент — `fg` (это главное после номера), период/продавец — `fg.muted`
   мелко; иконка по типу документа слева (счёт / УПД / акт сверки / договор) в круге
   `bg.muted` как аватар в заказах.
2. «Скачать» — `solid` `pecado` или `outline` с заметной иконкой, единая ширина; формат
   файла подписью у кнопки (`PDF` / `XLSX`), а не бейджем в заголовке.
3. Размер: убрать «0 МБ», пока бэкенд не отдаёт настоящий `size`.
4. Панель фильтров и пустое состояние — те же карточки (`bg="bg"`, `xl`, `border.muted`).
5. Группировка по дате (как «Одно оформление…» в заказах) — опционально, если список
   на день длинный (акты сверки идут пачками по 200+ в ночь).
6. Сверить глазами на локальном стенде с «Мои заказы» и «Отгрузки», а не только ESLint.
   Проверить тёмную тему.

## Не делать

- Не менять контроллер/бэкенд «Документов» (кроме `size`, если решим считать).
- Не трогать `CabinetLayout` — заголовок уже верный.
