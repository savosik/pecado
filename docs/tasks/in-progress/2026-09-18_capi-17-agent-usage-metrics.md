# capi-17: Метрики использования MCP `/mcp/client` и API v1 — экран «ИИ-агенты клиентов»

**Приоритет:** высокий
**Создано:** 2026-09-18
**Эпик:** capi-00
**Зависимости:** capi-14 (сервер MCP), capi-01 (реестр и REST v1)
**Ветка:** `feature/mcp-metrics`

## Описание

Заказчик (РОП, 18.09.2026): «нужно поставить метрики, пользуются ли клиенты MCP-сервером, кто и как часто,
и какие именно задачи — чтобы оценивать, насколько это полезный инструмент». До этого о пользовании
говорили только `api_tokens.last_used_at` (раз в минуту) и лог `client-agent` (только записи).

1. **Журнал `client_agent_calls`** — одна строка на подключение агента (`initialize` → `mcp_connect`,
   с `clientInfo` «claude-code 2.1.0» и сессией), на вызов инструмента (`mcp_tool`: инструмент, операция
   реестра, юрлицо, признак записи, исход, код отказа, длительность) и на REST-запрос v1 (`rest`).
   Аргументы и ответы **не хранятся** — журнал отвечает «кто, когда, что, с каким исходом».
   Ретенция `CLIENT_AGENT_CALLS_RETENTION_DAYS` (365), `model:prune` 05:15.
2. **Точки записи**: `ClientServer` переопределяет `handleInitializeMessage` / `runMethodHandle`
   (`tools/call`), `RecordClientApiUsage` — middleware группы `/api/client/v1`. Операцию и юрлицо
   отмечает `OperationRunner` через `UsageContext` (scoped-синглтон), коды отказов — трейт
   `InteractsWithClientOperations::refuse()`. Сбой журнала не ломает вызов (`report()`).
3. **Экран `/crm/agent-usage`** (право `crm-agent-usage.view`, менеджерам и РОПу; группа меню
   «Аналитика»): период 7/30/90/365, разрез «мои / отдел»; плитки «партнёров с агентом из N с токеном»,
   подключения/сессии, вызовы MCP+REST, % отказов, заказов через агента, вопросов менеджеру; график по
   дням; таблица партнёров (глаз → `/crm/agent-usage/{client}` — журнал вызовов); «какие задачи решают»
   (операции реестра по summary), «какими агентами подключаются», «частые отказы», «токены без вызовов
   за период».

## Критерии готовности

- [x] `initialize` пишет `mcp_connect` с агентом и сессией; `tools/call` — `mcp_tool` с инструментом,
      операцией, юрлицом, исходом и агентом сессии; REST — `rest` с операцией из маршрута (`ClientMcpUsageTest`).
- [x] Неавторизованный запрос строки не оставляет; сбой журнала не ломает вызов.
- [x] Экран: сводка, разрез «мои / отдел», период, карточка партнёра, 404 на чужого, 403 без права
      (`AgentUsageTest`); `PermissionNamingTest` зелёный (три реестра прав).
- [x] Комментарии к таблице и столбцам в миграции.
- [ ] На проде после миграции: `bi:sync-grants` (новая таблица — журнал не конфиденциален, BI-агенту виден).
- [ ] Прогон реальным MCP-клиентом на dev: в «Какими агентами подключаются» появляется настоящее имя клиента.
