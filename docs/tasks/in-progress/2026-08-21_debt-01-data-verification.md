# debt-01: сверка балансов с 1С и включение финансов кабинета

**Приоритет:** высокий
**Эпик:** [debt-00](2026-08-21_debt-00-epic.md)
**Создано:** 2026-08-21

## Описание

Предпосылка №0 всего эпика: система имеет право ограничивать клиента только по цифрам,
которым мы верим. `CABINET_FINANCE_ENABLED` выключен с 2026-08-09 именно из-за
недоверия (долг завышался в 5–20 раз до фикса зачёта авансов).

### Команда сверки `debt:verify-balances`

Сравнивает по каждому контрагенту три источника:
1. `contractor_balances.current_balance / overdue_debt` (мастер 1С);
2. расчёт сайта по графикам (`PaymentForecast::overdueOnly()`, остаток строк
   `amount − paid − prepaid`);
3. регистр взаиморасчётов (`settlement_entries`), где включён.

Выход — отчёт расхождений с порогом `EPSILON`: сколько контрагентов сходится
копейка в копейку, у кого расхождение и какое. Запуск разовый перед включением
и еженедельно по расписанию (дрейф = ранний сигнал проблем обмена).

### Ручная сверка топ-10

Топ-10 должников дополнительно сверить глазами с бухгалтерией 1С (у Гевеи долг
размазан по 29 юрлицам — именно такие кейсы машинная сверка может «сойтись»
неправильно по частям).

### Пилотное включение кабинета

`CABINET_FINANCE_ENABLED` становится per-user: глобальный флаг + белый список
(поле или конфиг-список id). Пилот — 10–20 сверенных клиентов, через 1–2 недели
без жалоб — включение всем. Механику белого списка не усложнять: это временная
лесенка запуска, после полного включения список умирает.

### Гейт свежести данных

В `config/debt.php` появляется `stale_after_days` (стартово 3): контрагент,
чей `balance_erp_updated_at` старше, автоматически исключается из любой будущей
эскалации (инвариант конституции). Несвежие балансы маркетплейсов (WB/ЯМ молчат
с 04.08) не разбираем — маркетплейсы не пользователи сайта и в автоматику
не входят (профиль `marketplace`, решение 21.08).

## Критерии готовности

- [ ] `debt:verify-balances`: отчёт расхождений, `--strict` для CI/еженедельного запуска
- [ ] Расхождения по каждому из топ-10 должников разобраны и объяснены (или устранены)
- [ ] Белый список пилота работает: участнику виден раздел оплат, остальным — 404 как сейчас
- [ ] `config/debt.php` создан: `stale_after_days`, отсечка 5 000 ₽, grace 5 банковских дней (используются со debt-02)
