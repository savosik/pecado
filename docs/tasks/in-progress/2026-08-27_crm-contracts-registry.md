# Реестр договоров в CRM (`/crm/contracts`)

**Приоритет:** высокий
**Исполнитель:** Claude
**Создано:** 2026-08-27
**Ветка:** `feature/crm-contracts`

## Описание

Перенос Google-таблицы «Реестр договоров» (вкладки «ООО Пекадо», «ИП Елисеев П.А.
(клиенты)», «ИП Кербер (клиенты)», «ИП Кербер (дистры)», «ООО Пекадо Импорт») в CRM.

Колонки таблицы: партнёр, контрагент, номер договора, дата, вариант оплаты
(предоплата / отсрочка / реализация), статус подписания (не отправлен / отправлен /
подписан), менеджер, форма (ЭДО / скан / оригинал), комментарий.

Модель: договор = `contracts` (категория ≈ вкладка таблицы, партнёр `users`,
контрагент `companies`, ответственный `personal_managers`, статус, даты подписания
и срока действия). Тип `contract` в `CrmEntityMap` даёт задачи, комментарии и
вложения (сканы) через существующие полиморфные механизмы.
