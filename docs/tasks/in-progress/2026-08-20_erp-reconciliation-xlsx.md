# Акты сверки в Excel в кабинет клиента раз в сутки (v16.6.0)

**Статус:** in-progress (сторона сайта готова, ждём выгрузку 1С)
**Ветка:** `feature/erp-reconciliation-xlsx`
**Топик Agent Hub:** [#2](https://pecado.ru/admin/agent-topics/2)

## Суть

1С раз в сутки формирует акт сверки взаиморасчётов в XLSX и присылает его тем же
каналом печатных форм (`printed_document.published`, очередь `erp_in.printed_documents`).
Клиент видит актуальный акт в разделе «Документы» личного кабинета, не запрашивая
его письмом у менеджера.

## Договорённости с 1С

| Что | Решение |
|---|---|
| Периодичность | раз в сутки, прогон около 05:00 МСК |
| Период акта | с начала текущего года по вчерашний день |
| Охват | оборот за период ≠ 0 **или** остаток на конец ≠ 0; порога по сумме нет |
| Разрез (ключ `uuid`) | организация × контрагент × валюта × **год** |
| Договоры | сводятся в один акт |
| Формат | XLSX (XLS разрешён схемой, в бою не ожидается) |
| Объём | ≈240 форм в сутки (замер 1С по боевой базе на 20.08.2026) |
| Ежемесячный регламент от 14.08.2026 | отменяется |

Год в разрезе — главное, что нашли в обсуждении: без него суточный прогон 1 января
переписал бы период у прошлогодней формы, и акт за прошлый год исчез бы из кабинета
(сайт хранит одну актуальную версию и перезаписывает файл по тому же `uuid`).

## Сделано на стороне сайта

- **Спецификация:** `mime_type` больше не PDF-only, добавлены `period_from` / `period_to`
  (JSON Schema + AsyncAPI, версия протокола 16.6.0, bundle и HTML пересобраны).
- **Документация:** бизнес-правила, changelog и задание для 1С
  (`guides/printed-documents-for-1c.md`) — MkDocs пересобран.
- **Формат:** `App\Enums\PrintedDocumentFormat` — определение по сигнатуре
  (`%PDF-`, `PK`, `D0 CF 11 E0`), mime и расширение.
- **Перенос файла:** `StorePrintedDocumentFile` принимает PDF/XLSX/XLS, пишет фактический
  mime, кладёт файл с правильным расширением и удаляет осиротевший файл при смене формата.
- **Модель:** `period_from` / `period_to` (миграция с комментариями), `period_label`,
  `format`, имя скачивания с периодом и расширением.
- **Кабинет и CRM:** период и формат в списках, в CRM-экспорте — колонки «Период» и «Формат».
- **Тесты:** приём XLSX с периодом, XLS, расхождение mime с содержимым, смена формата
  без сироты в хранилище, нераспознанный формат → `rejected`, кабинетный показ и скачивание.
