# pay-01: платёжка «бери и плати» в кабинете

**Приоритет:** средний
**Создано:** 2026-08-27 (выделена из эпика дебиторки v1 — полезна всем клиентам, не только должникам)
**Зависит от:** — (debt-01 закрыта как неактуальная 29.08)

## Описание

Готовое платёжное поручение по паре контрагент × наша организация из регистра
(`settlement_entries`: непогашенные строки, документы в назначении платежа);
реквизиты — `organizations` (получатель, отсекать `is_stub`), `company_bank_accounts`
(плательщик). Сценарии суммы: просрочка / весь долг / конкретный документ.

Форматы — начать с **одного**: PDF с QR ГОСТ Р 56042. Файл `1CClientBankExchange`
— второй шаг, после проверки загрузкой в реальный клиент-банк.

Кнопка «отправить бухгалтеру»: контакт из `client_contacts` (роль accountant)
или новый email (сохраняется в адресную книгу). Отдельной таблицы не заводить,
пока не понадобится измерять конверсию.

## Критерии готовности

- [ ] `PaymentOrderService`: назначение платежа из документов пары — юнит-тесты сценариев
- [ ] Кабинет: контрагент → организация → сценарий → скачать/отправить; русский
- [ ] Письмо через `MailStream` с вложением; новый адрес попадает в `client_contacts`
