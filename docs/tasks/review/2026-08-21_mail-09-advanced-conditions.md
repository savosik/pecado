## Описание

Гибкость сверх «содержит метку». Берётся отдельной карточкой намеренно: основная
модель должна работать и быть понятной без этого.

## Условия по данным клиента

Отдельными условиями, а не склейкой профиля в общую строку:

```
[в заметках клиента есть ▾] [апельсины        ]
[город клиента            ] [Тюмень           ]
[стадия работы            ] [спящий           ]
```

Почему не склейкой: фильтр «Ромашка» поймал бы и клиента «Ромашка», и того, у кого
в заметке «раньше работал в Ромашке», — и объяснить срабатывание было бы нечем.

## Точные пороги

Ступеней (`просрочка:60+`) хватает не всегда. Для случаев вроде «этому клиенту
писать с 45 дней» — числовое условие:

```
[просрочка больше ▾] [45] дней
```

## Выражения

Продвинутый режим для сложных случаев: вместо «содержит» — регулярное выражение.

Даётся вторым уровнем и с обязательным превью: кривое выражение либо молчит,
либо ловит всё, и заметить это можно только по последствиям. Превью показывает
результат до сохранения.

## Критерии готовности

- [ ] Условия по полям профиля клиента отдельными строками
- [ ] Числовые пороги для сумм и дней
- [ ] Режим выражения с превью; ошибка в выражении показывается понятным текстом
- [ ] Обычный режим остаётся по умолчанию: выражения не навязываются
