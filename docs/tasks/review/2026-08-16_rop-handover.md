## Что делает команда `crm:rop-handover`

По умолчанию сухой прогон с отчётом, запись только с `--apply`. Идемпотентна.

1. Учётка Павла (paxa333@gmail.com, была «Большая Красная Шляпа») → имя
   «Елисеев Павел», роль `sales-head`, `user_kind = staff`.
2. Карточка менеджера Астапенко (без erp_uuid, ~620 клиентов) → имя «Елисеев
   Павел», email `sales@pecado.ru`, привязка к учётке Павла. Клиенты, лиды,
   планы и промо-аудитории ссылаются на id карточки — переезжают сами, 1С не
   перетрёт (erp_uuid пуст).
3. Открытые `crm_tasks` и все `crm_task_recurrences` Астапенко → на Павла.
   История (комментарии/звонки/письма/закрытые задачи) не переписывается.
4. Учётка Астапенко: `status = blocked` (middleware разлогинит), снятие ролей
   (fallback задач по недоборам берёт первого sales-head!), отзыв
   `crm_agent_tokens`, удаление `entity_subscriptions`.
