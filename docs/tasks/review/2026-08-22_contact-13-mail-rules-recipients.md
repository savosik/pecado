# contact-13 · Получатель правила по роли контакта

**Приоритет:** средний
**Создано:** 2026-08-22
**Эпик:** [contact-00](../backlog/2026-08-22_contact-00-epic.md)
**Зависимости:** [contact-06](../review/2026-08-22_contact-06-mail-addressbook.md)
**Оценка:** ~1 день

## Описание

Тот самый кейс, ради которого затевался отменённый пульт: «изменения по заказам контрагента
приходят на почту его бухгалтера». Теперь он решается одной строкой в правиле-фильтре, без
отдельного раздела.

## Как

В правилах потока писем ([mail-03](../review/2026-08-21_mail-03-rules.md)) получатели уже
поддерживают спецзначения «клиент» и «менеджер», которые раскрываются по самому письму.
Добавляется третье семейство — по роли контакта:

```
Отправить на   бухгалтер, менеджер
```

Раскрывается в адреса активных контактов этой роли у партнёра письма (а если письмо про
конкретного контрагента — у этого контрагента). Уважает `is_active`, `unsubscribed_at`
и стоп-лист `notification_suppressions`.

Без справочника такое правило пришлось бы заводить на каждого из восьмисот партнёров отдельно —
ровно та беда, из-за которой прошлый подход не взлетел.

## Тонкость: пустая роль — не ошибка

Если у контрагента бухгалтер не заведён, правило просто не даёт этого адресата, а письмо остаётся
с остальными получателями. Причина видна в карточке письма, а не молча теряется.

## Критерии готовности

- [ ] Спецзначение роли в получателях правила, подсказка в форме
- [ ] Раскрывается по партнёру письма и по контрагенту
- [ ] Неактивный, отписавшийся и попавший в стоп-лист контакт адресатом не становится
- [ ] Пустая роль не ломает правило; причина видна в карточке письма
- [ ] Тест на кейсе «изменения по контрагенту → бухгалтеру»

## Сделано 23.08.2026

В получателях правила-фильтра рядом с «клиент» и «менеджер» теперь принимается **роль**:
«бухгалтер», «директор», «закупщик». Раскрывается в адреса активных людей этой роли
у партнёра письма.

Это и есть тот кейс, ради которого затевался отменённый пульт — «изменения по контрагенту
приходят на почту его бухгалтера», — но одним правилом на всю базу и без отдельного раздела.

Пустая роль не ломает правило: у контрагента может не быть бухгалтера, и письмо просто уходит
остальным получателям. Уволившийся и отписавшийся адресатом не становятся. Всё под тестами.
