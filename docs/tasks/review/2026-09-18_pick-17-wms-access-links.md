# pick-17 · Вход кладовщика по ссылке без пароля

**Приоритет:** высокий
**Создано:** 2026-09-18
**Эпик:** [pick-00](../in-progress/2026-09-17_pick-00-epic.md)
**Зависимости:** pick-07
**Волна:** 3

## Описание

Решение заказчика 18.09.2026: логины и пароли кладовщикам не заводим. Начальник склада выпускает в кабинете
склада ссылку «как в Google Docs», кидает её кладовщику в любой мессенджер, при необходимости перевыпускает.

- Таблица `wms_access_links`: одна ссылка — одна учётная запись кладовщика (роль `storekeeper`, технический
  e-mail, случайный пароль), поэтому в журнале выдачи видно, с какого телефона выдали.
- `GET /wms/join/{token}` — вход без пароля с «запомнить меня», редирект на экран выдачи, подсказка добавить
  на главный экран. Секрет хранится хешем (поиск) и зашифрованным (повторный показ). Throttle 20/мин.
- Перевыпуск: новый секрет, `session_version` +1, `remember_token` заменён. Сессии в Redis, удалить чужую
  нельзя — поэтому middleware `EnsureWmsLinkSessionValid` сравнивает версию из сессии с версией ссылки и
  закрывает старые телефоны на первом запросе. Отключение — то же плюс `revoked_at`.
- Раздел `/wms/access-links` (право `wms-access.view/edit`, только `warehouse-head`): выпустить, переслать,
  скопировать, показать QR (кладовщик наводит камеру), перевыпустить, отключить.
- На экране выдачи — баннер установки на главный экран (`PwaInstallBanner`): Android предлагает сам,
  iPhone получает подсказку про «Поделиться → На экран „Домой"».

## Ход работ

- **18.09.2026** — реализовано: миграция, `WmsAccessLink`, `App\Services\Wms\AccessLinkService`,
  `WmsJoinController`, `Wms\AccessLinkController`, middleware в группе `wms`, права по трём реестрам,
  страница `Wms/Pages/AccessLinks/Index.jsx`. Тесты `tests/Feature/Pickup/WmsAccessLinkTest.php` (5),
  `PermissionNamingTest` зелёный.

- **19.09.2026** — по замечанию заказчика вход по ссылке стал «киоском»: учётка ссылки получает роль
  `pickup-operator` («Выдача по ссылке», только `wms-pickups.view/issue`), middleware уводит любые адреса склада
  на экран выдачи, каркас панели без бокового меню и шапки — только логотип, имя и «Выйти» (`kiosk` в пропах,
  `PanelLayout kiosk`). Ссылки, выпущенные раньше с ролью кладовщика, переводятся на новую роль при следующем входе.
  Обычные кладовщики с логином видят панель как прежде. **Не выложено** — ждёт команды.

- **19.09.2026** — по каждой ссылке начальник видит ответственность и загрузку: выдач сегодня / за 7 / за 30 дней /
  всего, отмены, последняя выдача, полоски по часам 9–20 за 30 дней; кнопка «Журнал выдач» (7/30/90 дней): когда,
  кому (клиент, юрлицо), что (заказы, ордер, мест), курьер, способ, код пропуска, отмены и пометки разбора.
  `GET /wms/access-links/{link}/handovers`. Правила пропусков: один комплект — один пропуск. **Не выложено.**

## Критерии готовности

- [x] Кладовщик входит по ссылке без логина и пароля и попадает на экран выдачи.
- [x] Ссылка даёт права кладовщика, но не начальника склада.
- [x] Перевыпуск отключает старую ссылку и разлогинивает телефоны, вошедшие по ней.
- [x] Отключённая и случайная ссылки не входят и не раскрывают, существует ли такая.
- [x] Кладовщик не видит раздел ссылок и не может их выпускать.
- [ ] Проверено на телефоне: вход, установка значком, работа после перевыпуска.
- [ ] Вошедший по ссылке видит только экран выдачи, без меню (киоск).
- [x] По каждой ссылке — статистика загрузки и журнал выдач.
