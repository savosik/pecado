## Контекст

Первая же реальная акция показала, что форма громоздкая. Одна карточка условия — это
переключатель «вся корзина», селектор товаров, две колонки категорий и брендов, чекбокс
подкатегорий, теги, чекбоксы групп 1С, сегмент «считать», выбор сравнения и поле порога.
Карточка награды — ещё десяток полей. Два условия и две награды дают форму на несколько
экранов, при том что в реальной акции почти все поля остаются пустыми.

Список правил тоже разъезжается: восемь колонок, из которых «Условие» и «Награда» —
длинные текстовые строки.

## Задача

Сократить путь «настроить типовую акцию» до нескольких полей, не теряя возможности
настроить нетиповую.

**Форма условия.** Селекторы свёрнуты в блок «Что попадает под условие»: показываются
только заданные критерии, остальные добавляются из списка «+ ещё критерий»
(товары / категории / бренды / теги / группы 1С / вся корзина). Критерий убирается
крестиком — заодно очищается. «Вся корзина» прячет остальные: с ней они не нужны.
Чекбокс «включая подкатегории» переехал внутрь критерия «Категории», где ему и место.

**Карточки списком.** Условия и награды свёрнуты в строку-подпись
(«Количество товаров «…» ≥ 6 шт. (за каждые 6 шт.)»), раскрываются по клику. Подпись
собирается тем же способом, что и на бэкенде в `PromotionRuleDescriber`, чтобы форма и
список правил говорили об одном одинаково. Только что добавленная карточка
раскрывается сразу — иначе непонятно, куда нажали.

**Награда.** «Вид промо-позиции», «склад-источник» и «кратность» убраны под
«Дополнительно». Раздел раскрывается сам, если там что-то настроено, — иначе его не найдут.

**Список правил.** Появился переключатель «Группировать по акции»: акция — карточка с
числом правил и ссылкой на лендинг, правила внутри, группа сворачивается. Группируется
**текущая страница**: пагинация серверная, и делать вид, что в группе все правила акции,
было бы враньём — поэтому в счётчике честно «правил на странице».

## Нюансы

- **Chakra — только через `@/components/ui/*`**, недостающие компоненты ставить через
  CLI (`npx @chakra-ui/cli snippet add …`). Обратите внимание: CLI пишет в `src/`, файлы
  нужно перенести в `resources/js/components/ui/`.
- **Никаких тяжёлых эффектов** — see `feedback_ui_effects_minimal`: анимации раскрытия
  минимальные, без «вау».
- **Ширина.** Таблица внутри группы — тот же `DataTable`, со своим горизонтальным
  скроллом; вёрстка групп на узком экране складывается в колонку (`wrap` в шапке).
- Форма делалась **после** [promo-13](2026-07-28_promo-13-per-item-multiplicity.md),
  поэтому поле кратности сразу встало в строку условия рядом с порогом.

## Критерии готовности

- [x] Типовая акция «за N штук — подарок» настраивается без раскрытия «Дополнительно»:
      наверху остаются «что выдаём», количество и цена.
- [x] Форма с двумя условиями и двумя наградами помещается в один-два экрана —
      свёрнутые карточки занимают по строке.
- [x] Список правил читается при полутора десятках правил одной акции: группировка
      плюс свёрнутая сводка условий из promo-13.
- [ ] Проверено на узком экране — **осталось на ручную проверку**, вёрстка глазами
      не смотрелась.
