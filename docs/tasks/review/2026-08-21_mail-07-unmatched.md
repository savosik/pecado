# mail-07 · Папка «Мимо фильтров» и уборка

**Приоритет:** средний
**Создано:** 2026-08-21
**Эпик:** [mail-00](../in-progress/2026-08-21_mail-00-epic.md)
**Зависимости:** [mail-05](2026-08-21_mail-05-orders-documents.md)
**Оценка:** ~1 день

## Описание

Система собирает письма по всем поводам, но правила ловят не всё. Непойманное надо
куда-то девать, иначе «Черновики» превратятся в свалку и рабочая папка перестанет
работать.

Решение из двух частей.

**Отдельная папка.** Письмо, которое не подошло ни под одно правило, уходит
в «Мимо фильтров» и не мешает в «Черновиках».

**Ретенция.** Живёт две недели и удаляется. Данные не копятся.

## Непойманное — подсказка, а не мусор

Главная польза папки не в уборке, а в том, что по ней видно, чего система умеет
больше, чем от неё сейчас берут:

```
За неделю мимо фильтров прошло:
  недоборы по заказам ......... 340 писем
  акты сверки ................. 41
  просрочка ................... 12

Ни одно правило их не ловит.        [настроить]
```

Кнопка ведёт в создание правила с уже подставленным условием.

## Критерии готовности

- [ ] Непойманные письма в отдельной папке, «Черновики» не засоряются
- [ ] Ретенция две недели, настраивается
- [ ] Сводка по видам непойманного с переходом в создание правила
- [ ] Письмо, пойманное правилом позже (правило завели вчера), переходит в «Черновики»

## Сделано 21.08.2026

- статус `unmatched` = папка «Мимо фильтров»; в «Черновики» непойманное
  не попадает;
- `mail:prune-unmatched` в расписании на 04:40, ретенция
  `MAIL_STREAM_UNMATCHED_DAYS`;
- сводка по видам непойманного с переходом в правила;
- правило, заведённое сегодня, подбирает вчерашние письма
  (`MailRuleEngine::reapplyToUnmatched`) — иначе менеджер настроил бы фильтр
  по сводке и не увидел ни одного письма, ради которого настраивал.

Кнопка «настроить» у каждой строки сводки открывает форму правила с уже
набранным условием (`?tag=…`) — иначе менеджер, увидевший «недоборы: 340»,
попадал бы на пустой экран и переписывал метку руками. Сделано 22.08.2026.
