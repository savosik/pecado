# buf-06: WMS-консоль «Страховой запас»

**Приоритет:** средний (после включения буфера)
**Эпик:** [buf-00](2026-08-16_buf-00-epic.md)
**Зависит от:** buf-01; полная польза — после buf-04
**Создано:** 2026-08-16

## Описание

Управление буфером живёт у склада (решение заказчика 2026-08-16): кладовщик
первым видит и брак на полке, и подозрительно старые экземпляры срокового товара.
Раздел `/wms/stock-buffers`, права `wms-stock-buffers.view|edit`
(по образцу `wms-defects.*`).

### Список рисковых SKU

- Все товары с ненулевым буфером (расчётным или ручным): фото, название, остаток,
  размер буфера, «скрыто N шт».
- Раскладка «почему в списке» из `reasons`: «3 отмены за 90 дн», «2 партии брака»,
  «срок до 02/27», «ручная пометка» — кладовщик видит причину, а не магию.
- Итоговая строка: скрыто всего штук / на сумму по базовым ценам / доля от остатка.

### Ручное управление

- Добавить товар в буфер через поиск (по образцу непрерывного ввода в WMS-разделах):
  задать `manual_qty` — например, «на полке коробка с помятой партией, придержи 2 шт».
- Изменить/снять ручную пометку; расчётный буфер руками не редактируется
  (он пересчитается ночью — для влияния есть `manual_qty`).
- Кто и когда поставил пометку — фиксируется.

### Метрика контроля

Блок в этом же разделе: доля заказов клиентов сегмента с отменёнными строками
по месяцам (движок запроса — как `cancelled_lines` в `ShortageAnalyticsService`,
с фильтром по `users.stock_buffer_enabled`). Это главный показатель, ради которого
эпик затевался: после включения буфера он должен пойти вниз.

## Реализация (2026-08-16)

- Раздел `/wms/stock-buffers`: список рисковых SKU (фото, остаток региона по
  умолчанию, буфер, «скрыто N шт», причины бейджами: «N отмен за 90 дн»,
  «N парт. брака», «срок до MM/YY», «ручная пометка»), summary «скрыто
  штук / на сумму по базовым ценам / доля от остатка», плашка-предупреждение,
  когда `STOCK_BUFFER_ENABLED` выключен.
- Ручная пометка: поиск товара (имя/артикул/код) → «Придержать N шт»;
  автор и время в новых столбцах `manual_set_by`/`manual_set_at`
  (миграция с комментариями). Снятие пометки возвращает расчётный буфер;
  запись без сигналов удаляется целиком.
- Метрика отмен по месяцам: доля заказов клиентов сегмента с отменёнными
  строками (COALESCE-бизнес-дата, месяц диалектно: DATE_FORMAT в MySQL /
  strftime в SQLite — проверено на локальной MySQL).
- Права `wms-stock-buffers.view|edit`: грант-миграция storekeeper /
  warehouse-head / super-admin (по образцу wms-defects) + сидер + пункт
  меню «Страховой запас» в WMS.
