# Задачи по реализации Поиска в шапке (Pecado)

Документ содержит декомпозицию задач на основе [Технического задания](tz-search.md).
**Стек**: Laravel 12, Inertia 2, React 19, Tailwind 4.

## Спринт 1: Backend поиска

### [SE-BE-01] Модель SearchHistory и миграция ✅
**Описание**: Создать модель и таблицу для хранения истории поиска.
**Детали**:
- [x] Создать миграцию `create_search_histories_table`: `id`, `user_id` (FK), `query`, `results_count`, `ip_address`, `timestamps`.
- [x] Создать модель `App\Models\SearchHistory`: fillable, связь `user()`.
- [x] Запустить миграцию, убедиться что таблица создана.

### [SE-BE-02] Настройка Laravel Scout ✅
**Описание**: Подключить полнотекстовый поиск к моделям.
**Детали**:
- [x] Установить / настроить Laravel Scout (meilisearch).
- [x] Добавить трейт  `Searchable` к моделям: `Product`, `Category`, `Brand`, `Article`, `News`.
- [x] Настроить `toSearchableArray()` для каждой модели:
    - `Product`: `name`, `sku`, `barcode` + translit/cyrillic/layout.
    - `Category`: `name` + translit/cyrillic/layout.
    - `Brand`: `name` + translit/cyrillic/layout.
    - `Article`: `title`, `short_description` + translit/cyrillic/layout.
    - `News`: `title` + translit/cyrillic/layout.
- [x] Проверить работу поиска через tinker: `Brand::search('Satisfyer')->get()`.

### [SE-BE-03] SearchController — основной поиск ✅
**Описание**: Реализовать контроллер поиска с методом `index`.
**Детали**:
- [x] Создать `App\Http\Controllers\User\SearchController`.
- [x] Метод `index(Request)`:
    - Валидация `q` (min 2), `type`, `limit`, `include_unavailable`.
    - Поиск через Scout по типам: products (лимит 10), categories (5), brands (5), articles/news (5).
    - Фильтрация: товары по наличию (если не `include_unavailable`), бренды по `is_active`, контент через `shouldBeSearchable()`.
    - Разделение контента на articles и news по `type`.
    - JSON-ответ при `Accept: application/json`, Inertia `User/Search/Index` при обычном запросе.
    - Сохранение запроса в `search_histories` для авторизованных.
- [x] Метод `suggestions(Request)`: подсказки — только товары, лимит 8.
- [x] Зарегистрировать роуты: `GET /search`, `GET /api/search/suggestions`.

### [SE-BE-04] SearchController — история поиска ✅
**Описание**: Реализовать CRUD для истории поиска.
**Детали**:
- [x] Метод `history(Request)`: последние 20 записей пользователя (`auth` middleware).
- [x] Метод `clearHistory(Request)`: удалить все записи пользователя.
- [x] Метод `deleteHistory(Request, SearchHistory)`: удалить одну запись (проверка `user_id`).

## Спринт 4: Полировка и тестирование

### [SE-QA-01] Ручное тестирование
**Описание**: Проверка всех сценариев поиска.
**Детали**:
- [ ] Ввод текста → появление дропдауна с результатами.
- [ ] Клик по результату → переход на страницу.
- [ ] Клик вне дропдауна → закрытие.
- [ ] Чекбокс «Включая отсутствующие» → фильтрация товаров.
- [ ] История: показ, удаление, очистка.
- [ ] Голосовой ввод: начало записи, остановка, вставка текста.
- [ ] Мобильный: полноэкранный overlay, инпут, закрытие.
- [ ] Страница `/search?q=...` → полные результаты.
- [ ] Все надписи на русском.

### [SE-QA-02] Оптимизация и edge cases
**Описание**: Проверка граничных случаев и производительности.
**Детали**:
- [ ] Race conditions: быстрый ввод → только последний результат.
- [ ] Debounce: запрос не уходит при каждом нажатии.
- [ ] AbortController: предыдущие запросы отменяются.
- [ ] Блокировка скролла при дропдауне.
- [ ] Пустой запрос → не отправлять запрос.
- [ ] 1 символ → «Введите минимум 2 символа».
- [ ] API возвращает ошибку → корректное отображение.
- [ ] Скорость ответа API < 300ms.

## Backlog (на потом)

Задачи, исключённые из текущей реализации:

1. **Подсказки с автодополнением** (`/api/search/suggestions`) — отдельный endpoint с карточками товаров в дропдауне.
2. **Поисковая аналитика** — отчёт по популярным запросам, конверсия поиска.
3. **Синонимы и опечатки** — «Вы имели в виду...», fuzzy search.
4. **Поиск по штрихкоду** — сканирование камерой (мобильные).
5. **Персонализация** — ранжирование результатов на основе истории покупок.
