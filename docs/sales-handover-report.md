## Зона ОПТ

**Дебиторская задолженность — главный ежедневный процесс.** РОП ежедневно смотрит отчёт 1С «Задолженность клиентов — копия» и раздаёт менеджерам задачи по просрочке; отдел в конце дня сдаёт отчёт о работе с должниками. По судебным должникам комментарии уже внесены в CRM. Не закрыто: отчёта по дебиторке для KPI нет (ТЗ передано Елене), а сценарий эскалации по клиенту (авто-письмо → звонок-напоминание → жёсткий тон → досудебка) существует только концептуально. Значительная часть уже покрыта разделом `/crm/finance` (план поступлений, просрочка, балансы) — сюда же логично довести задачи-напоминания и эскалацию.

**Клиентская база.** Три параллельных инициативы: база активных клиентов филиала (делается на сайте с ИИ), сводная база всех офлайн-клиентов РФ (перетащить данные из Тюмени; сырьё — таблица «Регионы»: 703 магазина, 94 сети, 463 «чёрных» непроверенных точек), и «тезисный рассказ про клиентов» для Павла — комментарии РОП о точках роста и рисках по каждому клиенту. Последнее стоит забрать как знание, пока оно не ушло вместе с человеком.

**Регулярные ритуалы месяца:** акции согласуются с Ильёй (по оборачиваемости и анализу прошлых акций), актуальный список акций менеджерам напоминается вручную (велась лента в группе «отдел продаж B2b»); план на следующий месяц пересматривается в конце текущего; еженедельно — задачи менеджерам на чистку неоформленных накладных; периодически — проверка старых резервов заказов, обработка «потенциалов», контроль подвисшей кредиторки клиентов («заставить потратить переплату» — это и повод для допродажи).

**Отдельные сюжеты:** Лавка (прямой договор с отсрочкой, заказы через EDI, менеджеры переносят в 1С вручную — можно автоматизировать; отгрузка по пятницам с очередями; минимальный заказ 100 т.р.; оператор — Курочкина; есть общий ТГ-чат с их категорийщиками — нужно туда войти). Два телеграм-канала на ведении: [опт-канал](https://t.me/sexoptmsk) (3 поста/нед.) и [lovense-сообщество](https://t.me/lovenseRUcommunity). Реклама у оптовиков: активнее всех Retail-партнёры «Рейне» и «Интимшоп», раньше Гевея. Брак ОПТ ведётся в таблице (2024–2026, ~540 записей) с решениями бракера и возвратными накладными 1С.

## Зона МП

Команда: Артём (Ozon, оклад 150 т.р. + 1,5 % чистой прибыли) и Адель (110 т.р. + 2 % ЧП по Золотому Яблоку и Яндекс.Маркету); KPI выплачивается после «защиты» цифр 10–15 числа, по Яблоку — отдельно (данные приходят в 20-х). Кабинеты разнесены по юрлицам (матрица в «Реестре МП»): Ozon — Муравьева (основной) и ТЛК; WB — Елисеев (основной), Андрей-М, Импиранте; ЯМ — Елисеев.

Ритм управления: ежедневные брифинги ~10:30 (проблемы, задачи, результаты), еженедельный отчёт (РОП советует делать его глубже: ДРР, темпы месяца, SKU, выдача), ежемесячно — сверка самовыкупов с данными продаж, коммерческих расходов с выделенными суммами, контроль возвратов, запрос остатков складов МП в последний день месяца. Реклама: целевой ДРР ≤ 10 %, в идеале 7–8 %. Аналитика: по Ozon — живая таблица STPULSE (ОПиУ, юнит-экономика, себестоимость по SKU, реклама), по WB — truestats, по ЯМ — sellerstats. Также: контроль «плашек оригинальности», слежение за конкурентами (lovense, shunga, FF, теперь и «письки Пекадо») через аналитику Ozon, тест ФБС/ДБС (в т.ч. как страховка товара «от атак БПЛА»), зависший возврат lovense от Золотого Яблока после фотосессии (курирует Адель).

Примечательно: Битрикс для задач МП умирает — «теряет актуальность из-за созданной Славой CRM».
