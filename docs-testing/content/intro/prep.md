### Mailpit — проверка писем

Нужен для тестов регистрации, восстановления пароля, уведомлений. **На dev-сервере письма не уходят наружу** — все они копятся в Mailpit.

!!! warning "Mailpit недоступен из интернета"
    Порт Mailpit (`8025`) закрыт файрволом, прямой вход по `http://93.94.150.16:8025` **не работает извне**. Выбирайте способ по вашей роли:

=== "Разработчик / администратор с SSH-доступом"

    Поднимите SSH-туннель до dev-сервера и откройте Mailpit на `localhost`:

    ```bash
    ssh -L 8025:localhost:8025 ladmin@93.94.150.16
    ```

    Оставьте терминал открытым — пока он жив, туннель работает.
    В браузере на своей машине: [http://localhost:8025](http://localhost:8025) — откроется интерфейс Mailpit, логин/пароль не нужны.

    **Что увидите:** слева список всех писем, сверху поиск по email/теме. Клик по письму показывает отправителя, получателя, тему, HTML-тело и ссылки. Письмо-приветствие приходит после регистрации, письмо сброса пароля — с темой «Сброс пароля» и ссылкой вида `http://dev.pecado.ru/reset-password/{token}?email=...`.

=== "Тестировщик без SSH-доступа"

    Попросите разработчика в общем чате заглянуть в Mailpit и подтвердить факт письма:

    > «Зарегистрировал клиента `test-имя+01@example.com`, проверьте, пришло ли письмо-приветствие.»

    Разработчик пришлёт скриншот или выдержку из письма. Проверку оформите как обычный пункт ☒ плана.

    В будущем, если пунктов с Mailpit станет много, стоит попросить опубликовать Mailpit через nginx за basic-auth — это несложно и снимет блокировку. Создайте замечание типа **✨ Хотелка** через [багрекер](bugtracker.md).

### Админка Pecado

Нужна для подглядывания, смены статусов и разблокировки тестовых клиентов.

| Параметр | Значение |
|---|---|
| URL | [http://dev.pecado.ru/admin](http://dev.pecado.ru/admin) |
| Логин | `sales@pecado.ru` |
| Пароль | `Sales2024!` |
| Роль | `sales-manager` (заказы, возвраты, отгрузки, клиенты, корзины) |
| Зачем заходить | 1) разблокировать/активировать тестового клиента, которого создали при регистрации; 2) увидеть заказ, созданный на сайте, и вручную сменить статус, чтобы проверить, как это отразится в ЛК клиента; 3) убедиться, что реквизиты компании, адрес доставки и другие данные дошли из формы до БД. |
| Что искать | раздел «Клиенты» → найти свой email → проверить статус, роли, компании. Раздел «Заказы» → ваш заказ, смена статуса (Ожидает → Подтверждён → К отгрузке). Раздел «Возвраты» → ваша заявка. |

### RabbitMQ Management UI (опционально)

Для проверки интеграции с 1С.

!!! warning "RabbitMQ UI тоже закрыт файрволом снаружи"
    Порт `15672`, как и Mailpit, недоступен напрямую из интернета. Используйте SSH-туннель:

    ```bash
    ssh -L 15672:localhost:15672 ladmin@93.94.150.16
    ```

    После этого откройте [http://localhost:15672](http://localhost:15672) в браузере на своей машине.
    Либо попросите разработчика заглянуть и прислать скриншот очередей.

| Параметр | Значение |
|---|---|
| URL (через SSH-туннель) | `http://localhost:15672` |
| Логин | `pecado_admin` |
| Пароль | `SecurePass2024!` |
| Зачем заходить | посмотреть, ушло ли сообщение из сайта в 1С при создании заказа / возврата. |
| Что искать | вкладка «Queues» → очереди `erp_out.orders`, `erp_out.returns` — должны накопиться сообщения после ваших действий. |

Перед началом заполните — это пригодится в нескольких этапах.

| Тип данных | Значение |
|---|---|
| Email для регистрации нового клиента (не занят) | _______________ |
| Пароль (8+ символов) | _______________ |
| Валидный ИНН для новой компании | _______________ |
| ИНН, который уже есть в системе (для проверки дубликата) | _______________ |
| Адрес доставки | _______________ |
| Телефон в международном формате (+7…) | _______________ |
| Артикул товара для проверки точного поиска | _______________ |
| Штрихкод товара для сканера в корзине | _______________ |

!!! tip "Совет по email"
    Для разных этапов регистрируйте **разные email**: `тест-имя+01@example.com`, `тест-имя+02@example.com`. Mailpit покажет их все, а большинство почтовых систем считают всё после `+` алиасом того же адреса.
