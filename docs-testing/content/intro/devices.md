# Тестовые устройства и браузеры

Каждый тестировщик должен пройти план минимум на **двух устройствах**:

- ☐ Настольный компьютер (Chrome / Firefox / Edge) — минимальное разрешение **1920×1080**
- ☐ Смартфон (Safari на iOS или Chrome на Android) — реальное устройство, **не эмулятор**
- ☐ (опционально) Планшет — проверка промежуточной адаптивности

## Шапка для записи

Перед началом тестирования заполните:

| Параметр | Значение |
|---|---|
| Браузер | _______________ |
| Версия браузера | _______________ |
| Устройство | _______________ |
| Разрешение экрана | _______________ |

!!! tip "Почему важно указывать"
    Багрекер автоматически запишет браузер и разрешение **на момент отправки замечания**, но если вы проходите план «оффлайн» или по распечатке, эта информация пригодится при расшифровке замечаний.
