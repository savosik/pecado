# ЭТАП 14. Статические страницы и контент (авторизованный)

!!! abstract "Сценарий"
    Повторно пройдитесь по статическим страницам (теперь как авторизованный), сверяя с гостевой версией.

## 14.1. Проверка разделов

- [ ] `/faq` — тот же контент, доступен поиск по вопросам
- [ ] `/news`, `/news/{slug}` — статьи открываются, в них проставлены все ссылки на товары/категории
- [ ] `/articles`, `/articles/{slug}`
- [ ] `/brand-stories`, `/brand-stories/{slug}`
- [ ] `/promotions`, `/promotions/{slug}` — **акционные товары в каталоге** соответствуют описанию

## 14.2. CMS-страницы

URL: `/pages/{slug}` (например, `/pages/o-nas`, `/pages/dostavka`, `/pages/oplata`).

Проверьте минимум 5 разных:

| № | URL / название | Статус |
|---|---|---|
| 1 | _______________ | ☐ ОК / ☐ Замечания |
| 2 | _______________ | ☐ ОК / ☐ Замечания |
| 3 | _______________ | ☐ ОК / ☐ Замечания |
| 4 | _______________ | ☐ ОК / ☐ Замечания |
| 5 | _______________ | ☐ ОК / ☐ Замечания |

**Замечания:** через [багрекер](../intro/bugtracker.md).
