# ЭТАП 9. Отслеживание заказов

!!! abstract "Сценарий"
    Клиент создал заказ и теперь следит за его статусом и прохождением через 1С.

## 9.1. Список заказов

URL: `/cabinet/orders`

- [ ] Хотя бы один заказ уже виден (из ЭТАПА 8)
- [ ] Поиск по номеру заказа — работает
- [ ] Фильтры (можно свернуть/развернуть): Статус, Тип (Заказ / Предзаказ), Дата «от»/«до», Сумма «от»/«до»
- [ ] Сброс фильтров работает
- [ ] Сортировка: Номер / Дата / Статус / Сумма (↑ и ↓)
- [ ] Бейджи статусов цветные:
    - Ожидает — жёлтый
    - Подтверждён — синий
    - К отгрузке — фиолетовый
    - Закрыт — зелёный
    - Удалён — красный
- [ ] Пагинация

## 9.2. Детальная страница заказа

Откройте свой заказ.

- [ ] Заголовок «Заказ №___»
- [ ] Бейдж статуса, тип заказа, дата
- [ ] Блок «Информация о заказе»: дата, сумма, комментарий
- [ ] Блок «Реквизиты»: компания (название, ИНН), адрес
- [ ] Таблица товаров: фото, название, артикул, бренд, количество, цена, скидка, сумма
- [ ] Timeline статусов и изменений
- [ ] Блок «Отгрузки» — пока пустой (до 1С-синхронизации)
- [ ] Кнопка «Создать возврат» — неактивна или скрыта до появления отгрузки

**Замечания:** через [багрекер](../intro/bugtracker.md).

---

## 9.3. Синхронизация с 1С

Попросите разработку запустить синхронизацию статусов или дождитесь её (обычно 1–3 минуты после действия менеджера в 1С).

- [ ] Статус заказа обновился (например, с «Ожидает» на «Подтверждён»)
- [ ] Timeline получил новую запись
- [ ] В детали заказа появилась связанная отгрузка (если создана)

Как проверить обмен — [раздел «Обмен с 1С»](../intro/erp-sync.md).
