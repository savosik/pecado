# ЭТАП 5. Исследование каталога (уже авторизованный)

!!! abstract "Сценарий"
    Клиент начинает выбирать товар. Теперь в каталоге видны цены и остатки, доступно избранное.

!!! info "Клик по товару — всегда QuickView"
    В авторизованной части сайта поведение то же, что у гостя: клик по карточке открывает **QuickView-диалог** поверх страницы, URL не меняется. Прямой переход на `/products/{slug}` — только через адресную строку или «открыть в новой вкладке».

## 5.1. Каталог с ценами и наличием

URL: `/products`

- [ ] Открыть `/products`
- [ ] Теперь **видны цены** на карточках
- [ ] Виден **статус наличия**: «В наличии», «Предзаказ», «Нет в наличии»
- [ ] Новый фильтр **«Наличие»** (радио): Все / В наличии / Предзаказ / Нет в наличии
- [ ] Новый фильтр **«Цена»**:
    - [ ] Два поля «От» и «До»
    - [ ] Гистограмма (столбики)
    - [ ] Клик по столбику выставляет диапазон
    - [ ] Ручной ввод обновляет выдачу с задержкой (~0.5 сек)
    - [ ] Максимум меньше минимума — обработано корректно

## 5.2. Карточка товара (QuickView + прямой URL)

Кликните любой товар из каталога — откроется QuickView. Затем для сравнения откройте тот же товар по прямому URL `/products/{slug}`.

- [ ] **Цена** показывается (в т. ч. зачёркнутая старая + красная новая при скидке)
- [ ] **Наличие** показывается с количеством в шт.
- [ ] Бейджи: «Новинка», «Хит», «−XX %» (если применимо)
- [ ] SKU можно скопировать (клик → тост «Скопировано»)
- [ ] Штрихкоды можно скопировать
- [ ] Галерея — листание, зум, лайтбокс, Esc закрывает
- [ ] Видео воспроизводится (если есть)
- [ ] Варианты товара: клик переключает на страницу варианта
- [ ] Вкладки «Характеристики», «Описание», «Размерная сетка», «Сертификаты», «Медиа» — всё содержимое корректное, без «сырого» HTML
- [ ] Кнопка «В корзину» **активна**, клик добавляет в активную корзину
- [ ] После добавления — кнопка превращается в счётчик `[−][ 1 ][+]`
- [ ] Увеличить количество до большего, чем в остатке → тост «Количество скорректировано»
- [ ] Клик по сердечку → тост «Добавлено в избранное», счётчик в шапке увеличился

**Замечания:** через [багрекер](../intro/bugtracker.md).

## 5.3. Избранное

URL: `/favorites`

- [ ] Добавить **5 товаров** в избранное
- [ ] Открыть `/favorites`
- [ ] Товары на месте
- [ ] Удалить один кликом по сердечку → удалился из списка
- [ ] Пагинация (если товаров много)
- [ ] Empty state, если всё удалить: иллюстрация + «Список избранного пуст»

**Замечания:** через [багрекер](../intro/bugtracker.md).

---

## 5.4. Edge-кейсы в каталоге

- [ ] Товар с ценой 0 → кнопка «В корзину» **скрыта** (проверено в `ProductCard.jsx`: рендерится только при `price > 0`)
- [ ] Товар без фото → серый плейсхолдер
- [ ] Товар с очень длинным названием → не ломает сетку (3 строки max)
- [ ] Товар «Нет в наличии» → кнопка «В корзину» скрыта

**Замечания:** через [багрекер](../intro/bugtracker.md).
