# ЭТАП 6. Поиск товаров (авторизованный)

## 6.1. Автодополнение

- [ ] Клик в поле поиска → **История запросов** (пустая при первом разе)
- [ ] Ввести «виб» (или часть популярного запроса) → подсказки в секциях: Товары / Бренды / Категории / Статьи
- [ ] Клик по товару-подсказке → открывается **QuickView** (не отдельная страница)
- [ ] Enter — переход на `/search?q=...`
- [ ] Запрос **сохранился в истории** (проверить, открыв поиск снова)

## 6.2. История поиска

- [ ] Крестик рядом с запросом в истории — удаляет конкретный запрос
- [ ] Кнопка «Очистить историю» — удаляет всю историю

## 6.3. Страница результатов

URL: `/search?q=...`

- [ ] По точному артикулу (SKU) — находит **один товар**
- [ ] По части названия — несколько товаров
- [ ] По названию бренда — секция «Бренды» показывает ссылки, секция «Товары» — товары этого бренда
- [ ] По запросу, которого точно нет (например, `asdqwezxc123`) — «Ничего не найдено»
- [ ] **Семантический поиск**: ввести описание, не содержащее точных слов (например, «что-то розовое для двоих» — ожидаем релевантную выдачу). Отметьте адекватность выдачи: ____________
- [ ] Чекбокс «Показать недоступные» — включает/исключает товары без остатка

**Замечания по поиску:** через [багрекер](../intro/bugtracker.md).
