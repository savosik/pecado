# ЭТАП 18. Выход из системы

!!! abstract "Сценарий"
    Клиент завершил работу с сайтом и хочет выйти.

## 18.1. Logout (desktop)

- [ ] Клик по аватару → «Выйти»
- [ ] Редирект на `/login` с сообщением «Вы вышли из системы»
- [ ] Попытка открыть `/cabinet/dashboard` → редирект на `/login`
- [ ] Кнопки «Назад» в браузере не восстанавливают сессию

## 18.2. Logout (mobile)

- [ ] Бургер-меню → «Выход» — аналогично desktop-поведению

**Замечания:** через [багрекер](../intro/bugtracker.md).
