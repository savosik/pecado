# ЭТАП 2. Онбординг (анкета о бизнесе)

!!! abstract "Сценарий"
    Система хочет узнать, какой это клиент, чтобы предложить релевантные условия.

## 2.1. Шаг 1 — Личные данные

- [ ] Прогресс-бар показывает «Шаг 1 из 5»
- [ ] Поле «ФИО / Название компании» (required)
- [ ] Выпадашка «Страна»: есть RU, BY, KZ
- [ ] Поле «Город» (required)
- [ ] Поле «Телефон»:
    - [ ] Ввести локальный номер без кода — валидация ругается
    - [ ] Ввести международный (+7 999 123 45 67) — принимает
- [ ] Нажать «Далее» с пустыми полями → ошибки на каждом поле
- [ ] Заполнить корректно → переход на Шаг 2

## 2.2. Шаг 2 — О бизнесе

- [ ] Множественный выбор «Тип бизнеса» (секс-шоп, интернет-магазин, маркетплейс, шоурум, оптовый закупщик, другое)
- [ ] Можно выбрать несколько
- [ ] Название компании (опционально)
- [ ] URL сайта/соцсети (опционально)
- [ ] Кнопка «Назад» возвращает на Шаг 1, **данные не теряются**
- [ ] Кнопка «Пропустить» закрывает онбординг и ведёт на главную
- [ ] Нажать «Далее» → переход на Шаг 3

## 2.3. Шаг 3 — Опыт и объёмы

- [ ] Опыт: менее 1 года / 1–3 года / 3–5 лет / более 5 лет
- [ ] Ожидаемый объём закупок: 5 градаций
- [ ] Чекбокс «Есть физическая точка продаж»:
    - [ ] Включён → появляется поле «Количество точек» (1, 2–5, 6–10, >10)
    - [ ] Выключен → поле «Количество точек» **скрывается**
- [ ] Переход на Шаг 4

## 2.4. Шаг 4 — Категории товаров

- [ ] Список категорий отображается (если в системе есть хотя бы одна)
- [ ] Можно выбрать несколько категорий
- [ ] Или нажать «Далее» без выбора → переход допустим

## 2.5. Шаг 5 — Финал

- [ ] Поле «Как вы узнали о Pecado?» (6 вариантов)
- [ ] Textarea «Дополнительная информация» — максимум 2000 символов
- [ ] Ввести 2001 символ → ограничение/ошибка
- [ ] Кнопка **«Завершить»** (не «Далее»)
- [ ] После нажатия — редирект на `/` + **Welcome-диалог** с именем клиента

**Замечания по онбордингу:** через [багрекер](../intro/bugtracker.md).
