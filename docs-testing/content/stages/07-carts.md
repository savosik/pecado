# ЭТАП 7. Работа с корзинами (множественными)

!!! abstract "Сценарий"
    Клиент собирает несколько корзин под разные магазины / клиентов. Система поддерживает любое количество именованных корзин с одной активной.

## 7.1. Дропдаун корзины в шапке

- [ ] Клик по иконке корзины в шапке
- [ ] Отображается список корзин (сейчас — одна «Основная»)
- [ ] Можно переключить активную корзину (галочка)
- [ ] Кнопка «+ Создать новую» — появляется поле ввода имени
- [ ] Ввести «Шоурум Москва» → создать → корзина появилась
- [ ] Inline-редактирование имени (карандаш)
- [ ] Удаление корзины — диалог подтверждения

## 7.2. Страница списка корзин

URL: `/cabinet/carts`

- [ ] Таблица/карточки со всеми корзинами
- [ ] Колонки: Название, Позиций, Единиц, Сумма, Обновлена, Действия
- [ ] Сделать корзину активной — звёздочка
- [ ] Перейти в деталь корзины
- [ ] Переименовать inline
- [ ] Удалить — подтверждение

## 7.3. Детальная корзина

URL: `/cabinet/carts/{id}`

- [ ] Название корзины — редактируется карандашом
- [ ] Поле поиска товаров: ввести 2+ символа, выбрать товар из списка → добавился
- [ ] Карточки статистики: Позиций / Единиц / Итого
- [ ] Таблица товаров: фото, название, артикул, бренд, цена (со скидкой если есть), количество (−/input/+), сумма, иконка удаления
- [ ] Кнопка «−» уменьшает количество, при «0» — товар удаляется с подтверждением
- [ ] Кнопка «+» — увеличивает до максимума остатка, потом — «Количество скорректировано»
- [ ] Ввод вручную большого числа — также клампится
- [ ] Удалить товар — диалог «Удалить «...» из корзины?»
- [ ] «Очистить корзину» — подтверждение, всё удаляется

## 7.4. Основная корзина с продвинутыми действиями

URL: `/cart`

Наполните активную корзину **10+ товарами** (через QuickView на карточках или через поиск внутри корзины).

- [ ] Заголовок, кнопка «Управление корзинами»
- [ ] Поиск по позициям корзины (название / SKU / штрихкод) — фильтрация на клиенте
- [ ] Сортировка по названию, цене, статусу
- [ ] Чекбоксы для выбора позиций
- [ ] **Массовые действия** («Действия»):
    - [ ] Задать количество — диалог с input 0–999, применяется к выбранным
    - [ ] Удалить выбранные
    - [ ] Перенести в другую корзину — диалог выбора
    - [ ] **Экспорт в Excel** — скачался файл `.xlsx`, открывается в Excel, все колонки на русском
    - [ ] Очистить корзину — подтверждение
- [ ] **Сканер штрихкодов**:
    - [ ] Кнопка «Сканер» открывает диалог с полем ввода
    - [ ] Ввести штрихкод (или отсканировать) → товар найден → добавился
    - [ ] Несуществующий штрихкод → тост-ошибка
- [ ] **Кнопка «Обновить»** — повторно подгружает данные с сервера
- [ ] Итог корзины: разделение **«В наличии» / «Предзаказ»**, суммы, «Ваша выгода» (при скидке)
- [ ] Кнопка «Оформить заказ» ведёт на `/checkout`

**Замечания по корзинам:** через [багрекер](../intro/bugtracker.md).

## 7.5. Edge-кейсы корзин

- [ ] Удалить активную корзину — система сама должна назначить другую активной, либо запретить удаление
- [ ] Оставить корзину полностью пустой и перейти на `/cart` → empty-state «Корзина пуста» + кнопка в каталог
- [ ] Добавить в одну корзину 50+ позиций — скорость загрузки адекватна
- [ ] Открыть ту же корзину в двух вкладках, изменить в одной — обновляется ли вторая?

**Замечания:** через [багрекер](../intro/bugtracker.md).
