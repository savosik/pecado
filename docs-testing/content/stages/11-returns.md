# ЭТАП 11. Возврат товара

!!! abstract "Сценарий"
    Клиент получил отгрузку, часть товара бракованная и её нужно вернуть.

!!! note "Возврат создаётся только на основании отгрузки"
    Нельзя вернуть то, что не было отгружено. Поэтому минимум одна отгрузка (ЭТАП 10) должна быть завершена до возврата.

## 11.1. Список возвратов

URL: `/cabinet/returns`

- [ ] Пусто при первом заходе → empty-state «Возвратов пока нет»
- [ ] Кнопка «Создать возврат»

## 11.2. Создание возврата

URL: `/cabinet/returns/create`

- [ ] Textarea «Комментарий к возврату»
- [ ] Блок «Позиции возврата (0)» с кнопкой поиска товара
- [ ] Поиск товара в поле → подсказки **только из предыдущих отгрузок** клиента
- [ ] Выбрать товар → появился в таблице позиций возврата
- [ ] Поля на каждую позицию:
    - Товар (наименование + заказ + отгрузка откуда)
    - Количество (не больше отгруженного!)
    - Причина возврата (dropdown: Дефект/повреждение, Не соответствует описанию, Не нравится, Другое)
    - Кнопка удалить позицию
- [ ] Добавить ещё одну позицию
- [ ] Количество больше, чем в отгрузке → ошибка/клампинг
- [ ] Нажать «Отправить заявку» без указания причины → ошибка
- [ ] Корректно заполнено — заявка отправлена, тост «Заявка на возврат создана», редирект на список

!!! info "Проверка в RabbitMQ"
    После отправки заявки в очередь `erp_out.returns` должно попасть сообщение — сайт отправляет возврат в 1С. Проверка через SSH-туннель (см. [Подготовка](../intro/prep.md#rabbitmq-management-ui)).

## 11.3. Детальная страница возврата

- [ ] Номер, статус (`pending` / `approved` / `rejected` / `completed`), дата
- [ ] Комментарий клиента
- [ ] Таблица позиций
- [ ] История статусов (меняется, когда 1С обрабатывает возврат — через очередь `erp_in.returns`)
