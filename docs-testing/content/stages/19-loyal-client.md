# ЭТАП 19. Повторный цикл (лояльный клиент)

!!! abstract "Сценарий"
    Клиент возвращается через неделю, чтобы сделать повторную закупку. Все данные должны быть на месте.

## 19.1. Проверка сохранённого состояния

- [ ] Войти под клиентом — дашборд показывает накопленную статистику (заказы, корзины, избранное)
- [ ] Список заказов — старый заказ на месте, статус мог измениться
- [ ] Отгрузка появилась в разделе «Отгрузки»
- [ ] Возврат (если создавали) — виден в «Возвраты»
- [ ] Список избранного — сохранился
- [ ] Корзины — сохранились все, что создавали

## 19.2. Повторный заказ

- [ ] Открыть старую корзину, нажать «Оформить заказ» — заказ создаётся с обновлёнными ценами и остатками
- [ ] Выгрузки-пресеты по-прежнему выдают актуальные данные (дата обновления свежая)
- [ ] Ссылки на пресеты, скопированные неделю назад, **по-прежнему работают** без авторизации

**Замечания по лояльному сценарию:** через [багрекер](../intro/bugtracker.md).
