# ЭТАП 10. Получение отгрузки (реализации)

!!! abstract "Сценарий"
    1С сформировала реализацию — теперь клиент видит её на сайте.

!!! warning "Зависит от 1С"
    Отгрузки создаются только в 1С и приходят на сайт через очередь `erp_in.documents`. Если в админке / 1С никто не создал реализацию — раздел будет пустым, и это **не баг**.

## 10.1. Список отгрузок

URL: `/cabinet/shipments`

- [ ] Есть минимум одна отгрузка (иначе попросите разработчика/менеджера создать реализацию в 1С)
- [ ] Таблица/карточки: номер, тип «Отгрузка», статус, компания, количество позиций, дата отгрузки, сумма, валюта
- [ ] Статусы: `new` / `in_progress` / `completed` / `cancelled` — цвета соответствуют
- [ ] Поиск (номер / ИНН / название товара)
- [ ] Фильтры (статус / дата / сумма)
- [ ] Empty-state: «Отгрузок пока нет. Когда 1С создаст реализацию, она появится здесь»

## 10.2. Детальная отгрузка

URL: `/cabinet/shipments/{id}`

- [ ] Номер, статус, дата отгрузки
- [ ] ИНН контрагента, компания, валюта из 1С
- [ ] **Итоговая сумма** крупно, «Ваша выгода» (при скидке)
- [ ] Таблица товаров: фото, название, артикул, бренд, количество, **базовая цена**, **цена со скидкой**, **НДС**, сумма
- [ ] Связанные заказы: список, клик ведёт на карточку заказа
- [ ] Документы (при наличии): УПД, счёт-фактура, накладная — кнопка «Скачать», файл открывается
- [ ] Проверить, что в скачанных документах данные **совпадают** с отгрузкой

**Замечания:** через [багрекер](../intro/bugtracker.md).
