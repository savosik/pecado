# ЭТАП 17. Восстановление пароля

!!! abstract "Сценарий"
    Клиент забыл пароль и хочет его восстановить.

## 17.1. «Забыли пароль»

URL: `/forgot-password`

- [ ] Выйти из системы
- [ ] Открыть `/forgot-password`
- [ ] Ввести email **несуществующего** пользователя → ошибка «Пользователь не найден»
- [ ] Ввести email **существующего** пользователя → success-сообщение «Ссылка отправлена»

## 17.2. Письмо со сбросом

!!! note "Как открыть Mailpit"
    Mailpit закрыт файрволом снаружи. Способы доступа — в [подготовке](../intro/prep.md#mailpit). Коротко: SSH-туннель `ssh -L 8025:localhost:8025 ladmin@93.94.150.16` → `http://localhost:8025`. Если нет SSH — попросите разработчика проверить письмо.

- [ ] В списке писем Mailpit → новое письмо на указанный email
- [ ] Тема и текст на русском
- [ ] Ссылка в письме ведёт на `http://dev.pecado.ru/reset-password/{token}?email=...`

## 17.3. Форма сброса

- [ ] Email заполнен автоматически и недоступен для редактирования
- [ ] Поля «Новый пароль», «Подтверждение»
- [ ] Пароли не совпадают → ошибка
- [ ] Пароль короче 8 символов → ошибка
- [ ] Корректно → редирект на `/login` + сообщение «Пароль успешно изменён»
- [ ] Войти с новым паролем — успех
- [ ] Использовать ту же ссылку повторно → ошибка «Ссылка недействительна или истекла»

**Замечания по восстановлению:** через [багрекер](../intro/bugtracker.md).
