# ЭТАП 1. Регистрация нового B2B-клиента

!!! abstract "Сценарий"
    Клиент решил, что сайт подходит, и начал регистрацию.

## 1.1. Форма регистрации

URL: `/register`

- [ ] Клик по «Регистрация» в шапке открывает `/register` или модальное окно
- [ ] Видны поля: Email, Пароль, Подтверждение пароля, кнопка «Зарегистрироваться»
- [ ] Видна ссылка «Уже есть аккаунт? Войти»
- [ ] Отправить пустую форму → валидационные ошибки на каждом поле (на русском)
- [ ] Ввести невалидный email (`qqq`) → ошибка «Введите корректный email»
- [ ] Ввести пароль короче 8 символов → ошибка «Пароль должен содержать не менее 8 символов»
- [ ] Ввести пароли, которые не совпадают → ошибка «Пароли не совпадают»
- [ ] Попытаться зарегистрироваться с **уже существующим email** → ошибка «Пользователь с таким email уже зарегистрирован»

## 1.2. Проверка письма-приветствия

!!! note "Как открыть Mailpit"
    Mailpit закрыт файрволом снаружи. Способы доступа — в [подготовке](../intro/prep.md#mailpit). Коротко: SSH-туннель `ssh -L 8025:localhost:8025 ladmin@93.94.150.16` → `http://localhost:8025`. Если нет SSH — попросите разработчика проверить письмо.

- [ ] В списке писем Mailpit появилось письмо, отправленное на указанный при регистрации email
- [ ] Тема и содержимое на русском, без «кракозябр»
- [ ] Все ссылки в письме ведут на `http://dev.pecado.ru/...`, открываются, не выдают 404

**Замечания:** через [багрекер](../intro/bugtracker.md).
