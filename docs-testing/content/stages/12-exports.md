# ЭТАП 12. Настройка выгрузок

!!! abstract "Сценарий"
    Клиент хочет автоматически получать цены и остатки для своего интернет-магазина / маркетплейса.

## 12.1. Стандартные выгрузки

URL: `/cabinet/export-presets`

- [ ] Открылся раздел, есть описание: «Готовые выгрузки для популярных интернет-магазинов…»
- [ ] Сетка карточек пресетов (цены, остатки, 1С, Яндекс.Маркет, Google, Авито, Ozon и т. д.)
- [ ] Выбрать один пресет (например, «Цены JSON»), нажать «Получить ссылку»
- [ ] Появилась ссылка-URL (скопировать) и кнопки «Скачать», «Удалить»
- [ ] Кнопка «Скачать» открывает файл — убедиться, что данные валидны
- [ ] Скопировать ссылку, открыть в инкогнито — файл скачивается **без авторизации** (это ключевая проверка)
- [ ] Повторный запрос того же пресета — использует кэш (дата обновления не меняется)
- [ ] Удалить пресет → ссылка перестала работать

**Замечания:** через [багрекер](../intro/bugtracker.md).

---

## 12.2. Конструктор выгрузок

URL: `/cabinet/product-exports`

- [ ] Нажать «Создать выгрузку»
- [ ] Форма: Название (required), Формат (JSON / CSV / XML / XLS)
- [ ] **Поля для экспорта** (чекбоксы): название, SKU, код, штрихкод, категория, бренд, цена базовая, цена со скидкой, валюта, остаток, предзаказ, SEO, медиа
- [ ] **Фильтры**: категории, бренды, статус (в наличии / предзаказ), цена «от/до», поисковый запрос
- [ ] Сохранить и скачать — файл скачивается, формат соответствует
- [ ] Вернуться в список — выгрузка появилась в таблице
- [ ] Скопировать ссылку в буфер — тост
- [ ] Открыть ссылку в инкогнито — **[!]** файл скачивается без авторизации
- [ ] Отредактировать (изменить фильтр, добавить поле) → сохранить
- [ ] Удалить — подтверждение

**Замечания:** через [багрекер](../intro/bugtracker.md).
