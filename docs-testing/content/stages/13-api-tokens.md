# ЭТАП 13. API-токены

!!! abstract "Сценарий"
    Клиент планирует интегрировать сайт со своей ERP / 1С и ему нужен API-ключ.

## 13.1. Создание токена

URL: `/cabinet/api-tokens`

- [ ] Описание API + warning «Храните ключ в секрете»
- [ ] Кнопка «Создать ключ» → модальное окно с полем «Название»
- [ ] Ввести «Тестовая интеграция» → Создать
- [ ] **[!]** Полный токен показан **один раз**, кнопка «Скопировать»
- [ ] После закрытия — токен замаскирован (`pec_****…****`)
- [ ] Карточка токена: название, дата создания, badge «Активен», Base URL, «Последнее использование»

## 13.2. Использование токена

Документация API — публичная, доступна на [https://dev.pecado.ru/docs/api](https://dev.pecado.ru/docs/api). Там же можно взять примеры запросов.

- [ ] `GET /api/client-api/{token}/prices` — возвращает JSON с ценами (200 OK)
- [ ] `GET /api/client-api/{token}/stocks` — возвращает остатки
- [ ] `POST /api/client-api/{token}/orders` — создаёт заказ; ошибка при пустом body
- [ ] С невалидным токеном → **404**
- [ ] 61-й запрос за минуту → **429 Too Many Requests**
- [ ] На странице токена обновилось «Последнее использование»

## 13.3. Пересоздание и удаление

- [ ] Перегенерировать ключ → новый токен, старый перестал работать
- [ ] Удалить ключ → подтверждение → токен исчез

**Замечания по API-токенам:** через [багрекер](../intro/bugtracker.md).
