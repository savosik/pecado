# ЭТАП 4. Настройка профиля, компании, адресов

!!! abstract "Сценарий"
    Перед закупкой клиент заполняет реквизиты.

## 4.1. Редактирование профиля

URL: `/cabinet/profile`

- [ ] Открыть «Мои данные»
- [ ] Поля: Имя / Название, Телефон, Email — заполнены из регистрации
- [ ] Изменить имя → «Сохранить» → тост «Профиль обновлён»
- [ ] Изменить телефон на невалидный → ошибка
- [ ] Очистить email → ошибка «Email обязателен»
- [ ] Попытаться указать email, уже занятый другим → ошибка
- [ ] Успешное сохранение → тост + данные обновились в шапке

**Замечания:** через [багрекер](../intro/bugtracker.md).

---

## 4.2. Создание компании

URL: `/cabinet/companies/create`

- [ ] Перейти в «Мои компании» → «+ Добавить компанию»
- [ ] Форма с полями: Страна, Название, Юр. название, ИНН, КПП, ОКПО, Юр. адрес, Факт. адрес, Телефон, Email
- [ ] Попробовать сохранить пустую форму → ошибки на required-полях
- [ ] Ввести уже существующий ИНН → ошибка «Компания с таким ИНН уже зарегистрирована в системе»
- [ ] Ввести ИНН длиной 5 цифр → ошибка
- [ ] Корректные данные:

    | Поле | Значение |
    |---|---|
    | Название | _______________ |
    | ИНН | _______________ |

- [ ] Успешное сохранение → редирект на страницу редактирования
- [ ] Проверить, что компания появилась в списке `/cabinet/companies`

---

## 4.3. Банковские счета

- [ ] В форме редактирования компании — раздел «Банковские счета»
- [ ] «+ Добавить счёт»: Название банка, Номер счёта
- [ ] Сохранить → счёт появился в таблице
- [ ] Отредактировать счёт
- [ ] Удалить счёт → подтверждение → удалён

**Замечания по компаниям:** через [багрекер](../intro/bugtracker.md).

---

## 4.4. Адреса доставки

URL: `/cabinet/delivery-addresses`

- [ ] «+ Добавить адрес»
- [ ] Поля: Название (например, «Склад №1»), Страна, Адрес, Контактное лицо, Телефон
- [ ] Сохранить → адрес в списке
- [ ] Отредактировать → сохранения работают
- [ ] Удалить → подтверждение → удалён
- [ ] Empty-state при отсутствии адресов
- [ ] Создать **минимум 2 адреса** — понадобятся при оформлении заказа

**Замечания по адресам:** через [багрекер](../intro/bugtracker.md).
