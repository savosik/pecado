# ЭТАП 15. Темы оформления, адаптивность, a11y

## 15.1. Светлая тема

- [ ] Фон песочный, текст тёмный
- [ ] Контраст между текстом и фоном — комфортный
- [ ] Акцентные кнопки красные (pecado), второстепенные — нейтральные
- [ ] Все иконки читаемы
- [ ] Карточки товаров: тени и границы соответствуют макету

---

## 15.2. Тёмная тема

- [ ] Клик в футере по «Солнце/Луна» — тема переключилась моментально
- [ ] Фон почти чёрный с оттенком бордо
- [ ] Текст светло-кремовый
- [ ] Все изображения читаемы (без засветов)
- [ ] Формы: инпуты, селекты, чекбоксы — видны на тёмном фоне
- [ ] Модальные окна (логин, создание корзины, подтверждения, QuickView) — тёмные

## 15.3. Мобильная версия

Повторите ключевой путь **на смартфоне**: регистрация → каталог → карточка (QuickView) → корзина → чекаут → заказ.

- [ ] Бургер-меню открывается и закрывается
- [ ] Кнопки крупные, не слишком мелкие — пальцы попадают
- [ ] Формы — клавиатура не перекрывает активное поле
- [ ] Модальные окна (включая QuickView) помещаются на экране
- [ ] Нижняя навигация (если есть MobileNav) видна
- [ ] Галерея товара листается свайпом
- [ ] Таблица корзины переключается на карточки

**Замечания по адаптивности:** через [багрекер](../intro/bugtracker.md).

---

## 15.4. Доступность

- [ ] Можно пройти основные сценарии **с клавиатуры** (Tab / Shift+Tab / Enter)
- [ ] На иконочных кнопках есть всплывающие подсказки или `aria-label`
- [ ] Alt-текст на ключевых изображениях (проверить на 2–3 товарах)
- [ ] Масштаб 125%, 150% в браузере — текст не перекрывает другие блоки

**Замечания:** через [багрекер](../intro/bugtracker.md).
