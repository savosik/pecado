# ЭТАП 0. Знакомство с сайтом (гость, неавторизованный)

!!! abstract "Сценарий"
    Потенциальный клиент впервые зашёл на сайт. Ему нужно понять — тот ли это поставщик, что ему нужен, и можно ли здесь вести оптовый бизнес.

## 0.1. Главная страница

URL: [http://dev.pecado.ru/](http://dev.pecado.ru/)

- [ ] Страница открывается без ошибок, загружается **менее чем за 3 сек** на десктопе
- [ ] Шапка содержит: логотип, кнопку «Каталог», поиск, «Войти», «Регистрация»
- [ ] На мобильном — видно бургер-меню, логотип, поле поиска
- [ ] Логотип ведёт на главную (кликнуть)
- [ ] **Story Circles** (если есть): круги с историями прокручиваются, клик открывает историю
- [ ] **Баннер-слайдер**:
    - [ ] Переключается автоматически
    - [ ] Можно прокрутить стрелками или свайпом
    - [ ] Клик по баннеру ведёт на соответствующую страницу
- [ ] **Подборки товаров (табы)**: переключаются без перезагрузки, товары в табе меняются
- [ ] Блок **«Новинки»**: отображается минимум 5 товаров, ссылка «Смотреть все новинки» работает → `/products/novinki`
- [ ] Блок **«Бестселлеры»**: аналогично, ссылка → `/products/bestsellery`
- [ ] **Футер** содержит: «О компании», «Покупателям», «Категории», логотип, копирайт с текущим годом, переключатель темы

**Замечания по главной странице:** через [багрекер](../intro/bugtracker.md) (тип замечания на ваш выбор) с короткой пометкой в блокноте.

## 0.2. Карточка товара в гостевом режиме

Кликните на любой товар из блока «Новинки».

!!! info "Как открывается товар"
    Клик по карточке товара (левой кнопкой мыши) **открывает модальное окно быстрого просмотра (QuickView)** поверх текущей страницы. URL в адресной строке **не меняется**. Это основной способ просмотра товара — и на главной, и в каталоге, и в результатах поиска.

    Полноценная страница товара (`/products/{slug}`) открывается только если:
    — ввести URL вручную в адресную строку,
    — открыть ссылку в новой вкладке (средняя кнопка мыши или правый клик → «Открыть в новой вкладке»).

    Содержимое QuickView и страницы одинаковое.

!!! warning "Что гость НЕ видит"
    Ни в QuickView, ни на странице товара гостю **не показываются**: цена, статус наличия, кнопка «В корзину», иконка избранного (сердечко). Всё это рендерится только для авторизованных пользователей — гостю отображаются только публичные данные товара.

### QuickView-диалог

- [ ] Клик по карточке товара открывает **модальное окно** поверх страницы (не перенаправляет)
- [ ] URL в адресной строке не меняется
- [ ] Окно можно закрыть: крестиком в правом верхнем углу, клавишей **Esc**, кликом по затемнённому фону
- [ ] Прокрутка страницы под модалкой **заблокирована** пока окно открыто
- [ ] В модалке отображаются: галерея, название, артикул (SKU), бренд (ссылка), хлебные крошки категории
- [ ] Отображаются вкладки: «Характеристики», «Описание», «Размерная сетка», «Сертификаты», «Медиа» (какие есть у товара)
- [ ] **Цена НЕ показывается гостю** (скрыта — ни в какой форме, даже в виде плашки)
- [ ] **Статус наличия НЕ показывается гостю** (скрыт полностью)
- [ ] Кнопка **«В корзину»** гостю **не показывается**
- [ ] Иконка **избранного (сердечко)** гостю **не показывается**
- [ ] Галерея товара внутри модалки: основное фото + миниатюры, стрелки «‹» / «›» листают, клик открывает лайтбокс
- [ ] Клик на бренд внутри модалки → модалка закрывается, открывается страница бренда
- [ ] **[!]** Нигде не «мерцают» индикаторы загрузки дольше 2 сек после открытия

### Страница товара напрямую

- [ ] Открыть тот же товар через адресную строку по URL `/products/{slug}` → открывается полноценная страница (не модалка)
- [ ] На странице есть хлебные крошки (Главная → Категория → Товар)
- [ ] Содержимое идентично QuickView: те же ограничения для гостя (нет цены/наличия/корзины/сердечка)

**Замечания:** через [багрекер](../intro/bugtracker.md).

## 0.3. Каталог и фильтры (гость)

URL: `/products`

- [ ] Страница каталога открывается
- [ ] Отображается сетка товаров (минимум 12)
- [ ] Карточки товаров в каталоге **не показывают гостю цену, наличие, кнопку «В корзину», сердечко** — только изображение, название, бренд и бейджи
- [ ] Клик по карточке открывает **QuickView-диалог** (модальное окно), а не переход на страницу товара — URL не меняется
- [ ] Есть фильтры: Категории, Бренды (Цена и Наличие скрыты для гостя, потому что гость всё равно не видит цену/остаток)
- [ ] Фильтр «Категории»: клик по чекбоксу перезагружает выдачу
- [ ] Фильтр «Бренды»: поиск по полю (если >10 брендов) работает
- [ ] Можно комбинировать несколько фильтров
- [ ] Чипы с активными фильтрами появляются сверху, каждый можно удалить «×»
- [ ] Кнопка «Сбросить всё» убирает все фильтры
- [ ] Сортировка: «Новинки», «Цена ↑», «Цена ↓», «Название А–Я» — перепроверьте несколько вариантов
- [ ] Вид отображения: переключение «Сетка» / «Список» работает
- [ ] Пагинация: переход на вторую страницу, кнопки «‹», «›»
- [ ] Переключатель «Бесконечная прокрутка»: включается, кнопка «Загрузить ещё» / автодозагрузка при скролле
- [ ] Выбор «Показывать по»: 10, 20, 40, 60, 100 — меняет количество карточек

**Замечания:** через [багрекер](../intro/bugtracker.md).

## 0.4. Поиск (гость)

- [ ] Клик в поле поиска открывает выпадающую панель
- [ ] Ввод 2–3 символов показывает подсказки (товары, бренды, категории)
- [ ] Нажатие Enter ведёт на `/search?q=...`
- [ ] Иконка микрофона (если браузер поддерживает):
    - [ ] Кликнуть → запрос доступа к микрофону → говорить слово
    - [ ] Результат голоса подставился в поле поиска
- [ ] На странице поиска отображаются: товары, бренды, категории, статьи, новости
- [ ] Ничего не найдено: показывается иллюстрация + текст «Ничего не найдено»
- [ ] Поиск по артикулу (например, SKU `123-ABC`) возвращает конкретный товар
- [ ] Поиск кириллицей и латиницей даёт схожие результаты (транслит)

**Замечания:** через [багрекер](../intro/bugtracker.md).
