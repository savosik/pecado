# ЭТАП 16. Смена пароля

## 16.1. Форма смены пароля

URL: `/cabinet/change-password`

- [ ] Поля: Текущий пароль, Новый, Подтверждение нового
- [ ] Пустая форма → ошибки
- [ ] Неверный текущий пароль → ошибка
- [ ] Новый пароль короче 8 символов → ошибка
- [ ] Подтверждение не совпадает → ошибка
- [ ] Успешная смена → тост / редирект / повторный логин (проверить поведение)
- [ ] Войти со **старым** паролем — невозможно
- [ ] Войти с **новым** паролем — возможно

**Замечания:** через [багрекер](../intro/bugtracker.md).
