# E.2. Кросс-авторизация

!!! abstract "Сценарий"
    Один и тот же браузер, две вкладки. Проверка, что сессия правильно перекрывается.

- [ ] Открыть `/cabinet/dashboard` в одной вкладке под клиентом А
- [ ] В другой вкладке войти под клиентом Б
- [ ] Обновить первую вкладку — отображаются данные клиента Б (не А)

!!! warning "Осторожно с параллельным тестированием"
    Если вы параллельно с коллегой используете один и тот же dev-аккаунт — проверяйте, что корзина, заказы и избранное не «пересекаются». Лучше завести разные email для каждого тестировщика.

**Замечания:** через [багрекер](../intro/bugtracker.md).
