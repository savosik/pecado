# Edge-кейсы и регрессия

Раздел собирает нестандартные сценарии, которые легко пропустить при прямолинейном прохождении основных этапов. Часть из них — моделирование ошибок и нагрузки, часть — проверка после деплоя.

## Как выполнять

Edge-кейсы — не обязательный прогон на каждой итерации. Минимальный набор для релиза: [регрессия](regression.md), [кросс-авторизация](cross-auth.md), [проверка багрекера](bugtracker-check.md). Остальное — при крупных обновлениях.
