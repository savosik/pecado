# E.4. Длинные значения

!!! abstract "Сценарий"
    Что происходит с UI, когда поля заполнены «по самое не могу».

- [ ] Название корзины 255 символов — как отображается в дропдауне шапки, не ломает ли вёрстку
- [ ] Комментарий к заказу 5000 символов — принимается / обрезается / выдаёт ошибку
- [ ] Товар с названием в 200 символов — в карточке, в QuickView, в чекауте, в документах отгрузки

**Замечания:** через [багрекер](../intro/bugtracker.md).
