# E.6. Офлайн

!!! abstract "Сценарий"
    Сеть отключилась во время работы — сайт должен сказать об этом понятно, а не «упасть в белый экран».

- [ ] Во время работы в корзине отключите интернет (DevTools → Network → Offline, либо Wi-Fi)
- [ ] Попробуйте добавить товар / изменить количество
- [ ] Ожидается **внятное сообщение об ошибке**, без «белого экрана»
- [ ] После восстановления интернета — данные синхронизируются или появляется кнопка «Повторить»

**Замечания:** через [багрекер](../intro/bugtracker.md).
