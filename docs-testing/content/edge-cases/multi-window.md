# E.7. Многооконность

!!! abstract "Сценарий"
    Клиент открыл одну корзину в двух вкладках и вносит изменения в каждой.

- [ ] Открыть одну и ту же корзину в двух вкладках
- [ ] Изменить количество в первой вкладке
- [ ] Обновить вторую вкладку → данные совпадают с первой
- [ ] Проверить аналогично для избранного, смены активной корзины, переключателя темы
