# E.8. Прайс и валюта

!!! abstract "Сценарий"
    Клиенты из Беларуси и Казахстана должны видеть свои валюты (BYN / KZT), пересчитанные по курсу 1С.

- [ ] Если сайт поддерживает валюту **BYN** или **KZT** — переключить, проверить пересчёт:
    - [ ] В каталоге (карточки товаров)
    - [ ] В QuickView
    - [ ] На странице товара
    - [ ] В корзине (суммы)
    - [ ] В заказе (итоги, таблица позиций)
- [ ] Документы отгрузки — валюта 1С соответствует той, что видит клиент на сайте
- [ ] После обновления курса в 1С (через `erp_in.prices`) — цены пересчитаны в течение 1–2 минут

**Замечания:** через [багрекер](../intro/bugtracker.md).
