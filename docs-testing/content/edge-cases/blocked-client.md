# E.1. Неактивированный / заблокированный клиент

!!! abstract "Сценарий"
    Менеджер заблокировал клиента в админке / 1С — клиент не должен иметь доступ к личному кабинету.

- [ ] Попросить разработку (или sales-manager через админку) заблокировать тестового пользователя
- [ ] Попытаться войти → редирект на страницу ошибки / logout с пояснением
- [ ] Администратор разблокирует → клиент снова может войти
