# E.10. Регрессия после обновления

!!! abstract "Сценарий"
    Каждый деплой может что-то сломать. Короткий смоук, который можно пройти за 5 минут, чтобы убедиться — ничего критичного не развалилось.

## Быстрый прогон

- [ ] Главная открывается
- [ ] Логин работает
- [ ] Каталог отображает товары
- [ ] QuickView открывается по клику
- [ ] Можно положить товар в корзину
- [ ] Можно оформить заказ (без реального проведения, отменить / использовать тестовый профиль)
- [ ] Страница `/docs/api` открывается (публичная документация REST)
- [ ] Страница `/docs/erp-guide/` открывается
- [ ] Страница `/docs/test-plan/` открывается (этот документ)

**Замечания:** через [багрекер](../intro/bugtracker.md).

!!! tip "Этот чек-лист стоит распечатать и держать под рукой"
    Если регрессия падает — сразу [багрекер](../intro/bugtracker.md) типа **🐛 Баг** с приоритетом «критично», дубль в общий чат с разработкой.
