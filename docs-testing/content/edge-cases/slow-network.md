# E.5. Медленный интернет

!!! abstract "Сценарий"
    Пользователь работает на слабом 3G-соединении — сайт должен оставаться живым, а не деградировать в хаос.

Включите в DevTools (F12) → вкладка Network → выпадающий список → «Slow 3G» и повторите:

- [ ] Главная грузится без «белого экрана» — показываются скелетоны
- [ ] Каталог подгружает страницы (пагинация или «Загрузить ещё») без дублирования
- [ ] Добавление в корзину не задваивается при быстрых кликах (кнопка должна блокироваться на время запроса)
- [ ] Оформление заказа показывает прогресс, кнопка не позволяет отправить дважды
- [ ] QuickView загружается с индикатором загрузки, пока `/api/products/{slug}` не ответит

**Замечания:** через [багрекер](../intro/bugtracker.md).
