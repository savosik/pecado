    ЭТАП 3. Первичное освоение личного кабинета¶

    Сценарий

    Клиент зарегистрирован и прошёл онбординг. Теперь осматривается в ЛК.

    3.1. Dashboard¶

    URL: /cabinet/dashboard

    • [ ] Страница открывается, заголовок «Дашборд»
    • [ ] Приветственная карточка с аватаром (инициалы клиента)
    • [ ] Статистика-плитки: Заказы / Избранное / Корзины / Баланс (если применимо)
    • [ ] Клик по плитке «Заказы» → /cabinet/orders
    • [ ] Клик по плитке «Избранное» → /favorites
    • [ ] Клик по плитке «Корзины» → /cabinet/carts
    • [ ] Блок «Последние заказы» (пустой, т. к. клиент новый): сообщение «Заказов пока нет»
    • [ ] Боковое меню ЛК содержит пункты:
      • Дашборд
      • Мои заказы
      • Отгрузки
      • Возвраты
      • Мои корзины
      • Мои компании
      • Адреса доставки
      • Стандартные выгрузки
      • Конструктор выгрузок
      • API-токены
      • Мои данные
      • Смена пароля
      • Выход
    • [ ] Клик по пункту «Выход» — сразу разлогинивает

    Не выходите из аккаунта

    Дальнейшие этапы проходятся под тем же клиентом. Если случайно вышли — войдите повторно и продолжите с того же места.
